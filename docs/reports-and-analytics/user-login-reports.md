> **At a glance** - Access the User Login Reports to monitor user activity and login statistics within your SmartWinnr account.

Go to **Left Menu >> Admin >> Reports >> User Login Reports**. This will open the User Login Reports page.

![User Login Reports page](/img/helpscout/authored/user-login-reports-mrx1rth3.png)

You can search for a specific user to find out if they have logged in or not by various criteria, which are as follows:

* **Business Unit**
* **Country**
* **Group**

To learn more about Advanced Search, [Click here.](http://support.smartwinnr.com/help/en-us/47-project-management/167-advanced-options-for-projects)

Here, you can find three different types of login reports:

![login reports](/img/helpscout/authored/user-login-reports-mt4odndq.png)

* **Initial Login Report** - This report provides a list of users who have completed their initial login into the SmartWinnr account.

* **All Login Reports** - This report shows all users who have logged into their SmartWinnr account for the selected date range. It includes two types of reports: the total number of users who have logged in during a specific date range and the number of times each user has logged into their account.

* **Not Using SmartWinnr Yet** - This report lists users who have not logged into their SmartWinnr account yet.

* **All User Access** - This report gives you the number of SmartWinnr accesses done by a user in a date range. It also provides the number of accesses date-wise.

You can also use filters to view the analytics chart of the users. The various options are as follows:

* **Frequency**: The total number of users logged in can be set to "Daily", "Weekly", "Quarterly", or "Annually".
* **Date Range**: Specify the date range for which you want the user report.

After setting the appropriate filters, you can download the analytics report in the following formats:

1. **Image**: Click on the image icon.
2. **Excel Report**: Click on the Hamburger Menu, which will provide the option to download the report in Excel format.

![Excel Report: click on the Hamburger Menu which will give you the option to download the report into excel format](/img/helpscout/admins/user-login-reports-3.png)

### Initial Login Report

![Initial login report](/img/helpscout/authored/user-login-reports-mt4ozmo8.png)

To download the initial login report, click on the **Hamburger Menu** and select **Download Initial Login Report**, which provides the list of users who have logged into the SmartWinnr account for the first time. Click on **Download Initial Login Report CSV** to download this report in a .csv file format.

### All Login Reports

![All login reports](/img/helpscout/authored/user-login-reports-mtilidga.png)

To download the all login report, which gives the number of users who logged into the system during the selected period, click on **Download All Login Report By User**. To download the .csv file, click on **Download All Login CSV Report By User**.

To download the user login details of all the users irrespective of the metatags for each day in a specific date range, click on **Download All Login Report by Date**. Click on **Download All Login CSV Report by Date** to download the .csv format file of the same report.

To download the division-wise report, click on **Download Division Wise Report**. It will ask you to select the metatags of the users you want to download the report.

![Select the metatag](/img/helpscout/authored/user-login-reports-mtilpffq.png)

Select the metatags and click on the **Download** button.

To download a day-wise report for users under specific metatags, select the option **Download Day Wise Login Report**. It will ask you to select the metatags as given below.

![Select the metatag](/img/helpscout/authored/user-login-reports-mtilpffq.png)

Select the metatags and click on the **Download** button.

### Not Using SmartWinnr Yet

![Not using SmartWinnr Yet](/img/helpscout/authored/user-login-reports-mtimlx4m.png)

This report will give you the list of users who have not logged into the system yet.

Select **Download Not Logged In User Report** to download the report with users who have not yet logged into the system. Select **Download Not Logged In User Report in CSV** to download this report in .csv format.

Note: The reports will get generated under the "Generated Report" section and you can download the reports from here. Please refer to the nelow article on hoow to download the report from generated report section.
