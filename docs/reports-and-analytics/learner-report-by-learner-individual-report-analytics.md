> **At a glance** - The Learner Report provides detailed analytics for individual learners, including quiz performance, survey responses, and coaching metrics.

An Editor who has access to the Learner Report can see the Report Analytics. This report allows you to analyze individual learner performance across various activities.

## When to use this
Use the Learner Report when you need to:
- Assess individual learner progress and performance.
- Review quiz results and responses.
- Analyze survey feedback.
- Evaluate coaching effectiveness.

## Steps

### 1. Access the Learner Report
Navigate to **Editor → Reports → Learner Report → By Learner**.

![GO TO EDITOR>>REPORTS>>LEARNER REPORT>>BY LEARNER.](/img/helpscout/editors/learner-report-by-learner-individual-report-analytics-1.jpg)

### 2. Select a User
Select the user you want to check the learner report for by clicking on the **Analytics** icon. You can also filter users by selecting the specific Business Unit, Country, and Group/Team.

![Select the user you want to check the learner report by clicking on the Analytics icon. You can also filter the user by selecting the specif](/img/helpscout/editors/learner-report-by-learner-individual-report-analytics-2.jpg)

### 3. Change the Date Range
You can change the date range to get the specific analytics report for a user. Then you can check the analytics for any particular quiz, survey, or coaching by clicking on the **Analytics** icon beside the activity.

![You can change the date range to get the specific analytics report for a user. Then you can check the analytics for any particular quiz, sur](/img/helpscout/editors/learner-report-by-learner-individual-report-analytics-3.jpg)

### 4. Review Activity Data
Here, you will see all the data for an activity of the user, including Quizzes Played, Quizzes Pending, Net Score, and Percentage Score.

![Here you will see all the data for an activity of the user like the Quizzes Played, Quizzes Pending, Net Score, and Percentage Score.](/img/helpscout/editors/learner-report-by-learner-individual-report-analytics-4.jpg)

### 5. Check Quiz Responses
After scrolling down, you can check the responses under **Quiz Response** for the quiz questions, including the time taken and the correct responses. You can also change the responses by clicking on the **Change Response** icon.

![After scrolling down, you can check the responses under Quiz Response for the quiz questions with the time taken and the correct responses. ](/img/helpscout/editors/learner-report-by-learner-individual-report-analytics-5.jpg)

### 6. Analyze Answer Analytics
In **Answer Analytics**, you can get details for total time taken, average time taken, and correct responses.

![In Answer Analytics, you can get the details for total time taken, the average time taken, and correct responses.](/img/helpscout/editors/learner-report-by-learner-individual-report-analytics-6.jpg)

### 7. Review Quiz Wise Performance
Scroll down to get the **Quiz Wise Performance**, where you can see Correct Answers, Incorrect Answers, Net Score, and Percentage Score.

![Scroll down to get the Quiz Wise Performance, where you get the Correct Answers, Incorrect Answers, Net Score, and Percentage Score.](/img/helpscout/editors/learner-report-by-learner-individual-report-analytics-7.jpg)

### 8. Check Survey Analytics
Similarly, for Surveys, you can check the analytics by clicking on the **Analytics** icon.

![Similarly, for Survey, you can also check the analytics by clicking on the Analytics icon.](/img/helpscout/editors/learner-report-by-learner-individual-report-analytics-8.jpg)

### 9. Review Survey Question Analytics
Here, you get the analytics for all the different types of survey questions.

![Here you get the analytics for all the different types of survey questions.](/img/helpscout/editors/learner-report-by-learner-individual-report-analytics-9.jpg)

### 10. Analyze Video Coaching
For Video Coaching, you can check the analytics as well by clicking on the **Analytics** icon. Here, you can check the uploaded video and the competencies on which the user was scored.

![Coaching analytics](/img/helpscout/authored/learner-report-by-learner-individual-report-analytics-mt2vy8gp.png)

This is how you can check the user report analytics for any activities participated in by the user.
