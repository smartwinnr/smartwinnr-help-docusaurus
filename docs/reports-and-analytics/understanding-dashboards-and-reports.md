> **At a glance** - SmartWinnr dashboards help you review participation, performance, coaching activity, and content usage. Each dashboard focuses on one module and shows the metrics, charts, and tables available for that area.

Use dashboards to understand activity across quizzes, coaching, SmartPaths, and content. Each dashboard shows the information for its module, and the available metrics depend on the tab you open.

## When to use this

Use dashboards when you want to review trends, compare results, or check progress across a module.

- Review quiz participation, completion, and performance.
- Analyze coaching participation and competency development.
- Check SmartPath progress, completion, and scores.
- Review content usage, references, and lifecycle status.
- Compare results for a selected date range or organizational group.

# 1 Quiz Dashboard

Use the Quiz Dashboard to review quiz activity, learner participation, and performance. It includes four tabs: **Overview**, **Participation**, **Learner Management**, and **Performance**.

### Overview

Use **Overview** to review the main quiz activity and performance metrics. It includes **Active Learners**, **Completion Rate**, **Quiz Attempts**, **Avg Score**, **Performance Trend**, **Popular Quizzes**, and **Recent Activity**.

### Participation

Use **Participation** to review learner activity, participation patterns, and submissions. It includes **Daily Active Users**, **Peak Usage Time**, **Participation Completion**, **Total Participation**, **Participation Over Time**, **Quiz Completion Status**, **Submissions**, and **Participation Heatmap**.

### Learner Management

Use **Learner Management** to review learner engagement and performance. It includes **New Learners**, **High Performers**, **At-Risk Users**, **Certification Due**, **User Engagement Trend**, **User Segmentation**, and **User Performance Overview**.

### Performance

Use **Performance** to review quiz results and performance patterns. It includes **Certification Pass Rate**, **Average Attempts**, **Avg Completion Time**, **Retry Success Rate**, score-distribution charts, a pass/fail donut chart, and an organizational heatmap.

The heatmap supports **Zone**, **Region**, **Team**, and custom tag filters.

# 2.SmartPath Dashboard

Use the SmartPath Dashboard to review learner participation, learning progress, module-wise performance, and SmartPath completion. It includes three tabs: **Overview**, **Module Wise Analysis**, and **Participation Insights**.

### Overview

Use **Overview** to review overall SmartPath activity, learner engagement, completion trends, and learning component distribution. It includes **Active Courses**, **Active Learners**, **Learning Hours**, **Avg Learning Hours**, **Completion Over Time**, **Learning Component Distribution**, **Top SmartPaths by Completion**, **Top Learners by Score**, and **Certification Overview**.

### Module Wise Analysis

Use **Module Wise Analysis** to review participation and performance across learning component types in SmartPaths.

It includes these sections:

- **Quiz Module Analysis**
- **Survey Module Analysis**
- **SmartFeed Module Analysis**

Each section shows the metrics available for that component type, such as active items, active learners, participation, average score, time spent, and completion status.

### Participation Insights

Use **Participation Insights** to review learner participation, SmartPath completion, progress, and scores for the selected period. It includes **Total Participants**, **Total Completed**, **Average Progress**, **Average Score**, **Completion Over Time**, and **Learner Progress**.

The **Learner Progress** section shows learner name, SmartPath, status, progress, score, time spent, and last activity. It also provides filtering and reporting options.

# 3.Content Centre Dashboard

Use the Content Centre Dashboard to review content availability, usage, effectiveness, references, and lifecycle status. It includes four tabs: **Overview**, **Effectiveness**, **All Content**, and **Lifecycle**.

Use the date range options to view the last 30 days, the last 90 days, or a custom period. The selected range affects the dashboard data.

### Overview

Use **Overview** to review the content library, usage, upload trends, and distribution. It includes **Total Content Items**, **Storage Used**, **Actively Used Content**, **Unused Content**, **Content by Type**, **Upload Trend by Content Type**, **Most Referenced Content**, **References by Module**, **Top Contributors**, **Folder Distribution**, and **Top Tags**.

### Effectiveness

Use **Effectiveness** to review content usage and engagement across your organization. It includes **Content Library**, **Assets Viewed**, **Internal Views**, **External Views**, **Active Viewers**, **Usage by Content Folder**, **Usage and Adoption by Business Unit**, **Content Consumption**, and **Content Details**.

### All Content

Use **All Content** to find content items, review their details and usage, and download the **All Content** report.

It includes **Content Highlights**, **Search Content**, **Filters**, **All Content Items**, **Content Details**, **Pagination**, and **Download Report**.

### Lifecycle

Use **Lifecycle** to monitor content as it moves through the approval and publishing process. It includes **Lifecycle Pipeline**, **Review Queue**, **Expiry Timeline**, **Pending Approval**, **Approval Turnaround**, and **Content Freshness**.

The lifecycle stages include **Draft**, **In Review**, **Approved**, **Published**, and **Archived**.

:::note
Only published content can be attached to modules.
:::

:::note
Archived content cannot be newly attached to modules, but existing attachments remain.
:::

:::note
Archived content can be republished where permitted.
:::

# 4. AI Coaching Dashboard

Use the AI Coaching Dashboard to review coaching participation, competency development, and learner progress. It includes three tabs: **Overview Analysis**, **Competency & Skills Insights**, and **Participation Insights**.

Use **coaching type**, **business unit**, and **region** filters, then select **Apply Filters** to refresh the dashboard. The dashboard also supports 30-day and 90-day comparisons.

### Overview Analysis

Use **Overview Analysis** to review coaching participation and the main coaching metrics. It includes **Active Learners**, **Average Attempts**, **Skill Improvement**, **Session Duration**, **Engagement Trends**, and **AI-generated insights**.

### Competency & Skills Insights

Use **Competency & Skills Insights** to review competency development and skill performance.

It includes:

- **Competency Growth Over Time**
- **Competency Performance by Attempt**
- **Soft Skills Assessment**

The charts cover skill groups such as **Call Closing**, **Objection Handling**, **Product Knowledge**, **Trust Building**, **Probing**, **Engagement**, and **Communicating Skills**.

The **Soft Skills Assessment** includes skills such as fluency, clarity, pace, and gestures.

### Participation Insights

Use **Participation Insights** to review participation-related coaching information for the selected filters and period. Refer to the labels shown in the dashboard for the available metrics and visualizations.

# 5. Field Coaching Dashboard

Use the Field Coaching Dashboard to review coaching participation, manager performance, session completion, and competency development. It includes three tabs: **Participation**, **Manager View**, and **Competency Analysis**.

Use the date range options and **Filters** to narrow the dashboard data by period and field coaching form.

### Participation

Use **Participation** to review overall coaching participation, session completion, and manager-level performance. It includes **Number of Managers**, **Coachees Assigned**, **Completed Sessions**, **Completion %**, **Total Sessions**, **Session Completion Trend**, **Completion % by Manager**, and **Participation Report**.

The **Participation Report** includes manager name, division, coachees assigned, completed sessions, total sessions, completion percentage, and status. You can filter by status, manage columns, and download the report.

### Manager View

Use **Manager View** to review coaching activity and competency ratings for one manager and their reportees. Select a manager from the **Manager** dropdown.

It includes **Coachees Assigned**, **Completed Sessions**, **Completion %**, **Total Sessions**, **Session Completion Trend**, **Reportee Sessions**, **Gap by Reportee**, **Gap by Competency**, and **Competency Heatmap — Reportees**.

### Competency Analysis

Use **Competency Analysis** to review competency ratings, track changes over time, and compare coach assessments with coachee self-assessments.

It includes **Competency Score Distribution**, **Competency Score Trend**, **Competency Snapshot**, **Competency Detail**, **Self-Awareness Distribution**, **Gap Trend Over Time**, and **Perception Gap by Competency**.

:::note
Some sections may show **No data available** when the selected filters or period return no results.
:::

## Using dashboard filters and date ranges

Use the filters available on each dashboard to focus the data on the right period, group, or category.

- In **AI Coaching Dashboard**, select the applicable coaching types, business units, and regions, then select **Apply Filters**.
- In **Content Centre Dashboard**, select **30-day**, **90-day**, or **custom** date ranges.
- In **Quiz Dashboard**, use the available segment and organizational filters, including **Zone**, **Region**, **Team**, and custom tags where shown.

The available filters depend on the dashboard and the tab you are viewing. Check the labels on screen to confirm which filters apply.

## Interpreting dashboard information

When you review a dashboard, start with the tab that matches your question. Then check the selected date range and filters before comparing results.

Use the charts, tables, and heatmaps to spot trends, compare groups, and identify items that need more review.
