> **At a glance** - This article explains how to give access permissions to other editors for various tasks in SmartWinnr.

As an Editor in SmartWinnr, you can give access permission to various tasks that you create to other editors. Tasks include:

* Quiz
* Survey
* SmartFeed
* Competitions
* Coaching
* Form

This access permission can only be given by Editors to other Editors.

## When to use this

Use this feature when you want to collaborate with other editors by granting them access to specific tasks you create. This is particularly useful for team projects or when multiple editors need to work on the same content.

## Steps

### 1. Access Your Profile

On the SmartWinnr portal, click on your name displayed at the top right corner of the screen. Then click on the **Profile** button as shown in the picture below:

![Access Profile](/img/helpscout/authored/how-do-i-give-access-permission-to-other-editors-ms8m4izm.png)

### 2. Navigate to Access Permission Tab

It will take you to the following page:

![Profile Page](/img/helpscout/authored/how-do-i-give-access-permission-to-other-editors-ms8m5qdx.png)

Here, select the **Access Permission** tab. It shows you the following page where you can add access permissions:

![Access Permission Tab](/img/helpscout/authored/how-do-i-give-access-permission-to-other-editors-ms8m75xm.png)

### 3. Add Access Permissions

Now, click on the "Click Here" link on the above page to add access permissions. It will open the following pop-up:

![Add Access Permissions](/img/helpscout/authored/how-do-i-give-access-permission-to-other-editors-ms8m8iq6.png)

Here, select a task for which you want to give access permission and select the editors to whom you want to give access. Then, click on the **Save** button. This will successfully give access to that particular task to all the selected editors.

On providing access permission to a task or Module (eg: Quiz, SmartFeed, Coaching, Survery etc), the other editor can access those content/activity in the tag called **'Other SmartFeeds'/'Other Quizzes'/'Other coachings'** etc, under the respective module as shown below.

![Other coachings tag](/img/helpscout/authored/how-do-i-give-access-permission-to-other-editors-ms8mrc40.png)

### 4. View Granted Permissions

Here is how you will be able to see all the permissions that you have given:

![Granted Permissions](/img/helpscout/authored/how-do-i-give-access-permission-to-other-editors-ms8m9mvv.png)

The editors who have access to a particular kind of task will have access to similar kinds of tasks that you create in the future by default. For example, if you have chosen three editors and given them access to the quiz, then those three editors will have access to all the quizzes that you create in the future.
