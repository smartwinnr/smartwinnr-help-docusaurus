> **At a glance** - Grant access to other editors for specific tasks like quizzes, surveys, or coaching activities in SmartWinnr.

Once you create a task in SmartWinnr, such as a quiz, survey, coaching session, SmartFeed, or competition, you can provide other editors access to that task. This access allows them to view and analyze the associated reports and analytics.

## When to use this

Use this feature when you want to:

- Collaborate with other editors on specific tasks.
- Allow team members to access analytics and reports for a task you created.
- Manage permissions effectively within your organization.

## Steps

### 1. Navigate to the task

Go to the task to which you would like to give access. For example, if you need to give access to a quiz you created, navigate to **Left Menu >> Editor >> Questions and Quizzes >> View all quizzes**. Here, select the required quiz for which you would like to give access.

![Go to the task to which you would like to give access. For example, if you need to give access to a quiz that you have created in SmartWinnr](/img/helpscout/editors/how-to-give-other-editors-access-to-a-particular-activity-task-you-created-in-smartwinnr-1.png)

### 2. Open access permissions

This will take you to the selected quiz. Click on the **hamburger icon** at the top right-hand corner of the page and then choose the **Access Permission** option.

![Access Permission option in the menu](/img/helpscout/authored/how-to-give-other-editors-access-to-a-particular-activity-task-you-created-in-smartwinnr-ms8mfjed.png)

### 3. Select users for access

A screen will open where you can select the users to whom you want to give access permission. The list will include all the editors from your organization.

![User selection for access permission](/img/helpscout/authored/how-to-give-other-editors-access-to-a-particular-activity-task-you-created-in-smartwinnr-ms8mgipo.png)

### 4. Save your changes

Once you have selected the users, click on the **Save** button to save the changes.

## How will it appear to the people who have permission

An editor who has been granted permission to access an activity or task will be able to see it under the **Others** tab of quizzes, surveys, SmartFeeds, coaching sessions, etc.

Below is a screenshot of how an editor will be able to see the quizzes they have been given access to.

![Editor view of quizzes they have access to](/img/helpscout/editors/how-to-give-other-editors-access-to-a-particular-activity-task-you-created-in-smartwinnr-4.png)

Editors can filter these coaching sessions based on the date range, divisions, and the person who created them.
