> **At a glance** - If a user is in the “Pending” state and has not received their invitation email, you can easily resend the invitation.

In case the user is in “Pending” state and has not received the invitation email, you can resend the invitation to the user. To resend the account invitation, follow these steps:

## When to use this

Use this process when:

- A user has not received their account invitation email.
- The user status is still “Pending” in the system.
- You need to ensure the user can access their account.

## Steps

### 1. Navigate to Manage Users

Go to **ADMIN** > **Manage Users**. Click on the user you want to resend the invitation to.

![Go to ADMIN > Manage Users. Click on the user you want to resend the invitation to.](/img/helpscout/authored/how-to-resend-account-invitation-ms5pc8kh.png)

### 2. Select Resend Invitation

From the hamburger menu, select the “Resend Invitation” option. Click on “Send Reset Password Email”.

### 3. Choose Password Options

SmartWinnr will display a pop-up with the following password options:

1. **Set Random Password**  
   Select this option to automatically generate and send a random password to the user.

   ![Select random password to automatically generate and send a random password to the user.](/img/helpscout/authored/how-to-resend-account-invitation-ms5pijd4.png)

2. **Manually Set Password**  
   Select this option to enter a desired password. The entered password will be sent to the user.

   ![Select Manually set password and enter the desired password. The entered password will be sent to the user.](/img/helpscout/authored/how-to-resend-account-invitation-ms5pjm3y.png)
