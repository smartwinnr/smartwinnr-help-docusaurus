> **At a glance** - SmartWinnr allows you to search for users using various attributes, making it easy to find specific individuals within your organization.

SmartWinnr provides a powerful search functionality to search for users by different attributes. This feature enables administrators to quickly locate users based on specific criteria.

## When to use this
Use this search functionality when you need to find a user quickly based on various attributes, such as name, email, or user status. This is particularly useful for:

- Managing user accounts efficiently.
- Locating users for support or communication.
- Filtering users based on specific roles or attributes.

## Steps

### 1. Log in to the Admin Portal
Log in to the SmartWinnr Admin Portal using your administrator credentials.

### 2. Navigate to Manage Users
Go to **Admin** → **Manage Users** in the navigation menu.

### 3. Use Search and Filter Options
Utilize the available search and filter options to find the required users.

![It shows filter options to search users](/img/helpscout/authored/search-users-msojn4yy.png)

### 4. Search and Filter Options
- **Business Unit:** Select a Business Unit or Division to search for users belonging to that organization.
- **Country:** Select a Country or Sub-Division to search for users based on their location or organizational structure.
- **Name:** Search users by name. Partial name search is also supported.
- **Email:** Search users using their email address. A fully qualified email address is required.
- **Phone No.:** Search users using their registered phone number.
- **User Identifier:** Search users using their configured User Identifier.
- **User Emp ID:** Search users using their Employee ID.
- **Roles:** Search users based on any of the system roles assigned to them.
- **User Status:** Filter users based on their account status, such as Active, Pending, or Deactivated.
- **User Tags:** Search users using any User Tags configured in your organization.
- **Groups:** Search users based on the Groups they are assigned to.
- **Territory:** Search users based on their assigned Territory.

## Tips
- Combine multiple search criteria to narrow down results effectively.
- Use partial names or identifiers to broaden your search if necessary.

## Things to know
The available search and filter options may depend on the user attributes and organizational configurations available in your SmartWinnr instance.
