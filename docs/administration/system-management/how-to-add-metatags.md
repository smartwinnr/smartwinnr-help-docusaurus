> **At a glance** - You can create metatags either individually or in bulk to manage user metadata effectively.

Metatags help organize and categorize user data within your system. You can create them individually for specific needs or upload them in bulk for efficiency.

## When to use this
Use metatags when you need to:
- Organize user data for better management.
- Apply specific tags to user profiles.
- Update multiple tags simultaneously for efficiency.

## Steps

### 1. Log in and navigate to User Metadata
Log in to your Admin account. Go to **Admin > User Metadata**. This will take you to the Meta Tags list page where you can see the Meta Tag Name and its tags.

![Select Metatags from Admin section](/img/helpscout/authored/how-to-add-metatags-mrvpnqb6.png)

### 2. Create metatags individually
Click on the **Add New** button to create metatags individually.

![Add Metatags Individually](/img/helpscout/authored/authored-mrvpdjb5.png)

### 3. Add the metatag values
Enter the Metatag Name and its tags. You can add translations in all available language textboxes. Add as many tags as needed, then click the **Save** button.

![Add the metatag values](/img/helpscout/authored/authored-mrvpe4eg.png)

### 4. Create metatags in bulk
To create metatags in bulk, first create the metatag name with one tag value if it's a new metatag. Then, click on the **Upload Meta Tags in Bulk** button. If it is an existing metatag, then simply click on the **Upload Meta Tags in Bulk** button.

![Add metatags in bulk](/img/helpscout/authored/authored-mrvpeijt.png)

### 5. Download the template
Download the template and fill it with the required values.

![Download the Template](/img/helpscout/authored/authored-mrvpg0ks.png)

![Fill the CSV template](/img/helpscout/authored/authored-mrvphxea.png)

### 6. Upload the filled CSV file
Select the metatag name from the **Meta Tag Name** dropdown for which you would like to add the new values, choose the filled CSV file, and click on the **Upload** button. The values will then be uploaded to the system.

![Select the metatag name and upload the file.](/img/helpscout/authored/authored-mrvpinba.png)
