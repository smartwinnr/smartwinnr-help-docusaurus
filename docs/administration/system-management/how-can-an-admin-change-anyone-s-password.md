> **At a glance** - Admins can change any user's password through the Admin panel by following a few simple steps.

You can change the password of a user by following the steps outlined below.

## When to use this

Use this feature when:

- A user forgets their password.
- A user requests a password change for security reasons.
- You need to reset a user's password for any other reason.

## Steps

### 1. Navigate to Manage Users

Go to **ADMIN** > **Manage Users**.

### 2. Select Change Password

Click on the **Change Password** button for the user whose password you want to change.

![Only users with admin role can change the password.](/img/helpscout/admins/how-can-an-admin-change-anyone-s-password-1.png)

### 3. Set the New Password

Enter the new password. The password must comply with your organizational password policy as defined in the SmartWinnr system.

![The password you select needs to confirm with your organizational password policy as defined in the SmartWinnr system.](/img/helpscout/admins/how-can-an-admin-change-anyone-s-password-2.png)

### 4. Communicate the New Password

The user will not receive any email notification about the password change through this method. You need to communicate the changed password to the user separately.

## Things to know

- Only users with the admin role can change the password.
