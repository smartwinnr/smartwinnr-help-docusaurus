> **At a glance** - Use Groups in SmartWinnr to efficiently send Quizzes, Surveys, and Content to multiple users at once.

SmartWinnr allows you to send **Quizzes, Surveys, and Content** to a predefined set of users using **Groups**, making distribution quick and efficient. Only the Trainer/Editor can send tasks to groups.

## When to use this
Use this feature when you need to distribute content to multiple users without selecting them individually. This is particularly useful for:

- Assigning quizzes to a class.
- Distributing surveys to a team.
- Sharing content with a specific group of users.

## Steps

### 1. Select the Group
While assigning content, you will see a **Group** field where all Groups accessible to the Editor are listed. 

![While assigning content, you will see a Group field where all Groups accessible to the Editor are listed. The Editor can select the required](/img/helpscout/editors/how-to-send-quizzes-surveys-and-content-using-group-1.png)

### 2. Choose the Required Group
Select the required Group based on your needs. Once a Group is selected, the list of users associated with that Group will be displayed.

### 3. Select Users
Select the required users from the list and click **Save** to successfully assign the Quiz.

### 4. Sending Surveys and Content
The same process applies when sending **Surveys** or **Content (SmartFeed)**. Simply select the required Group during participant selection and proceed with saving or assigning.

Using Groups helps avoid selecting individual users and ensures faster, more consistent content delivery.
