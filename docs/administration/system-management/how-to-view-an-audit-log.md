> **At a glance** - Access the Audit Log to view detailed records of actions taken within the system, including timestamps and user information.

To view an Audit Log, navigate to **Admin** and select **Audit Logs**. This will open the Audit Log page, where you can see information about various existing logs, including when they were created, the actions taken, and the user associated with each event.

![You can see the information about the various existing logs. Information about when they were created, various actions](/img/helpscout/authored/how-to-view-an-audit-log-msirac8k.png)

## When to use this
Use the Audit Log to track user activities and system changes. This feature is helpful for:

- Monitoring user actions for compliance and security.
- Investigating issues or discrepancies in system behavior.
- Understanding the history of changes made within the system.

## Steps

### 1. Navigate to the Audit Logs
Go to **Admin** and select **Audit Logs** to open the Audit Log page.

![You can see the information about the various existing logs. Information about when they were created, various actions](/img/helpscout/authored/how-to-view-an-audit-log-msirac8k.png)

### 2. Filter by Date Range
Logs can be viewed for a specific date range by clicking on the **Date Range** option. The available options in the date range are shown below.

![Logs can be viewed for a specific date range by clicking on the date "Date Range"](/img/helpscout/authored/how-to-view-an-audit-log-msircei7.png)

Select the desired date range and click **Apply**. Logs within that date range will be displayed.

### 3. Filter by Action
You can also select the **Action** from the drop-down menu to filter the logs. The various actions are as follows:

![You can also select the "Action" from the drop-down for filtering the Log. The various actions are as follows](/img/helpscout/authored/how-to-view-an-audit-log-msirf16u.png)

### 4. Filter by Task Name and User Name
Audit Logs can be further filtered using the **Task Name** and **User Name** fields to narrow down the results.

## Tips
- Regularly check the Audit Log to ensure compliance with your organization’s policies.
- Use specific filters to quickly find relevant logs when investigating issues.

## Things to know
Audit Logs provide a comprehensive history of actions taken within the system. Ensure you have the appropriate permissions to access this feature.
