> **At a glance** - This article outlines the steps to create a group in SmartWinnr, including options for public and private groups.

## Create Groups

Follow the steps below to create a group in SmartWinnr:

## When to use this

Creating groups is useful when you want to organize users for specific purposes, such as training, communication, or project management. Use this feature when:

- You need to group users for a specific training program.
- You want to facilitate communication among a team.
- You are managing multiple projects and need to organize users accordingly.

## Steps

### 1. Navigate to Groups

Go to **EDITOR > Settings > Groups**.

### 2. Add a New Group

Click on **Add New Group**.

A ‘Public’ group will be visible to all, and other Editors will also be able to reuse it, while a ‘Private’ group will be visible only to you.

![A ‘Public’ group will be visible to all and other Editors will also be able to reuse it, while a ‘Private’ group will be visible only to you](/img/helpscout/editors/how-to-create-a-group-1.png)

### 3. Enter Group Details

Enter a **Group Name** and **Description**.

Select the **Group Type**:

- **Public Group**: Visible to all Editors and reusable by others.
- **Private Group**: Visible only to the creator.

![Select the Group Type:](/img/helpscout/editors/how-to-create-a-group-2.png)

If you choose the Group Type as public, then you need to select the Business Unit and Country to whom this group will be visible.

![If you choose the Group Type as public, then you need to select the Business Unit and Country to whom this group will be visible.](/img/helpscout/editors/how-to-create-a-group-3.png)

### 4. Save and Add Members

Once you have added the required details to create a group, click on the **Save And Add Members** button.

In the next step, add members to this new group. You can select members through the Search/Advanced Search provided in the selection screen. Once you have made the necessary selections, click on the **Add Selected Members** button at the bottom of the screen.

![Now, in the next step, add members to this new group. You can select members through the Search/Advanced Search given in the selection scree](/img/helpscout/editors/how-to-create-a-group-4.png)

### 5. Upload Users in Bulk (Optional)

SmartWinnr also provides an option to upload users in bulk.

There is an **Upload Users** option available at the **top-right corner** of the Groups page. Clicking on this button will navigate you to the bulk user upload page.

![There is an Upload Users option available at the top-right corner of the Groups page. Clicking on this button will navigate you to the bulk ](/img/helpscout/editors/how-to-create-a-group-5.png)

- Select **Type of Action** as **Add Users**.
- Choose the **User Identifier**:
  - Email Address, or
  - User Identifier
- Click on **Download Template** to download the CSV format.

![](/img/helpscout/editors/how-to-create-a-group-6.png)

### 6. Fill in User Details

Open the downloaded template and fill in the required user email IDs or user identifiers. Save the file in **CSV format**.

![](/img/helpscout/editors/how-to-create-a-group-7.png)

### 7. Upload the CSV File

Upload the CSV file by clicking the **Upload** button.

![](/img/helpscout/editors/how-to-create-a-group-8.png)

Once uploaded successfully, the users will be added to the selected group.

### To Remove Users in Bulk

1. Select **Type of Action** as **Remove Users**.
2. Follow the same steps by downloading the template, entering the user details, and uploading the CSV file.

This action will update the group accordingly. Once created or updated, all groups will be visible on the **Groups** page for easy access and management.
