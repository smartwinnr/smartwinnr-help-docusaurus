> **At a glance** - This article explains how to update the username of an existing user in the system.

You can easily update a user's username through the Admin panel. Follow the steps below to ensure the changes are saved correctly.

## When to use this

Use this feature when you need to:

- Correct a user's username for accuracy.
- Update a username due to a change in the user's preference.
- Ensure consistency in user records.

## Before you start

You need to have the **Admin** role to update a username. Ensure you have the necessary administrative privileges to access the **Admin** panel and modify user details.

## Steps

### 1. Navigate to Manager Users

Go to **Admin > Manager Users** and select the user whose username you want to update.

![first page showing list of users](/img/helpscout/authored/authored-mrx17hwy.png)

### 2. Open User Details

Click on the username to open the user's details.

![how visible after open user](/img/helpscout/authored/authored-mrx18kvg.png)

### 3. Edit the Username

Click on the **Edit** option in the top right corner, then click on the edit icon next to the **Username** field. Change the username as needed and click on the **Update** button to save the changes.

![how to edit username](/img/helpscout/authored/authored-mrx1aeju.png)

### 4. Connect to DynamoDB

After updating, click on the hamburger menu on the right side and select **Connect to DynamoDB**. This step ensures that all fields are saved properly.

![connect to dynamo db](/img/helpscout/authored/authored-mrx1f1wu.png)

## Tips

- Double-check the new username for accuracy before saving.
- Ensure that the new username complies with any organizational naming conventions.
