> **At a glance** - Archiving content does not remove it from modules where it is already being used. The existing module continues to use the attached content, while the archived content is no longer available for use in new modules.

When content is archived, its existing usage is not affected. The content remains available in modules that already use it, but it cannot be attached to new modules until it is available again.

## When to use this

Use this when you want to understand:

* What happens to existing modules when their content is archived.
* Whether archiving removes content from modules where it is already attached.
* Whether archived content can be used in new modules.
* How automatic archiving affects content that is still in use.

## Existing modules remain unchanged

Content that is already attached to a module remains attached after the content is archived. Archiving does not remove the content from existing modules.

## Archived content cannot be added to new modules

Archived content cannot be attached to a new module. It must be available in a published state before it can be used for a new module.

## Hold off while it is still in use

The **Hold off while it is still in use** option in the archive rules prevents content from being automatically archived while it is still attached to a module.

## Advance warning before automatic archival

Before content is automatically archived, the system sends an **advance warning email**. This gives you time to review the content before it is archived.

## Republish archived content

Republishing an archived content item makes it available for use again. Once it is published, the content can be attached to new modules.
