> **At a glance** - Use the **All Content** tab in **Content Effectiveness** to find content, review usage, and download the **All Content** report.

Use the **All Content** tab to search for content by name, narrow the list with filters, and open content details. You can also review summary sections for referenced, recent, and popular content, then download the **All Content** report.

## When to use this

Use the **All Content** tab when you want to:

- Find a specific content item by name.
- Review **Most Referenced Content**, **Most Recent Content**, and **Most Popular Content**.
- Filter content by type, status, or creator.
- Open content details such as references, views, folder, creator, and creation date.
- Move through a long content list with pagination.
- Download the **All Content** report.

## Steps

### 1. Open the **All Content** tab
Log in to the **Editor Portal**. Then go to **Content Management → Content Centre** and open **Content Effectiveness**. Select the **All Content** tab to view the content available in Content Centre.

![All Content tab](/img/helpscout/authored/authored-muwkfwwv.png)

### 2. Review content highlights
Use the summary sections to spot content that stands out by usage or recency. 

**Most Referenced Content** shows the items with the most references across modules.

**Most Recent Content** shows the latest additions. 

**Most Popular Content** shows the items with the highest total views.

![Most Referenced Content,Most Recent Content,Most Popular Content](/img/helpscout/authored/authored-muwm919w.png)

### 3. Search for content
Use **Search content by name...** to find a specific item. Enter the content name, review the matching results, and select the item you want to open.

### 4. Filter the list
Use the filters next to the search bar to narrow the results. You can filter by **All types**, **All statuses**, and **All creators**. You can also use search and filters together.

### 5. Review the content table
The **All Content Items** table shows key details for each item, including **Name**, **Type**, **Status**, **Folder**, **Refs**, **Total Views**, **Internal**, **External**, **Created By**, **Created On**, **Aging**, and **Expiry**.

![All Content Items table](/img/helpscout/authored/authored-muwmv4m3.png)

### 6. Open content details
Select any content item in the **All Content Items** table to open its details. You can review the content name, preview, type, status, folder, references, aging, view counts, unique viewers, and usage breakdowns. Select **X** in the top-right corner to return to the list.
![content details](/img/helpscout/authored/how-to-find-a-content-item-and-download-the-all-content-report-muwn70vo.png)
### 7. Move through pages
If the list spans multiple pages, use the pagination controls at the bottom of the table. The table also shows the current item range and total item count, such as **Showing 61–70 of 135 items** and **Page 7 of 14**.

### 8. Download the **All Content** report
Use **Download Report** to download the content list. You can search for content or apply filters first, then select Download Report to download the report.
![kindly click on download report](/img/helpscout/authored/how-to-find-a-content-item-and-download-the-all-content-report-muwnjetp.png)
Open the downloaded file to review the content details.
The downloaded report includes these columns:

| Column | Description |
| --- | --- |
| **Name** | Name of the content item |
| **Type** | Content type |
| **Status** | Current status of the content |
| **Folder** | Folder where the content is stored |
| **Refs** | Number of references to the content |
| **Total Views** | Total number of views |
| **Internal Views** | Number of internal views |
| **External Views** | Number of external views |
| **Created By** | User who created the content |
| **Created On** | Date the content was created |
| **Expiry Date** | Expiry date of the content |
