> **At a glance** -You can update an existing published content item by selecting *Edit* from the content item view. The new version follows its own review and publishing cycle.

Use this process when you need to change a content item that is already published. You can replace the file, update its categories, tags, and competencies, and then create a new version. The current live version stays available until the new version is approved and published.

## When to use this
Use this when you need to:
* Replace the file for an existing content item.
* Change categories, tags, or competencies.
* Keep the current live version available during review.
* Compare different versions from the content item view.

## Steps

### 1. Open the content item
Go to **Content Management → Content Center → All Content Center** in the Editor Portal. Open the published content item you want to update.
![open the content item](/img/helpscout/authored/how-to-update-a-content-item-and-create-a-new-version-muu247wl.png)

### 2. Select **Edit**
From the content item view, select **Edit** on the right side. The **Edit Content Item** screen opens, where you can update the content details and replace the existing file.
![click on edit](/img/helpscout/authored/how-to-update-a-content-item-and-create-a-new-version-muu26pti.png)

### 3. Replace the current file
In the **File** section, upload a new file to replace the existing file.
- Select **Drop file here or click to browse**.
- Choose the new file from your device.
- Review the selected file in the **File** section.
If you need to remove the selected file, select **Remove Selected File**.
![Replace the current file](/img/helpscout/authored/how-to-update-a-content-item-and-create-a-new-version-muu28j42.png)

### 4. Update categories

In the **Categories** section, update the required category values. Select the appropriate category from the available options for the content item.

### 5. Update tags and competencies

In the **Tags and Competencies** section, update the required values.

You can add or change:

- **Tags**
- **Competencies**
- **Competency level, where applicable**

Review the selected values before you create the new version.

### 6. Select **Update**

After you make the required changes, select **Update**. This creates a new version of the content item.

The existing published version remains available while the new version moves through its lifecycle.
![click on update](/img/helpscout/authored/how-to-update-a-content-item-and-create-a-new-version-muu2bvvp.png)
### 7. Submit the new version for review

Submit the **new version** for review and select the required **Reviewer**. The version moves through the review stages before it can be published.

### 8. Review and publish the new version

After the reviewer approves the new version, it moves to the **Approved** stage. Publish the approved version to make it the **Live** version.

### 9. Switch between versions

From the content item view, use the **Version** dropdown to switch between available versions. The dropdown shows each version of the content item.

The version marked **Live** is the version that is currently published and active. Use this view to review changes across versions.
![Switch between versions](/img/helpscout/authored/how-to-update-a-content-item-and-create-a-new-version-muu2g5zt.png)
