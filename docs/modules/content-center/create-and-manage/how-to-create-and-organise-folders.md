> **At a glance** - Use folders in Content Centre to keep content structured and easy to find. You can create folders under **Root**, nest folders inside other folders, and control the order of folders and items.

Content Centre is your central repository for organizational content. Use it to store content in one place and reuse it across supported SmartWinnr experiences.

## When to use this

Use folders when you want to organize content into a clear structure.

- Create subfolders under **Root** or inside existing folders.
- Group related content for easier navigation.
- Control the order of folders and content items.
- Prepare destination folders before a bulk import.

## Steps

### 1. Open Content Centre
Log in to the Editor Portal and go to **Content Management → content center → All Content Center**.
![kindly open content center](/img/helpscout/authored/how-to-create-and-organise-folders-mukwn7hy.png)
### 2. Create a folder
Go to the location where you want the folder. Select **New**,then choose **Create Folder**.
![create new folder](/img/helpscout/authored/how-to-create-and-organise-folders-mukwsdvn.png)

Enter a clear **Folder Name**, upload a **cover image** using a **16:9 aspect ratio**, and click **Create**.

![kindly click on create](/img/helpscout/authored/how-to-create-and-organise-folders-mukww4l1.png)
The folder appears as a folder card in Content Centre.

### 3. Create nested folders
Open the folder where you want to add a subfolder. Select **New → Create Folder**, enter the folder name, then select **Create**.

You can keep adding folders inside folders to build a hierarchy such as **Root → Product Training → Product Guides**.

### 4. Change folder sequence
Open the location where you want to change the folder order. On the right side, select the **hamburger menu**, then choose **Change Folder Sequence**. 
![kindly click on change folder sequence](/img/helpscout/authored/how-to-create-and-organise-folders-mukx2u1m.png)
Arrange the folders in the required order and save the sequence.
![kindly click on save](/img/helpscout/authored/how-to-create-and-organise-folders-mukx55j9.png)
### 5. Change item sequence
 Open the location where you want to change the item order. On the right side, select the **hamburger menu**, then choose **Change Item Sequence**.
![kindly click on change item sequence](/img/helpscout/authored/how-to-create-and-organise-folders-mukx7guq.png)
 Arrange the items in the required order, then save the sequence.
![kindly click on save](/img/helpscout/authored/how-to-create-and-organise-folders-mukx8aho.png)

### 6. Reindex all
Open the relevant folder menu. On the right side, select the **hamburger menu**, then choose **Reindex All**.
![kindly click on reindex all](/img/helpscout/authored/how-to-create-and-organise-folders-mukx9mav.png)
![kindly click on reindex](/img/helpscout/authored/how-to-create-and-organise-folders-mukxa9zx.png)
Allow the folder contents to be reindexed after you change folder or item order.

:::note
Reindexing updates the order and indexing of folders and items. It does not change the content itself.
:::

### 7. Create folders before bulk import
If you use Bulk Import, create the destination folders in Content Centre first. The import file uses those folders to place each item.

Create folders, create nested folders, set folder and item sequence, then run the bulk import.
