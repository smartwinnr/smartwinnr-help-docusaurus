> **At a glance** -Classify a content item with categories, tags, and competencies so it can be found and retrieved.

Content metadata helps you organize a content item in the Editor Portal. Use categories to classify it by business unit, tags to describe it, and competencies to connect it to skills and proficiency levels.

## When to use this

Use this when you need to organize a content item for easier discovery and clearer skill mapping.

- Classify a content item by business unit.
- Add tags or tag groups to describe the content.
- Assign competencies with proficiency levels.
- Use manual tags or auto-tagging.
- Update metadata on an existing content item.

## Steps

### 1. Open the content item
Go to **Content Management → Content Center → All Content Center** in the Editor Portal.

![Go to Content Management → Content Center → All Content Center in the Editor Portal](/img/helpscout/authored/authored-muv4y3is.png)

### 2. Add categories
When you create or edit a content item, assign the appropriate category for each relevant business unit. Use the category selector to classify the content correctly.

The available category selectors and values depend on your business unit setup.

### 3. Add tags
Add tags to describe the content by subject or characteristic. You can select tags individually or use auto-tagging to assign them automatically.

If your setup includes tag groups, use them to organize related tags.

### 4. Add competencies
Assign competencies to connect the content to the skills it covers. For each competency, choose the matching proficiency level, such as beginner or advanced.

![categories, tags, competencies](/img/helpscout/authored/authored-muv4yu8a.png)

You use **Auto-generate Tags** and **Auto-generate Competencies** when you want the system to automatically identify relevant tags and competencies from the content, instead of selecting them manually.

![kindly click on auto generate and auto generate competencies](/img/helpscout/authored/how-to-tag-content-with-categories-tags-and-competencies-muv63zsj.png)
Once you click **Auto-generate Tags**, a pop-up appears in the **bottom-right corner**.
![confirmation that tags are generated](/img/helpscout/authored/how-to-tag-content-with-categories-tags-and-competencies-muv7c47w.png)
Once you click **Auto-generate competencies**, a pop-up appears in the **bottom-right corner**.
![confirmation that competencies are generated](/img/helpscout/authored/how-to-tag-content-with-categories-tags-and-competencies-muv7f9i1.png)
### 5. Edit metadata on existing content

Click **Edit** on the **Content Item** page. Update the metadata as needed, including **Categories, Tags, Tag Groups, or Competencies** and their **Proficiency Levels**.

### 6. How metadata is used

**Categories, Tags, and Competencies** provide classification information that helps to **organize, classify, find, and retrieve content** in Content Center.

* **Categories** help group and classify content by relevant business units or subject areas.
* **Tags** and **Tag Groups** add keywords and characteristics that describe the content and make it easier to search and organize.
* **Competencies** associate content with the skills or competencies it supports and their assigned proficiency levels.
* The **Search bar** uses these metadata fields, along with the **content item title, description, and content within uploaded documents**, to help users find relevant **folders and content items**. For example, if a keyword appears in an uploaded PDF, searching for that keyword can return the associated content item.
![use Search bar to find folders and content items using relevant keywords. ](/img/helpscout/authored/how-to-tag-content-with-categories-tags-and-competencies-muw9n41w.png)
Using metadata makes content **easier to organize, search, and retrieve** in Content Center.
