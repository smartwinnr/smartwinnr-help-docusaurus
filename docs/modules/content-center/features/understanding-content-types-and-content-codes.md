> **At a glance** - Content center uses content types to classify items and content codes to identify them. You use both when creating content and updating existing items through bulk import.

Content Centre stores reusable content for the platform. Each item has a content type and a content code. Together, they help you organize content and keep track of the same item when you update it.
Use content types to describe what kind of file or learning content you are adding. Use content codes to identify a specific item, especially during bulk import updates.

## When to use this

Use this when you want to:

- Understand the content types supported by Content Centre.
- Choose the right content type when you create an item.
- See where the content code appears and what it means.
- Update an existing item through bulk import.
- Keep the same content item when you replace its file.

## Steps

### 1. Choose a content type
When you create a content item, select the content type that matches the file or learning content you are adding. Content Centre supports PDF, Video, Image, Audio and SCORM.

For example:
* Select **PDF** when adding a PDF file.
* Select **Video** when adding a video.
* Select **Image** when adding an image.
* Select **Audio** when adding an audio file.
* Select **SCORM** when adding SCORM content.


![content types](/img/helpscout/authored/authored-muxzzbdn.png)

### 2. Use the content code
The Content Code field appears on the Create Content Item page, alongside the other content details.Each content item has a content code. Content Centre can generate it automatically when you create an item. You can also enter a specific code if needed.

![content code is automatically generated](/img/helpscout/authored/authored-muy17nyg.png)
### 3. Identify content during bulk import

Use the **Content Code** during bulk import to identify an existing content item. This lets you update the required item instead of creating a new one.

### 4. Keep the same item identity

When you update content, the **Content Code** remains the same and continues to identify the existing content item. The updated file is added as a **new version** of that item, so the same Content Code is retained across versions.

## Note

* Content stored in Content Centre can be reused across SmartFeed, SmartPath, KHub, and Coaching.

* When updating content through bulk import, use the existing Content Code to identify the item you want to update.
