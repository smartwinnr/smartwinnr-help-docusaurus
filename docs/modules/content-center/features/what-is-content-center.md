> **At a glance** - Content Centre is the central repository in SmartWinnr for storing and managing content. You can use it for training content and for content used by buyers and sellers.

Use Content Centre to organize content, manage versions, control archival, and track usage over time. It gives you one place to manage content through its full lifecycle.

## When to use this

Use Content Centre when you need a single place to manage content across teams and use cases.

- Store content in folders and content items.
- Create individual items or import many items at once.
- Track content through draft, review, approval, publishing, and archival.
- Review usage, references, and lifecycle status from the dashboard.

Here’s a cleaner, documentation-ready version with a concise flow:

## Access Content Centre

In the **Admin Portal**, go to **Content Management > All Content Center**.

Content Centre is organised using a **Root folder**, which can contain nested folders and content items. This structure helps you organise content based on teams, topics, or use cases.

You can view content using **All**, **Folders**, or **Items**. Switch between **Grid** and **List** layouts, and use **Search** to quickly find content.

This keeps all the required information while making the section easier to scan and understand.

## Create and import content

### 1. Create an item
Go to the folder where you want the item to live, then select **New > Create Item**. Add the content type, title, description, file, and tags, then create the item.

### 2. Import items in bulk
Use **Bulk Import** to add multiple content items at once. Select **Validate Only** first to check the import file without creating items.

Then select **Import** to create the valid items in Content Centre.

## Manage the content lifecycle

Content items move through these stages:

Draft → In Review → Approved → Published → Archived

You can republish an archived item when you need to use it again.

You can also configure **Auto Archival** rules and reminders to control when content is archived.

When you update an existing content item, Content Centre creates a new version.

## Use the Content Centre Dashboard

The **Content Centre Dashboard** shows an overview of the content in Content Centre. It includes content usage, views, references, lifecycle stages, and business-unit usage.

Content Centre items can be used across SmartWinnr modules such as **SmartFeed, K-Hub, and SCORM courses**, as well as other supported learning and content experiences.

The dashboard shows where content is referenced and provides details such as **file type, folder, references, views, creator, and content age**.
