> **At a glance** - Content versioning lets you update an existing content item without replacing the live version right away. The new version goes through review and publishing before it becomes live.Content versioning keeps one content item current over time. 

When you update an existing item, Content Centre creates a new version and keeps the current live version available until the new one is published.
Use this when you need to update content that is already in use across SmartFeed, SmartPath, KHub, or other modules. It helps you keep the same content item, the same content code, and the same references while moving to an updated version.

## When to use this

Use content versioning when you want to:

- Update an existing content item instead of creating a separate one.
- Keep content that is already referenced in SmartFeed, SmartPath, KHub, or another module.
- Review and approve updated content before it becomes live.
- Manage content that changes over time, such as product information or approved documents.


### 1. Update the existing item
Open the existing content item and upload the updated file. Content Centre creates a new version for that item.

The content code stays the same. The title also stays the same unless you change it.

### 2. Review the new version
The new version does not become live immediately. It follows the same lifecycle as other content, including Draft, In Review, Approved, Published, and Archived.

Use the review and approval process to prepare the new version before publishing it.

For a detailed explanation of each lifecycle stage, refer to **[Understanding the content lifecycle stages](https://help.smartwinnr.com/modules/content-center/features/understanding-the-content-lifecycle-stages)**.

### 3. Check available versions
When more than one version exists, use the version dropdown on the content item to switch between versions.

The dropdown helps you identify the version that is live and the versions that are still in review. The live version is marked **Live**.

### 4. Publish the new version
After review and approval, publish the new version. The newly published version becomes the live version.

Existing references in modules such as SmartFeed and SmartPath use the new live version automatically.

For detailed steps on updating a content item and creating a new version, refer to **[Learn how to update a content item and create a new version](https://help.smartwinnr.com/modules/content-center/create-and-manage/how-to-update-a-content-item-and-create-a-new-version/)**.


## Things to know

## Note
* While a new version is in review, learners and modules continue to use the current live version.
* Updating an item does not create a separate content item. It creates a new version of the same item.
* When a new version is published, the auto-archival clock starts again for that version.
* The same content item can stay referenced in multiple places. Those references use the latest published version automatically.
