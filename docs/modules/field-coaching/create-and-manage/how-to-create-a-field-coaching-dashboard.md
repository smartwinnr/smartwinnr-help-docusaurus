Open the Field Coaching Dashboard to review coaching activity in one place. Use it to track session completion, compare manager participation, and analyze competency results. You can also download a Participation Report for offline review.

## When to use this

Use the dashboard when you need a single view of field-coaching performance.

- Review completion trends across coaching sessions.
- Compare participation by manager.
- Analyze final scores and competency patterns.
- Check self-assessment gaps across coaching activity.
- Export participation data for further analysis.

## Steps

### 1. Open the dashboard
Select **Field Coaching** from the left menu, then open **Field Coaching Dashboard**.

If the dashboard is not visible, contact SmartWinnr support.

![Open Field Coaching Dashboard from the left menu](<image url>)

### 2. Review the dashboard tabs
Use the **Participation**, **Manager View**, and **Competency Analysis** tabs to switch between reporting views.

The dashboard brings completion trends, manager participation, competency heatmaps, competency snapshots, and self-assessment gap analysis into one place.

### 3. Filter the data
Use the available filters to narrow the results by date range, coaching form, division, sub-division, group, or metatags.

Filtering helps you focus on a specific team, time period, or coaching program.

### 4. Download the Participation Report
On the **Participation** tab, select **Download Report** to export the Participation Report as an Excel file.

Use the file to share participation data or review it outside SmartWinnr.

## Things to know

:::note
The dashboard shows reporting data only after the relevant coaching activity is available in the system.
:::
