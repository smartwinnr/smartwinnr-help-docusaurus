> **At a glance** - Only users with ADMIN roles can create field coaching templates. Follow the steps below to create a new field coaching template.

Only users with ADMIN roles can create field coaching templates. If you have the privilege to create field coaching templates, you will see the link **Templates** under the **Field Coaching** setting in the **Admin** section of your left menu. Follow the steps below to create a new field coaching template.

## When to use this
Use this feature when you need to create a structured coaching framework for your team. This allows you to assess and improve individual performance through tailored coaching sessions.

- When onboarding new team members.
- To enhance the skills of existing employees.
- For performance evaluations and feedback sessions.
- To standardize coaching practices across your organization.

## Before you start
Ensure you have ADMIN privileges to access the field coaching template creation feature.

## Steps

### 1. Click on "Create New Template" at the right corner
By clicking on it, you will see the first step of the process shown below.

![By clicking on it, you will see the first step of the process shown below.](/img/helpscout/admins/how-to-create-field-coaching-template-1.jpg)

Enter the title and fill in the description with the details of the field coaching template, then click on the **Save** icon below.

### 2. Add the rating on which you want to score the user
This is the second step, as shown in the picture below.

![This is the second step as shown in the picture below.](/img/helpscout/admins/how-to-create-field-coaching-template-2.jpg)

**Evaluate Baseline:** This allows the manager to assess the competencies on which the user proceeds with coaching.

**Evaluate Strength Weakness:** Based on the strengths and weaknesses of the user, the manager can assess them on different competencies.

Fill in the rating description, add the rating, and also mention their description, then click on the **Save** icon below.

### 3. Select the competencies and add the Individual Rating Descriptors
In this step, first, you need to select the competencies and add the description for rating individually, as shown below.

![In this step first, you need to select the competencies and add the description for rating individually as shown below.](/img/helpscout/admins/how-to-create-field-coaching-template-3.jpg)

After filling in the description, click on the **Save** icon in the right corner.

### 4. Create the coaching section
Fill in the section name and description, and select all the necessary options by clicking on them, as shown below.

![Fill up the section name and description and select all the necessary options by clicking on it as shown below.](/img/helpscout/admins/how-to-create-field-coaching-template-4.jpg)

You can select who can see the results by clicking on the **Visible to** option. Also, you can add a field according to the number of steps you have and want to analyze.

**Section visible to:** This section selects whom we want to see the section. Example: Coach.

**Section Visible in steps:** This section selects the steps that can be visible for the selected category.

**Allow Tab Creation:** This allows the user and manager to add their comments after the coaching is finished.

**Tab Create By:** This section allows the coach or coaches to add their comments based on the section of the coaching.

**Tab Create in steps:** This tab allows us to choose which step we want to make visible.

**Field type:** This tab allows us to select the type of section where the user or manager can enter their comments. You have the option to create the following types of fields:

1. **Text:** User/Managers can add text input.
2. **Textarea:** User/Manager can add text input if they have more text to add.
3. **Number:** User/Manager can input numbers.
4. **Date:** User/Managers can input dates.
5. **Single Select:** Users/Managers can select one value from the dropdown.
6. **Show Image:** Users/Managers can submit images.
7. **Checkbox List:** Users/Managers can select multiple values from the list of values.
8. **Rich Text:** Users/Managers can submit different types of values in the same field.

**Display Name:** This allows you to enter the name that can be displayed.

**Placeholder:** This acts as an indicator to show what you need to type in the display name. Example: Enter your name.

**Visible to:** Here you can select the visibility of the step to the coach or coachee.

**Visible in Steps:** This tab allows us to choose in which step we want to make visible.

**Editable by:** Here you can choose any user who can edit this field.

**Editable Steps:** Select the steps in which the field should be available to edit.

After adding all the necessary fields, click on the **Save** icon below. The Field Coaching Template is now created.
