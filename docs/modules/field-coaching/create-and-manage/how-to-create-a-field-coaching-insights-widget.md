> **At a glance** - Add a coaching insights widget to a dashboard to show a written summary for the selected coaching form. Use it to see what needs attention first and what to do next.

Use this widget when you want a coaching dashboard to show more than numbers. It turns the selected form's insights into a headline, a summary paragraph, and attention items with next steps. Managers can review the current period and move through earlier periods from the widget itself.

## When to use this

Use the coaching insights widget when you want a quick read on team coaching performance.

- You want a written summary, not just metrics.
- You want to see overdue reps, weak competencies, strong competencies, and reps on the rise.
- You want each insight to include a recommended next step.
- You want managers to move through periods from the dashboard.

## Steps

### 1. Open the dashboard designer
Open **Dashboard Designer** and go to **Insight Widgets**. Find the widget type **Field coaching: insights**.

### 2. Add the widget to your dashboard
Add the widget to a field coaching manager dashboard that includes a **Coaching Form** filter.

### 3. Choose what the widget shows
In the widget editor, turn **Show the summary paragraph** on or off. Set **Items shown before View All** to control how many items appear before **View All**.

### 4. Review insights in the app
Open the dashboard in the mobile app. Use the arrows in the widget header to move between periods for the selected coaching form.

## Things to know

:::note
The widget only shows insights for the coaching form selected on the dashboard.
:::

:::note
If the widget is missing, contact SmartWinnr support.
:::

:::caution
Older app versions show a prompt to update the app before you can use this widget.
:::
