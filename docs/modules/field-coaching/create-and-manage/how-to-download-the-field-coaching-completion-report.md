> **At a glance** - Learn how to download different types of field coaching completion reports for analysis and tracking.

You can download field coaching completion reports to track coaching sessions and user progress. The reports include counts of sessions, detailed information for each user, and options for CSV formats.

## When to use this

Use this feature when you need to analyze coaching effectiveness or track user engagement. You might need to:

- Review coaching sessions for specific managers.
- Analyze user performance across different coaching sessions.
- Generate reports for compliance or performance reviews.

## Steps

### 1. Log in to Editor account and navigate to the report section

Log in to your Editor Account. In the left menu, go to **Field Coaching → Completion Report**. This takes you to the report selection page.

![Select completion report under field coaching](/img/helpscout/authored/how-to-download-the-field-coaching-completion-report-mruph9j6.png)

### 2. Select report parameters

On the report selection page, choose the **Field Coaching**, **Manager** (if applicable), **Frequency of Coaching**, and **Date Range** for the reports you want to download. After selecting the options, click on the **Hamburger Menu** to view the available reports.

![Download the completion report](/img/helpscout/authored/how-to-download-the-field-coaching-completion-report-mruphxhi.png)

### 3. Download Count Report

To download the count of coaching sessions created under each manager, click on **Download Count Report**.

![Download Count Report](/img/helpscout/authored/how-to-download-the-field-coaching-completion-report-mrupiot0.png)
A pop-up will appear; select **YES** to confirm the download.

![confirmation pop up](/img/helpscout/authored/how-to-download-the-field-coaching-completion-report-mrupjfls.png)

A sticky note will appear at the top, indicating that the report is generated. Go to the **Generated Report Section** to download it.

### 4. Download Detailed Report

For a complete overview of coaching sessions for each user, click on **Download Detailed Report**.

![Download Detailed Report](/img/helpscout/authored/how-to-download-the-field-coaching-completion-report-mrupk1op.png)

A confirmation pop-up will appear with an option to **Include Not Started Users As well**. Uncheck this if you do not want to include those sessions. Click **YES** to download the report.

![Confirmation pop up](/img/helpscout/authored/how-to-download-the-field-coaching-completion-report-mrupkl91.png)

### 5. Download Report As CSV

To download the detailed report in CSV format, click on **Download Report As CSV**.

![Download Report As CSV](/img/helpscout/authored/how-to-download-the-field-coaching-completion-report-mrupl1l8.png)

### 6. Download Combined Report as CSV

For a comprehensive view of all coaching sessions for all users, click on **Download Combined Report as CSV**.

![Download Combined Report as CSV](/img/helpscout/authored/how-to-download-the-field-coaching-completion-report-mruplezn.png)

A pop-up will prompt you to select the required checkbox. Click **YES** to proceed.

![Confirmation pop up](/img/helpscout/authored/how-to-download-the-field-coaching-completion-report-mrupmpil.png)

A sticky note will indicate that the report is generated. Go to the **Generated Report Section** to download it.

### 7. Overall Assessment Report

Click on the Overall Assesment Report to see the average ratings given for the competencis in the field coaching.

![Overall Assessment Report](/img/helpscout/authored/how-to-download-the-field-coaching-completion-report-mruvqlr3.png)

Click on the **Download Report** to download the report with these details.

## Tips

- Always check the date range to ensure you are downloading the correct data.
- Use the combined report for a holistic view of all coaching sessions.
- Keep an eye on the sticky notes for updates on report generation status.
