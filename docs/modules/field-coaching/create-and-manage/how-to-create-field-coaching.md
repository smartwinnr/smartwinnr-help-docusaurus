> **At a glance** - Follow these steps to create field coaching in SmartWinnr, ensuring that you have the necessary editor role.

Only the user with the editor role can create field coaching. Follow the steps below to set up your field coaching in the SmartWinnr account.

## When to use this
Use this guide when you need to create field coaching for your organization. This process is essential for setting up coaching sessions that facilitate performance tracking and development.

## Steps

### 1. Select the left menu
Go to **Editor** > **Field Coaching** > **Templates**. You need to select the template first to create the field coaching. After selecting the template, click on the **Create Coaching** icon in the top right corner.

![Select Create Coaching](/img/helpscout/authored/how-to-create-field-coaching-mswytt6c.png)

### 2. Fill in the coaching details
Fill in the title and description with the details of the coaching and select the time period for which you want to enable the field coaching.

![Fill in the title and description with the details of the coaching and select the time period for which you want to enable the Field Coaching](/img/helpscout/editors/how-to-create-field-coaching-1.jpg)

Select the **Start Date** and **End Date** of the coaching.

### 3. Configure settings options
Select the required settings options based on the requirements of the coaching. The settings options are explained below.

![Field coaching settings](/img/helpscout/authored/how-to-create-field-coaching-msyi07m3.png)

- **Grace Period**: After ending the frequency of coaching, if the coaches/coachees want to fill the field coaching, you can provide that option by adding the number of days/weeks/months they want access to the previous session. For example, if the coaching is monthly and after finishing one month, the coachees/coaches need to submit the coaching in the first 5 days of the following month, then select "Unit" 5 and "Select Metric" Days. They can then submit the coaching in the 5 days of the following month.

- **Enable Ad Hoc Sessions**: Enable this if users want to submit multiple sessions of the coaching in the same frequency.

- **Enable Inline Ratings**: Enable this if the coaching session has rating competencies to be filled by the coaches.

- **Coaching without Ratings**: Enable this if the coaching does not have any rating competencies and only input fields to show to the users.

- **Self Assessment**: Enable this if both coach and coachee want to rate the competencies.

- **Enable Session Duplication**: This allows users to duplicate an already filled session, so all the data gets duplicated from the old session to the new session, with the status stored as not_completed.

- **Enable Coaching Date**: This allows users/coaches to set a date for each session while submitting the session.

- **Allow Future Date / Allow Past Date**: This lets users choose a future or past date in the coaching date field in the session.

- **Only Coach Decides Coaching Date**: Restrict the coaching date to be decided only by the coaches.

- **Allow Any Manager To Coach**: This allows any manager from the organization to submit the coaching for a particular user.

- **Allow 1st or 2nd Line Managers To Coach**: Allow both first-line and second-line managers to submit coaching for a reportee in their hierarchy.

- **Allow Immediate Manager To Coach**: This allows only the immediate manager to coach the user.

- **Enable Acknowledgement**: Enable this if you want to enable the acknowledgement feature.

- **Enable Scoring in Fields**: This allows the creation of fields with scores associated with them.

- **Coachee Acknowledgement After Completion**: Allows the coachee to acknowledge completion.

- **Send Email to Coach After Completion**: Sends a completion email to the coach when the coaching is completed.

- **Show Average Rating**: Displays the average of ratings.

- **Acknowledgement Text**: Define the acknowledgement text here.

![External Email](/img/helpscout/authored/how-to-create-field-coaching-msyl2bxc.png)

If you want to notify external coaches, you can add their details in the above text boxes.

![Visibility Settings](/img/helpscout/authored/how-to-create-field-coaching-msyl7m7n.png)

Select the visibility settings, which help you set the "Coaching Date," "Ratings," and "Competencies as dropdown" in either the top or bottom of the coaching session page.

After filling in all the required segments, click on the **Save** icon. This will directly take you to the fifth page of the coaching setup.

### 4. Select users and coaches
In this final step, add the users and their coaches to check their performance.

![Step 5: Select the users and their coaches to check their performance](/img/helpscout/editors/how-to-create-field-coaching-5.jpg)

By doing this, you create a brand new field coaching program.
