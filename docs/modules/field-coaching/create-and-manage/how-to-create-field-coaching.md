Only the user with editor role can create a field coaching

Follow the below steps to create your field coaching to the SmartWinnr account.

## Step 1: Select the left menu>>Go to Editor>>Field Coaching >>Templates

You need to select the template first so that you can create the field coaching. After selecting the template, you should click on the " Create Coaching " icon in the top right corner.

![Slect Create Coaching](/img/helpscout/authored/how-to-create-field-coaching-mswytt6c.png)

Fill up the title and description with the details of the coaching and select the time period for which you want to enable the Field Coaching.

![Fill up the title and description with the details of the coaching and select the time period for which you want to enable the Field Coachin](/img/helpscout/editors/how-to-create-field-coaching-1.jpg)

Select the Start Date and End Date of the coaching.

Select the required settings options as per the requirement of the coaching. Settings options are explained below.

![field coaching setting](/img/helpscout/authored/how-to-create-field-coaching-msyi07m3.png)

**Grace Period**: After ending the frequency of coaching, if the coaches/coachees want to fill the field coachings, we can give that option by adding number of days/weeks/months they want the access to the previous session. For example, the coaching is monthly coaching and after finishing 1 month, the coachees/coaches need to submit the coachings in the first 5 days of following month, then select "Unit" 5 and "Select Matric" Days. Then, they can submit the coaching in the 5 days of following month.

**Enable Ad Hoc Sessions**: Enable this if users want to submit multiple sessions of the coaching in the same freequency

**Enable Inline Ratings**: Enable if the coaching session has the rating competencies to be filled by the coaches.

**Coaching without Ratings**: Enable this if the coaching does not have any rating competencies and it has only input fields to show to the users.

**Self Assessment**: Enable this if the both coach/coachee want to rate the competencies.

**Only Coach Decides Coaching Date?** If you want to restrict the coaching date to be decided by the coaches.

**Allow Any Manager To Coach**: This allows any manager from that org to submit the coaching for a particular user.

**Allow 1st or 2nd Line Managers To Coach**: If both first line and second line managers needs to be submitted the coaching for a reportee in their hierarchy.

** Allow Immediate Manager To Coach**: this will allow on the immediate manager to coach for the user.

** Enable Acknowledgement**: If you want to enable 
Enable scoring in fields
Coachee Acknowledgement After Completion?
Send Email to coach After Completion
Show Average Rating

After filling up all the required segments, click on the "Save" icon.
