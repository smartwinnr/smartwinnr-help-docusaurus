> **At a glance** - This article explains how to activate automatic reminders for your quizzes, allowing you to schedule notifications for quiz takers.

The automated reminder feature allows you to create and schedule reminders to be delivered to quiz takers about their assigned quizzes. Below are the steps to set a reminder for a quiz:

## When to use this

Use this feature when you want to ensure quiz takers receive timely reminders about their quizzes. This is particularly useful for:

- Keeping participants engaged and informed.
- Reducing the number of incomplete quizzes.
- Enhancing overall quiz completion rates.

## Steps

### 1. Go to the quiz creation section

Navigate to **EDITOR > LEARNING AND KNOWLEDGE > Questions and Quizzes > View All Quizzes > Add New Quiz**.

![Go to EDITOR > LEARNING AND KNOWLEDGE > Questions and Quizzes > View All Quizzes > Add New Quiz.](/img/helpscout/editors/how-to-activate-automatic-reminders-for-your-quizzes-1.png)

### 2. Fill in quiz details

Once you fill in all the details for creating the quiz, navigate to the last section, which is **Schedule Reminder**.

![Once you fill all the details for creating the quiz, navigate to the last section which is "Schedule Reminder".](/img/helpscout/editors/how-to-activate-automatic-reminders-for-your-quizzes-2.png)

### 3. Set reminders for existing quizzes

You can also schedule a reminder for an already created quiz. Follow the steps below to set a reminder for an existing quiz:

Go to **EDITOR > LEARNING AND KNOWLEDGE > Questions and Quizzes > View All Quizzes**. Click on a particular quiz from the list of all the created quizzes to which you want to add the reminder.

![EDITOR > LEARNING AND KNOWLEDGE > Questions and Quizzes > View All Quizzes. Click on a particular quiz from the list of all the created quiz](/img/helpscout/editors/how-to-activate-automatic-reminders-for-your-quizzes-3.png)

### 4. Edit the selected quiz

It opens the following page:

![It opens the following page](/img/helpscout/editors/how-to-activate-automatic-reminders-for-your-quizzes-4.png)

Now, click on the **Edit** button at the top right corner. Navigate to the last section, which is **Schedule Reminder**.

### 5. Add a new reminder

Click on the **Add** button at the top right corner of the **Schedule Reminder** section. It will open the following popup.

![Click on the "Add" button at the top right corner of the Schedule Reminder section. It will open the following popup.](/img/helpscout/editors/how-to-activate-automatic-reminders-for-your-quizzes-5.png)

### 6. Configure reminder settings

In the popup, fill in the following fields:

- **Send Type:** Decide if you want to send the reminder on a specific date or if you want to send it depending on the end date of the quiz.
- **Date to send:** Select the date and time when you want to send the reminder.
- **Send before end (In Days):** If you select "**Depends on Quiz End Date**," then you will see this field. Enter the number of days before the end date of the quiz when you want to send the reminder.
- **Send To:** Choose to send it to "**Everyone**" or a "**Group**."
- **Filter By:** Filter the quiz takers to whom you want to send the reminder. There are three options to choose from: "All," "Completed," or "Not Completed."
- **Teams:** If you selected "Group" in the **Send To** field, select the teams to whom you want to send the reminder.
- **Message:** This will display the message that will be sent in the reminder. This field will have an auto-generated message, but you can change it according to your requirements.

### 7. Save the reminder

Once you have filled in all these fields for the reminder, click on the **Save** button. This will add the reminder successfully to the quiz.

### 8. Finalize the quiz

After filling in all the details on this page, click on the **Save and Add Questions** button to save the quiz.
