> **At a glance** - Learn to add translations to quiz questions efficiently by downloading, updating, and uploading a CSV template.

You can add translations to your quiz questions in bulk by using a CSV template. This process involves exporting your questions, updating them with translations, and then importing the updated file back into the system.

## When to use this

Use this feature when you need to:

- Translate a large number of quiz questions into different languages.
- Ensure consistency across translations for better learner experience.
- Save time by bulk updating translations instead of editing each question individually.

## Steps

### 1. Export Questions

To add translations in bulk, start by downloading the questions. Click on **Export Questions** from the hamburger menu.

![Download the questions](/img/helpscout/authored/authored-mrvvbn8p.png)

### 2. Select Language

You will be prompted to select the language of the questions. Choose the desired language to include in your report. Click on the **Download** button to download the report.

![Select languages](/img/helpscout/authored/authored-mrvvc92z.png)

### 3. Review Question IDs

The downloaded report will include the question IDs. Use these IDs to add translations.

![Questions with IDs](/img/helpscout/authored/authored-mrvvcjzz.png)

### 4. Download Question Template

Next, download the question template for adding translations. Click on **Import Questions**.

![Import Questions](/img/helpscout/authored/authored-mrvvdadx.png)

### 5. Download Template

Click on the **Download Template** button to get the CSV template.

![Download Question Template](/img/helpscout/authored/authored-mrvvdqst.png)

### 6. Update the Template

Open the template and add the Question ID column. Enter the translations for each question in the required language. A sample template is provided for reference.

![Update the template](/img/helpscout/authored/how-to-add-translations-to-questions-in-bulk-mrvvtnvr.png)

### 7. Upload the Updated CSV

Select the updated file and click on the **Upload** button to import it into the system.

![Upload the CSV to the system](/img/helpscout/authored/authored-mrvvhegi.png)

### 8. Verify Translations

After uploading, the questions will display the added translations. Check to ensure everything is correct.

![Question after adding the translations](/img/helpscout/authored/authored-mrvvq344.png)
