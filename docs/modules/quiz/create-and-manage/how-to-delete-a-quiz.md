> **At a glance** - Deleting a quiz in SmartWinnr is straightforward but irreversible. Follow these steps to ensure you do it correctly.

You can delete any quiz you have created in SmartWinnr. However, be cautious, as this action will permanently remove all associated data if users have already taken the quiz.

## When to use this

Use this feature when you need to remove a quiz that is no longer relevant or necessary. Consider deleting a quiz in the following situations:

- The quiz contains outdated questions.
- You want to clean up your quiz list.
- The quiz was created by mistake.

## Steps

### 1. Select the quiz

From the quiz list, choose the quiz you want to delete.

![Select Quiz](/img/helpscout/authored/authored-mrvwwkf6.png)

### 2. Click on the delete option

Open the **Hamburger menu** and select the **Delete** option.

![Select Delete option](/img/helpscout/authored/authored-mrvwwun8.png)

### 3. Confirm deletion

A confirmation pop-up will appear. If the quiz has been taken by users, all related data will be lost. Click **YES** to proceed with the deletion.

![Confirmation Pop-up](/img/helpscout/authored/authored-mrvwx5k9.png)

## Tips

- Always double-check if the quiz has been taken before deleting it to avoid losing valuable data.
- Consider archiving the quiz instead of deleting if you might need it later.
