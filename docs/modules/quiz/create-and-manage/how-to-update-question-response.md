> **At a glance** - SmartWinnr allows editors to update or correct user responses in quizzes, automatically recalculating scores and updating analytics.

SmartWinnr enables editors to update or correct a user’s response in a quiz. When a response is modified, the system automatically recalculates the score and updates the revised results across all related analytics and reports.

## When to use this

Use this feature when you need to correct a user's answer in a quiz to ensure accurate scoring and reporting. This may be necessary in the following situations:

- A user selected the wrong answer by mistake.
- You need to adjust a response based on new information.
- You want to ensure the accuracy of quiz results for reporting purposes.

## Steps

### 1. Navigate to Questions and Quizzes

Go to **Editor > Questions and Quizzes**.

### 2. Access Quiz Analytics

Click on **Analytics** for the relevant quiz.

![You will be redirected to the quiz analytics page.](/img/helpscout/editors/how-to-update-question-response-1.png)

### 3. Select User for Update

Scroll down to the bottom and click on the analytics icon next to the user whose response you wish to update.

![Scroll down to the bottom and click on analytics icon towards the user you wish to update the response.](/img/helpscout/editors/how-to-update-question-response-2.png)

### 4. Change User Response

Click on "**Change Response**" next to the user response you want to modify.

![Click on "Change Response" against the user response where you want to make the change](/img/helpscout/editors/how-to-update-question-response-3.png)

### 5. Update and Save Response

Update the current response and click on "**Save**."

![Update the current response and click on "Save"](/img/helpscout/editors/how-to-update-question-response-4.png)

### 6. Confirmation of Update

The response will be updated successfully, along with the recalculated score.

![Then the response will be updated successfully along with the score as given below.](/img/helpscout/editors/how-to-update-question-response-5.jpg)
