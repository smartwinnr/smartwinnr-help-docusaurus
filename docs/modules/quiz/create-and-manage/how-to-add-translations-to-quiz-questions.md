> **At a glance** - Learn how to efficiently add translations to quiz questions.

You can enhance your quiz questions by adding translations. This feature allows you to cater to a multilingual audience, ensuring that all learners can understand the content.

## When to use this

Use this feature when you need to:

- Create quizzes for a diverse audience speaking different languages.
- Update existing quiz questions with translations.
- Improve accessibility and comprehension for learners.

## Steps

### 1. Edit the Question

Click the **Edit** button next to the question you want to translate.

![Edit the Question](/img/helpscout/authored/authored-mrvqpyws.png)

### 2. Add Translation

Click the **Add Translation** button to begin adding translations.

![Add Tranlstion](/img/helpscout/authored/authored-mrvqwy3w.png)

### 3. Select the Language

Choose the languages for which you want to add translations and click **Save**.

![Select the laguage](/img/helpscout/authored/authored-mrvqzev1.png)

### 4. Add the Translations

You will see the added language and a space to input the translations. Add translations for all answer options as well.

![Add the tanslations](/img/helpscout/authored/authored-mrvrqsy3.png)

### 5. Click on the Update Button

After adding all translations, click the **Update** button to save your changes.

![Click on the Update button](/img/helpscout/authored/authored-mrvrrh2e.png)
