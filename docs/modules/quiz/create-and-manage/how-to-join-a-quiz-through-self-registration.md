> **At a glance** - Learn how to join quizzes that allow self-registration and how to find them.

Quizzes can allow learners to register themselves, providing flexibility in accessing content. This article explains how to find quizzes open for self-registration, how to opt in, and what happens after joining. Only quizzes that the editor has opened for self-registration will appear for you.

## When to use this
Use self-registration when you want to join quizzes without waiting for an assignment. This is useful in scenarios such as:
- You want immediate access to a quiz.
- You are looking for quizzes available for self-enrollment.
- You prefer to manage your learning path actively.

## Steps

### 1. Find quizzes open for self-registration
Look for quizzes that allow self-registration. These will be marked accordingly by your editor.

![allow self registration](/img/helpscout/authored/authored-mtmusy1v.png)

### 2. Opt in to the quiz
If the editor shared a link with you, this allows you to participate without waiting for an assignment. This link will directly redirect you to that particular quiz. If you are not logged into SmartWinnr, the login page will appear, and once you complete the login, you will be directed to the corresponding quiz.

![where we can copy quiz link](/img/helpscout/authored/authored-mtmv1cdt.png)

## Tips
- Check your LMS settings to enable automatic assignment for quizzes accessed via the platform.
- Self-registration eliminates the need for pre-registration, making access smoother.
- Ensure you complete any prerequisites for module completion to access quizzes.

## Things to know
:::caution
Only quizzes specifically opened for self-registration will be visible to you.
:::
