> **At a glance** - Add audio files to questions or feedback to enhance the learning experience.

You can add an audio file to a question or feedback. This audio file needs to be available on your local computer.

## When to use this
Use this feature when you want to:
- Enhance questions with audio instructions or content.
- Provide audio feedback to learners.
- Make your quizzes more engaging and accessible.

## Steps

### 1. Click on the audio icon
Click on the **audio icon** in the question or feedback box:

![describe this screenshot](/img/helpscout/authored/how-to-add-an-audio-file-to-a-question-mt40dc42.png)

### 2. Choose your audio file
This will open the following popup:

![This will open the following popup:](/img/helpscout/editors/how-to-add-an-audio-file-to-a-question-2.png)

Click on the **Choose File** button to select an audio file from your local file system and click **Open**. Then choose the **Submit** button. The selected audio file will be added to the question or feedback. This will appear in the SmartWinnr mobile app, where the participant will be able to play the audio file.

![Click on the ‘Choose File’ button](/img/helpscout/editors/how-to-add-an-audio-file-to-a-question-3.png)

### 3. Confirm the addition
The selected audio will get added to the question or feedback.
