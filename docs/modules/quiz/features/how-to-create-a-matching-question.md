> **At a glance** - A matching question allows participants to pair items from one list with corresponding items in another list, enhancing assessment of relationships.

A matching question enables participants to correctly pair items from one list with corresponding items in a second list. This format is ideal for assessing understanding of relationships such as terms and definitions, products and features, or concepts and descriptions.

## When to use this
Use a matching question when you want to:
- Assess knowledge of relationships between items.
- Increase the difficulty of a quiz by adding distractors.
- Require participants to demonstrate understanding through pairing.

## Before you start
Ensure you have the necessary permissions to create questions in the quiz module.

## Steps

### 1. Navigate to the Question Bank
Go to **EDITOR > LEARNING AND KNOWLEDGE > Questions and Quizzes > Question Bank**.

### 2. Add a New Question
Click on the **'Add New Question'** button at the top right corner.

![Click on the 'Add New Question' button at the top right corner.](/img/helpscout/editors/how-to-create-multiple-choice-questions-1.png)

### 3. Select Question Type and Scoring method
On the Create New Question page, select Matching as the Question Type. Then choose the required scoring type:

**Default Scoring**: The user receives the total points only if all pairs are matched correctly.
**Partial Scoring**: The user receives points for each correctly matched pair.

Example: If there are 5 answer pairs and the total score is 10 points:

With Default Scoring, the user gets 10 points only if all 5 pairs are matched correctly.
With Partial Scoring, each correct pair is worth 2 points. So, if the user matches 2 pairs correctly, they receive 4 points.

![Select the 'Question Type' as ‘Matching’.](/img/helpscout/editors/how-to-create-a-matching-question-1.png)

### 4. Enter Your Question
Input your question in the **‘Question’** field.

![Enter the question text](/img/helpscout/authored/how-to-create-a-matching-question-mt3wyrpk.png)

### 5. Add Answer Options
Add items to the left-hand side as answer options (text, image, video, or audio). Check the **Rich Text** box to include multimedia. Add matching elements on the right-hand side. Use **Distractors** to increase difficulty by adding extra options.

Click on the **Add Pair** option to include more answer options. Click on **Add Distractors** to add more distractors.

![Answer options](/img/helpscout/authored/how-to-create-a-matching-question-mt3we50i.png)

### 6. Set Points
Enter the total score for the question.

![The total score for the question should be added here.](/img/helpscout/editors/how-to-create-multiple-choice-questions-9.png)

### 7. Provide Feedback
Use the feedback section to give additional information or clarification related to the question. This feedback appears to learners after they complete the quiz. **Correct answer feedback** is shown for correct responses, while **incorrect answer feedback** is displayed for wrong responses.

![Feedback section](/img/helpscout/editors/how-to-create-multiple-choice-questions-10.png)

### 8. Select Categories
Assign at least one knowledge category to the question. This helps classify and organize content for tracking and analytics. You can associate multiple relevant categories.

![Assign knowledge categories](/img/helpscout/editors/how-to-create-a-matching-question-3.png)

### 9. Save the Question
Once you have filled in all required details, click on the **'Save New Question'** button to save the question.


## Additional Match Possibilities (Distractors)
**Distractors** allow you to include additional answer options that appear on the right-hand side. This feature is useful when there are only a few matching pairs and you want to increase the difficulty by requiring more careful selection from participants.

## Additional Features

### Videos
You can pose a question through a video. Choose videos of products, demonstrations, or customer feedback. Click on the video icon to add your own videos or those from YouTube, Box, and Brainshark.

[Learn how to add different videos to a question](/modules/quiz/features/how-to-add-a-video-to-a-question)

### Images
Add images by clicking on the image icon and selecting files from your computer.

[Learn how to add an image to the question](/modules/quiz/features/how-to-add-an-image-to-the-question)

### Links
Insert links by clicking on the links icon.

Include audio files by clicking on the audio icon.

### Change Language
You can change the language of the question by clicking on the **"Change Language"** button at the top right corner. Select the desired language and click **Save**.

![Change Language](/img/helpscout/editors/how-to-create-a-matching-question-4.png)

## How do participants see the question?
Once the matching question is created and shared with participants, it will appear on their mobile application in an interactive format. The right-hand options are displayed as drop-down menus, which remain consistent across all items. A response is considered correct only when the participant selects the correct match for all items. Partial responses do not receive any marks.

![Question from user view](/img/helpscout/authored/how-to-create-a-matching-question-mt3wfy9p.png)
