> **At a glance** - This article explains how to create a Drag and Drop into Image Question, allowing participants to interactively place answers on an image.

A Drag and Drop into Image Question allows participants to drag and drop the correct answer to the given image.

## When to use this
Use a Drag and Drop into Image Question when you want to:
- Engage participants with interactive content.
- Assess knowledge visually by placing answers directly on an image.
- Create a more dynamic quiz experience.

## Steps

### 1. Go to the Question Bank
Navigate to **EDITOR > LEARNING AND KNOWLEDGE > Questions and Quizzes > Question Bank**.

### 2. Add a New Question
Click on the **Add New Question** button at the **top right corner**.

![Click on the 'Add New Question' button at the top right corner.](/img/helpscout/editors/how-to-create-a-missing-words-question-1.png)

### 3. Select Question Type
On the **Create new Question** screen, select the **Question Type** as **Drag and Drop into Image**.

![On the 'Create new Question' select the 'Question Type' as Drag and Drop into Image.](/img/helpscout/editors/how-to-create-a-drag-and-drop-into-image-question-1.png)

### 4. Enter the Question
Enter your question in the **Question** field.

![Enter your question in the ‘Question’ field.](/img/helpscout/editors/how-to-create-a-drag-and-drop-into-image-question-2.png)

### 5. Insert the Image
Insert the image you want to upload.

![Insert the Image you want to upload.](/img/helpscout/editors/how-to-create-a-drag-and-drop-into-image-question-3.png)

Once the image is added, it will be displayed as shown below. You can replace the image at any time by clicking the **Change Background Image** button.

![Once the image is added, it will be displayed as shown below. You can replace the image at any time by clicking the Change Background Image ](/img/helpscout/editors/how-to-create-a-drag-and-drop-into-image-question-4.png)

### 6. Enter Drag-and-Drop Options
Next, enter the **drag-and-drop options** and **distractors** in the corresponding text boxes, as shown in the image above. You can add additional options and distractors by clicking the **Add More** button. Once completed, the configuration will appear as shown below.

![Next, enter the drag-and-drop options and distractors in the corresponding text boxes, as shown in the image above. You can add additional o](/img/helpscout/editors/how-to-create-a-drag-and-drop-into-image-question-5.png)

### 7. Position the Options
Now, drag and drop the options to the correct place in the image as given below.

![Now, drag and drop the options to the correct place in the image as given below.](/img/helpscout/editors/how-to-create-a-drag-and-drop-into-image-question-6.png)

You can add as many distractors as you would like.

### 8. Set Points
The total score for the question should be added here.

![Points](/img/helpscout/editors/how-to-create-multiple-choice-questions-9.png)

Select the **Shuffle Last Option** checkbox to randomize the position of the last answer option in the question.

### 9. Add Correct Answer Feedback
Use **Correct Answer Feedback** if you want to add additional information to a question. (Optional)

![Use ‘Correct Answer Feedback’ if you want to add additional information to a question. (Optional)](/img/helpscout/editors/how-to-create-a-missing-words-question-8.png)

### 10. Include Reviewer Notes
You can add any additional feedback on the question or answer options.

![You can add any additional feedback on the question or answer options.](/img/helpscout/editors/how-to-create-a-missing-words-question-9.png)

### 11. Assign Categories
Every question must be assigned at least **one category**. Categories are predefined by your administrator. You may select multiple categories if applicable.

![Every question must be assigned at least one category. Categories are predefined by your administrator. You may select multiple categories i](/img/helpscout/editors/how-to-create-a-drag-and-drop-into-image-question-7.jpg)

### 12. Save the Question
Once you have filled in the required details of the question, click on the **Save New Question** button to save the question.
