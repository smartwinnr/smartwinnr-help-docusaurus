> **At a glance** - SmartWinnr allows editors to update quiz questions, correct answers, and marks after launch, depending on the quiz type and learner attempts. Question changes are allowed only before the first attempt, while correct answers and question marks can still be updated after launch. 

Use this when you need to adjust a quiz after it has been launched. The rules depend on the quiz type and on whether anyone has already attempted it.

- You want to correct an answer key after launch.
- You want to change marks for a question after users have responded.
- You want to edit, remove, or replace questions in a quiz.
- You need to know when question changes are locked.

## Manual quizzes

 **Updating Questions** - You can edit, remove, or replace questions only before any learner attempts the quiz. Once at least one learner has attempted it, the question set is locked.

**Updating Correct Answers** -
You can update the correct answer even after learners have attempted the quiz. However, the updated answer key will not automatically change the scores of learners who have already completed the quiz.

**Updating Question Scores** - 
To correct the scores of learners who have already attempted the quiz, the editor can manually update the scores for individual questions through Analytics.

## Automatic quizzes

**Updating Questions** - You can add new questions, remove or replace existing questions, and manage the question pool using tags only before any learner attempts the quiz. Once at least one learner has attempted it, the question set is locked.

**Updating Correct Answers** - You can update the correct answers even after learners have attempted the quiz. The updated answer key applies to both learners who have already attempted the quiz and those who have not attempted it yet.

**Updating Question Scores** - You can update the marks for individual questions after the quiz has been launched, regardless of whether learners have attempted the quiz or not.
## Things to know

:::warning
After a learner attempts a quiz, you cannot edit, remove, or replace questions in that quiz type if the question set is locked.
:::

:::note
Changing a correct answer can change existing scores. Review the updated results after you save the change.
:::
