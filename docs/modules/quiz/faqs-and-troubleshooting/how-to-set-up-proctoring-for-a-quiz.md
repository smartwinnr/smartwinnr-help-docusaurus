> **At a glance** - This article explains how to enable proctoring for quizzes to ensure assessment integrity.

You can set up proctoring for your quizzes to reduce the chances of malpractice and maintain a secure testing environment. Proctoring allows for webcam and screen monitoring during quiz attempts, which is essential for high-stakes assessments.

## When to use this
Use proctoring when you want to:
- Ensure the integrity of assessments.
- Monitor users during high-stakes quizzes.
- Provide a secure testing environment.

## Before you start
Ensure you have the necessary permissions to edit quiz settings.

## Steps

### 1. Access the quiz list
Go to **Editor > Learning and Knowledge > View All Quizzes** to see the list of created quizzes.

![quiz list page](/img/helpscout/authored/authored-mrx6gva5.png)

### 2. Open the quiz to enable proctoring
Select the quiz you want to enable proctoring for.

### 3. Enable proctoring settings
In the quiz settings, activate the remote proctoring feature. This ensures webcam and screen monitoring during quiz attempts.

![setting to enable](/img/helpscout/authored/authored-mrx6nl6s.png)

### 4. Save your changes
After enabling the settings, make sure to **Save** your changes.

### 5. User notification
Users will see a popup message with instructions informing them that proctoring is enabled. The message will state: "Kindly note that this is a proctored assessment, and images will be captured at random intervals during the test using your webcam or mobile camera. By proceeding, you consent to SmartWinnr capturing and securely storing your images and screenshots on the server for the duration of the assessment." Users must accept this notification before accessing the quiz.

![how user can see while starting proctoring quiz](/img/helpscout/authored/authored-mrx763fz.png)

## Tips
- Review the proctoring guidelines with users before they take the quiz.
- Test the proctoring setup with a sample quiz to ensure everything works smoothly.
- Keep an eye on any feedback from users regarding the proctoring experience.
