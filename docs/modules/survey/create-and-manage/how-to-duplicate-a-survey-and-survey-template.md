> **At a glance** - You can easily duplicate existing surveys in SmartWinnr to save time and effort when creating similar surveys for different audiences or periods.

SmartWinnr allows you to duplicate an existing survey so that you can reuse the structure, questions, logic, and settings without having to recreate everything from scratch. This feature helps save time when creating similar surveys for different audiences or periods.

> **Note:** Only Trainers or **EDITORS** with appropriate access permissions can duplicate surveys.

## When to use this
Use this feature when you need to create a new survey that is similar to an existing one. This is particularly useful for:

- Reusing survey structures for different events or periods.
- Modifying existing surveys for different audiences.
- Quickly setting up new surveys without starting from scratch.

## Steps

### 1. Access the Surveys Section
Go to **EDITOR > LEARNING AND KNOWLEDGE > Surveys**. Select any "Survey" that you want to duplicate.

![Go to EDITOR > LEARNING AND KNOWLEDGE > Surveys. Select any "Survey" that you want to duplicate.](/img/helpscout/editors/how-to-duplicate-a-survey-and-survey-template-1.png)

### 2. Open the Hamburger Menu
The following page will be displayed. Now select the hamburger menu located at the top right corner of the page.

![The following page will be displayed. Now select the hamburger menu located at the top right corner of the page.](/img/helpscout/editors/how-to-duplicate-a-survey-and-survey-template-2.png)

### 3. Select Duplicate
From the menu, select the **Duplicate** option.

![From the menu, select the Duplicate option.](/img/helpscout/editors/how-to-duplicate-a-survey-and-survey-template-3.png)

### 4. Confirm Duplication
Select **Yes** to create a duplicate copy of the selected survey.

![Select Yes to create a duplicate copy of the selected survey.](/img/helpscout/editors/how-to-duplicate-a-survey-and-survey-template-4.png)

### 5. Update the Duplicated Survey
Before saving the duplicated version:

- Rename the survey title to reflect its new purpose.
- Update the **description**, **start and end dates**, **visibility settings**, or any other relevant fields.
- Modify questions if needed to fit the new context.

### 6. Save the Duplicated Survey
Once all necessary updates are completed, click **Save** to save the duplicated survey.

![Once all necessary updates are completed, click Save to save the duplicated survey.](/img/helpscout/editors/how-to-duplicate-a-survey-and-survey-template-5.png)
