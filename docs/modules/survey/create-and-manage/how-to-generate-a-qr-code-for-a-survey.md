> **At a glance** - Create a QR code for your survey to make it easily accessible for users on mobile devices.

Generating a QR code for a survey allows users to quickly access and complete the survey via their mobile devices. This feature is especially useful for on-the-go responses, enhancing participation rates.

## When to use this

Use this feature when you want to:

- Make surveys easily accessible to users.
- Increase participation by allowing users to complete surveys on mobile devices.
- Share surveys quickly through QR codes.

## Steps

### 1. Log in to the SmartWinnr Admin Portal

Access your account to start creating a survey.

### 2. Navigate to Learning → Surveys

In the Admin Portal, go to the **Learning** section and select **Surveys**.

### 3. Click Add New Survey

Select **Add New Survey** in the top-right corner to begin.

### 4. Enable the QR Code Survey option

Turn on the **QR Code Survey** option to generate a QR code for your survey.

### 5. Add survey questions and create the survey

Input your survey questions and finalize the survey setup.

![How to create a QR code for a survey form](/img/helpscout/authored/authored-mrxb6lq5.png)

### 6. Share the QR code with users

Once the survey is created, the QR code will be generated. Share this code with users for easy access.

Users can scan the QR code with their mobile devices or iPads to be redirected directly to the survey, allowing for convenient completion.

## Tips

- Encourage users to scan the QR code by placing it in visible areas.
- Test the QR code yourself to ensure it directs to the correct survey before sharing it widely.
