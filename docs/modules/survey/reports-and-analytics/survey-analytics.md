> **At a glance** - Survey Analytics provides insights into user participation and feedback patterns, enabling you to evaluate survey results effectively.

Survey Analytics allows you to monitor and analyze responses collected from your surveys. This feature provides insights into user participation and feedback patterns, enabling you to evaluate results effectively.

## When to use this
Use Survey Analytics to:
- Gain insights into survey responses.
- Assess user participation levels.
- Identify trends and patterns in feedback.
- Evaluate the effectiveness of your surveys.

## Steps

### 1. Go to Surveys
Navigate to **EDITOR > LEARNING AND KNOWLEDGE > Surveys**.

![Go to EDITOR > LEARNING AND KNOWLEDGE > Surveys.](/img/helpscout/editors/survey-analytics-1.png)

### 2. Select Your Survey
Under the **My Surveys** section, select the survey type as **Survey**, which is located next to the Date Range.

![Under the 'My Surveys' section select Survey Type=Survey which is present very next to the Date Range.](/img/helpscout/editors/survey-analytics-2.png)

### 3. Access Analytics
Now under **Analytics**, click on the analytics icon next to the survey for which you want to view the analytics.

You will be taken to the following page, where the analytics of the selected survey is displayed.

![You will be taken to the following page, where the analytics of the selected survey is displayed.](/img/helpscout/editors/survey-analytics-3.png)

### 4. Filter By Response
There is separate analytics for dropdown and multi-select questions in the survey. Here you can filter by a particular dropdown/multi-select question and select one of the options to view the analytics.

![Filter By Response: There is separate analytics for Dropdown and Multi-select questions in Survey. Here you can filter with a particular Dro](/img/helpscout/editors/survey-analytics-4.png)

### 5. Review Graphs for Different Question Types
The following are the different types of graphs displayed for various question types in the survey.

#### 5.1 Single Select Question
The graph related to this question type is displayed using a pie chart, indicating the responses in different colors and the percentage of people who responded to each option.

#### 5.2 Multi-Select Question
The graph related to this question type is displayed using a bar graph. The question options are shown on the y-axis, and the percentage of users who responded is displayed on the x-axis, from a scale of 0 to 1 (where 0=0% and 1.0=100%).

![The graph related to this question type is displayed using a bar graph, the question options are displayed in the y-axis and the percentage ](/img/helpscout/editors/survey-analytics-6.png)

#### 5.3 Linear Scale Question
The graph related to this question type is displayed using a bar graph. The low to high scale value is shown on the x-axis, and the percentage of users who responded is displayed on the y-axis (where 0=0% and 1.0=100%).

![The graph related to this question type is displayed using a bar graph, from low to high scale value is shown in the x-axis, and the percent](/img/helpscout/editors/survey-analytics-7.png)

#### 5.4 Matrix Question
Matrix question graphs are useful for representing ratings. These are shown on the x-axis, while the y-axis consists of the options given for a particular category.

#### 5.6 Dropdown Question

### 6. Download Report

#### 6.1 User Wise Report
Click on the hamburger menu located in the top right corner. Now select the **User Wise Report**. The report will be downloaded as an Excel sheet.

![Click on the hamburger menu which is present on the top right corner. Now select the User Wise Report. The report will be downloaded as an e](/img/helpscout/editors/survey-analytics-11.png)

#### 6.2 Aggregate Report
This type of report consists of the survey question, responses, and the percentage of responses for each answer. Click on the **Download Report** button located in the right corner. The report will be downloaded as an Excel sheet.

![This type of report consists of the survey question, responses, and percentage of response for each answer.Click on the Download Report Butt](/img/helpscout/editors/survey-analytics-12.png)
