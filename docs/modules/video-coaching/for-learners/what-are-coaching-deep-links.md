***At a glance*** - Coaching provides **Copy Smart Link** and **Coaching Universal Link** options to share a Coaching activity with assigned users. These links help users access the Coaching activity from supported devices and experiences.

Coaching links let you share a Coaching activity with users. **Copy Smart Link** provides a device-aware link that directs users to the appropriate SmartWinnr experience based on their device and app availability. **Coaching Universal Link** provides a shareable link for accessing the Coaching activity it provides the access for everyone

## When to use this

Use Coaching links when you want to:

* Share a Coaching activity with assigned users.
* Use **Copy Smart Link** to provide a device-aware link that opens the appropriate SmartWinnr experience.
* Use the **Coaching Universal Link** to share a Coaching activity with users, including those who are not assigned to the activity.

* Allow users to access the activity from mobile or desktop.

## How Coaching links work

### Copy Smart Link

On the **Coaching View** page, click the **hamburger menu** in the top-right corner and select **Copy Smart Link** to copy the link.

Use **Copy Smart Link** to share the Coaching activity with users who are assigned to it.
![copy smart link](/img/helpscout/authored/what-are-coaching-deep-links-muax4q63.png)

When an assigned user opens the Smart Link:

* **Mobile + SmartWinnr app installed:** Opens the Coaching activity in the SmartWinnr app.
* **Mobile + app not installed:** Redirects the user to the appropriate app store.
* **Desktop/Laptop:** Opens the Coaching activity in the SmartWinnr web application.

### Coaching Universal Link

The **Coaching Universal Link** provides a shareable link to a Coaching activity. You can share this link with users who need to access the activity. **Anyone with the link can open the Coaching activity.**
