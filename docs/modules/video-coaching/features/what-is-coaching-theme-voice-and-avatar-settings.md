The coaching theme uses organization voice and avatar lists for its default male and female settings. You can pick from dropdowns that are narrowed by gender and show the provider and thumbnail. Zappy uses the same lists for AI personas, so your coaching and persona choices stay consistent.

## When to use this

Use these settings when you want coaching content to use approved voices and avatars from your organization.

- You want to set the default voice for male or female coaching themes.
- You want to set the default avatar for male or female coaching themes.
- You want Zappy AI personas to use the same voice and avatar options.
- You want to review the available voice catalogue when no voices have been imported yet.

## Steps

### 1. Open the coaching theme settings
Go to **Company Settings** and then **Organization Configuration**. Open the coaching theme group to view the default voice and avatar settings.

### 2. Choose a default voice or avatar
Edit **Default Male Voice**, **Default Female Voice**, **Default Male Avatar**, or **Default Female Avatar**. Each field opens a dropdown with the available organization options.

### 3. Review the available options
Pick from the list that matches the gender setting. The dropdown shows the provider for each voice and a thumbnail for each avatar.

### 4. Save your changes
Select **Save** to apply the selected defaults.

### 5. Set the AI persona in Zappy
Open the AI persona card in Zappy and select **Edit**. Choose the voice and avatar from the same organization lists.

## Things to know

:::note
If your organization has not imported any voices, the coaching create page shows the voice catalogue.
:::

:::note
If a voice or avatar is missing from the list, contact SmartWinnr support.
:::
