The cover image upload modal uses a clearer layout across supported modules. You see the image preview on the left and upload controls on the right. Validation feedback appears immediately when you choose an invalid file.

## When to use this

Use the modal when you need to add or replace a cover image in a supported area of SmartWinnr.

- You want to review the current image before uploading a new one.
- You need to check supported formats, file size, or recommended dimensions.
- You want immediate feedback if a file is too large or unsupported.
- You want a consistent modal size across supported upload screens.

## Steps

### 1. Open the cover image modal
Open any supported cover image upload modal. The modal opens at a large size and uses the same layout across supported areas.

### 2. Review the preview and controls
The preview card appears on the left. Upload controls appear on the right. Supported formats, maximum file size, and recommended dimensions appear below the file input.

### 3. Select an image file
Choose an image from your device or from the Available Images gallery, where available. The gallery shows as a scrollable 4-column grid with card-style items.

### 4. Check for validation feedback
If you select an invalid file, a red error message appears immediately. Use that feedback to choose a different file.

## Things to know

:::note
The modal layout is consistent across supported modules, including coaching, quiz, smartpath, survey, and other cover image upload screens.
:::

:::note
The Available Images gallery appears only where that option is available.
:::
