The Role Play Inventory report supports custom report headers. You can reorder, rename, show, or hide columns to match the layout you need.

The report includes seven new columns after **AI Avatar**. These columns add more detail to each role play inventory row and appear in the exported report.

## When to use this

Use this when you want a more detailed Role Play Inventory report or a custom column layout.

- Review inventory data with the columns you care about most.
- Reorder columns to match your team’s reporting format.
- Rename columns to use familiar labels.
- Hide columns you do not need in the export.
- Review the added inventory details after **AI Avatar**.

## Before you start

The custom header option may not be visible to everyone. If you do not see it, contact SmartWinnr support.

## Steps

### 1. Download the report
Download the Role Play Inventory report from the Role Play Inventory screen.

### 2. Open custom header settings
Go to **Super Admin Settings**, select **Coaching** from the module dropdown, then choose **Role Play Inventory Report**.

### 3. Adjust the columns
Reorder, rename, or hide columns as needed.

The new columns appear after the **AI Avatar** column.

**Audio Video Mode** shows **Audio**, **Video**, or **Both**. **Enable Screen Share**, **Enable Difficulty Levels**, and **Sharable Resources** show **Yes** or **No**.

**Skills** shows a comma-separated list of skills from coaching objectives and smart skills. **Competencies for Review** shows the review rubric competencies resolved from the org competency catalog.

Dynamic Global Attribute columns are appended after the static columns, even when custom headers are configured. Tenant-specific attribute columns are never lost.
