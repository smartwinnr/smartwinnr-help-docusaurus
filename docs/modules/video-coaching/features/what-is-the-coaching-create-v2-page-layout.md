The coaching create v2 page keeps the layout simple. You save from the bottom of the form, and the page title stays clear of extra controls.

Use this page when you create a coaching item and want to save it or assign users from one place.

## When to use this

Use the coaching create v2 page when you want to create a new coaching item from **Coachings**.

- You want to save a coaching and assign users.
- You want to save a coaching segment.
- You want a cleaner create page with fewer controls in the header.

## Steps

### 1. Open the create page
Go to **Coachings** in the left menu, then open the coaching create v2 page.

### 2. Review the page header
The page title appears without a save button next to it. The header stays focused on the page title.

### 3. Save from the bottom
Use the save button at the bottom of the form to save and assign users or save a coaching segment.

## Things to know

:::note
The edit coaching v2 page still uses its top save button.
:::
