The combined objective coaching report includes coachings from every lifecycle status when you do not select a status filter. This keeps it aligned with the coaching attempt report and the reportee-wise completion report.

Use this report when you want one view of all coachings in a report automation job. Leaving the lifecycle status filter empty includes draft, in-review, and released coachings.

## When to use this

Use the combined objective coaching report when you need a complete coaching set in one report.

- You want the report to include coachings across all lifecycle statuses.
- You are creating or editing a coaching report job in Report Automation.
- You want empty lifecycle status filters to behave consistently across coaching reports.

## Steps

### 1. Create or edit a coaching report job
Open Report Automation and create or edit a coaching report job.

### 2. Leave the lifecycle status filter empty
Leave the **Coaching Lifecycle Status** multi-select empty to include coachings in all lifecycle statuses.

### 3. Save the report job
Save the report job to use the combined objective report with all coachings included.
