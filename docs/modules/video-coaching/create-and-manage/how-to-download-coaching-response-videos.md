> **At a glance** - You can download coaching feedback for selected coachings and narrow it by metatag values.

Open the coaching feedback report from the Coaching page, then choose the filters you want before you download it. You can scope the report to specific metatag values when you only need feedback for part of your audience.

## When to use this

Use this report when you need to:

- Download feedback for one or more selected coachings.
- Limit the report to learners with a specific metatag value.
- Leave the metatag filter blank to include everyone in the selected coachings.

## Steps

### 1. Open the report modal

Go to **Coaching** and click the three-dot menu next to **Create Coaching**. Then choose **Download Coaching Feedback Report**.

![Coaching list](/img/helpscout/authored/how-to-download-coaching-response-videos-ms95uwk1.jpg)

### 2. Choose the report filters

Select a **Report Type** and one or more **Coachings**. You can also choose a **Meta Tag Type** and one or more **Meta Tags** values to narrow the download to coachees who carry those values.

![select the submitted video which need to be downloaded](/img/helpscout/authored/how-to-download-coaching-response-videos-ms9604of.jpg)

### 3. Clear the metatag type

Use the **x** next to the selected **Meta Tag Type** to clear it without reopening the modal. Leave the metatag fields blank to download feedback for everyone in the selected coachings.

![download video](/img/helpscout/authored/how-to-download-coaching-response-videos-ms962694.png)

### 4. Download the report

Click **Download** to generate the report with the filters you selected.

![Download video](/img/helpscout/authored/how-to-download-coaching-response-videos-ms963jev.png)

## Things to know

:::note
If you select a metatag value, the downloaded report includes only coachees with that value.
:::

:::note
If you leave the metatag filter unselected, the report includes everyone in the selected coachings.
:::

:::note
If a metatag value contains a comma, the report still filters it correctly.
:::
