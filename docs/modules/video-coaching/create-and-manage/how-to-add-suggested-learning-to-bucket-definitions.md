> **At a glance** - You can attach suggested learning to each bucket in a coaching definition. Learners then see those items on their coaching results and can start, continue, or open them.

Use suggested learning when you want a bucket to point learners to the next best action. Instead of only showing a result, you can connect that result to a quiz, coaching, SmartFeed, or external resource.

## When to use this

Use suggested learning when you want to guide learners after a coaching result.

- A learner lands in a low bucket and needs a clear next step.
- You want learners to open related content from their results page.
- You want to surface a quiz, coaching, SmartFeed, or external link for a specific bucket.
- You want learners to join a SmartFeed without being assigned first.

## Steps

### 1. Open bucket definitions
Go to **Company Settings** and open **Bucket Definitions**. Then open the coaching definition you want to edit.

### 2. Set the number of suggestions
In **Details**, set **Suggestions per bucket** to control how many items each bucket can hold.

### 3. Open a bucket
Open the bucket from the menu, then go to **Suggested learning**.

### 4. Add suggested items
Select **Add** and choose a quiz, coaching, or SmartFeed. You can also add an external link with a title and tags.

If you add an external link, you can also choose to sign the learner in with an existing menu link.

### 5. Save the definition
Save your changes. Learners in that bucket will see the suggestions on their coaching results in the app.

## Things to know

:::note
Learners see suggested items as **Suggested for you** on their coaching results.
:::

:::note
Learners can start, continue, or open each suggested item from their results.
:::

:::note
A SmartFeed can include an **Allow Self Registration** option. When learners start it, they join that month's open assignment and see it in their feed.
:::

:::note
If the feature is not visible in your environment, contact SmartWinnr support.
:::
