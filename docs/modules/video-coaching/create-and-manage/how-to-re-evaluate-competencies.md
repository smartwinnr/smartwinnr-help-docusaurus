> **At a glance** - Use the re-evaluation options to refresh competency analytics after you change coaching settings or competency definitions.

Re-evaluate competencies when you need updated analytics without asking learners to submit again. You can refresh results for a single coaching submission or for all submitted sessions in a coaching.

## When to use this

Use re-evaluation when coaching analytics need to reflect updated competency settings.

- You changed competency definitions.
- You adjusted competency weightage.
- You want to refresh results for one submitted session.
- You want to refresh results for every submitted session in a coaching.

## Steps

### 1. Open the submitted coaching analytics page
Open the analytics page for the submitted coaching session you want to refresh.

### 2. Re-evaluate one submission
Open the menu on the page and select **Re-Evaluate Competencies**.

A confirmation dialog appears before the re-evaluation starts. After it finishes, you see a success or error message.

### 3. Re-evaluate all submitted sessions
Open the menu on the coaching analytics editor page and select **Re-Evaluate Competencies For All**.

A confirmation dialog appears before the re-evaluation starts. After it finishes, you see a success or error message.

## Things to know

:::note
These options appear only when competency analytics is enabled for the coaching and in your coaching settings.
:::

:::note
If the option is missing, contact SmartWinnr support.
:::

:::note
Re-evaluation depends on the competency analytics processing setup being available.
:::
