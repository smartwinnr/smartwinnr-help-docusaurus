> **At a glance** - The SmartPath Journey View is an interactive map that displays a learner's progress through a SmartPath. An Organization Admin must first enable this feature in the organization settings. Once enabled, editors can access the Journey themes and Journey view options for the SmartPaths they are allowed to edit.

The Journey View is disabled by default for every organization. Enabling it at the organization level makes the feature available to editors without changing the existing learning experience for learners.

## When to use this

Use this setting when you want to:

- Enable the SmartPath Journey View at the organization level.
-	Make the Journey View feature available to editors.
-	Allow editors to access Journey themes and Journey view settings for their assigned SmartPaths.

## Steps

### 1. Sign in as an organization admin

![Organization Admin](/img/helpscout/authored/authored-mwlp9std.png)

### 2. Open Organization Configuration

Go to **Company Settings → Organization Configuration**.

![Navigate to Organization Configuration](/img/helpscout/authored/authored-mwlpeqy0.png)

### 3. Find SmartPath Configurations

In **Organization Configuration**, search for **SmartPath Configurations**.

![Select SmartPath Configurations to proceed](/img/helpscout/authored/authored-mwlpjkqp.png)

### 4. Turn on SmartPath journey view

After selecting **SmartPath Configurations**, locate **SmartPath journey view** and click **Edit**.
![Search for SmartPath journey view and click Edit.](/img/helpscout/authored/how-to-turn-the-journey-view-on-for-an-organization-mwlr87o7.png)
Enable the **SmartPath journey view** toggle and click **Save** to apply the changes.
![Enable the SmartPath journey view toggle and click Save](/img/helpscout/authored/how-to-turn-the-journey-view-on-for-an-organization-mwlr8glw.png)
Once you click **Save**, a confirmation notification appears in the top-right corner of the page.
![A confirmation notification appears in the top-right corner of the page.](/img/helpscout/authored/how-to-turn-the-journey-view-on-for-an-organization-mwlr8ndy.png)

### 6. Verify the setting in SmartPaths

Open **SmartPaths** and confirm that the Journey View options are available for editors.

### **What happens after enabling the Journey View?**

Once the organization-level setting is enabled:

- Editors can see the **Journey themes** button at the top of the SmartPaths list.
- Editors can access the **Journey view** button on each SmartPath they are allowed to edit.
- Editors can configure the Journey View for individual SmartPaths.

### **Note**
- The organization-level setting only makes the Journey View feature available to editors. It does not automatically enable it for learners.
- If the Organization Admin switches off the **SmartPath journey view** setting, the Journey View is hidden across all SmartPaths. Previously configured SmartPath settings are retained and restored when the organization-level setting is enabled again.
