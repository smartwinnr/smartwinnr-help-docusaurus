> **At a glance** - Use bulk attendance upload to record attendance for many learners in one file. Download the template, fill it out, and upload it to SmartWinnr.

Use bulk attendance upload when you need to record attendance for multiple learners in a learning session. It helps you update attendance and completion status without marking each learner one by one.

## When to use this

Use this feature when you need to:

- Record attendance for multiple learners at once
- Handle a session with many attendees
- Save time compared with individual updates
- Update completion status efficiently for several learners

## Steps

### 1. Open SmartPath
Log in to the Editor Portal and go to **Learning and Knowledge > SmartPath > View All SmartPaths**.
![Open smartpath](/img/helpscout/authored/how-to-upload-attendance-in-bulk-for-learning-sessions-mtwr1ev2.png)
### 2. Select the SmartPath
Find the SmartPath for the learning session you want to update.

### 3. Open batches
On the SmartPath card, click **Batches**. You can also open the SmartPath and click **View Batches** in the top-right corner.
![open batches](/img/helpscout/authored/how-to-upload-attendance-in-bulk-for-learning-sessions-mtwr2ez2.png)
### 4. Start bulk attendance
Click the **Bulk Attendance** icon.
![click on bulk attendance icon](/img/helpscout/authored/how-to-upload-attendance-in-bulk-for-learning-sessions-mtwr3a1k.png)
 The attendance upload page opens with the selected batch details.

![Select the user identifier](/img/helpscout/authored/how-to-upload-attendance-in-bulk-for-learning-sessions-mtwr52me.png)
Under **Upload User Data File**, choose the user identifier you want to use. Select **Email Address** if you have learner email addresses. Select **User Identifier** if you have employee IDs or another unique identifier used in SmartWinnr.

Download the template, fill in the attendance details, then upload the completed file and click **Upload**.

### 5. Complete the template
Use one row per learner. Fill in the attendance template with the required details for each session.

The template includes these fields:

- **SmartPath Code**: Auto-populated unique code for the SmartPath
- **Module ID**: Auto-populated ID of the module
- **Module Name**: Auto-populated module name
- **Segment ID**: Auto-populated ID of the learning session segment
- **Segment Name**: Auto-populated learning session segment name
- **Batch ID**: Auto-populated unique batch ID
- **Email Address**: Learner email address
- **Is Present**: Select **Yes** if the learner attended the session
- **Is Waiver**: Select **Yes** if attendance is waived for the learner
- **Is Applicable**: Select **Yes** if the session applies to the learner
- **Comment**: Add any attendance notes
- **Attendance Date**: Enter the date the attendance was recorded
![Complete the template](/img/helpscout/authored/how-to-upload-attendance-in-bulk-for-learning-sessions-mtwr7p44.png)
### 6. Review validation errors
After you upload the file, SmartWinnr validates the data. If the file is invalid, you see a **Validation Errors** message with the records that failed validation.
![Review validation errors](/img/helpscout/authored/how-to-upload-attendance-in-bulk-for-learning-sessions-mtwr8bxl.png)
Review the errors, correct the CSV file, and upload it again.
