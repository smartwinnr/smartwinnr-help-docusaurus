> **At a glance** - Journey view turns a SmartPath into a visual map with progress, milestones, and a next-step nudge. You set it up from the SmartPath list, then learners see it in **My Journey**.

Journey view gives learners a visual way to track progress through a SmartPath. It can show a map of modules, a moving traveler, readiness metrics, and a **What's next** line.

You can turn it on for a SmartPath, choose the layout and theme, and decide how the journey appears on different screen sizes.

## When to use this

Use Journey view when you want learners to see progress in a more visual way.

- You want a SmartPath to feel more like a guided path than a flat module list.
- You want to highlight progress, milestones, or readiness along the way.
- You want to show a clear next step for learners to continue.
- You want the journey to match your organization’s visual style.

## Steps

### 1. Open the SmartPath journey settings

Open **SmartPaths**, then use the row actions for the SmartPath you want to update. Select **Journey view** to open the setup page.

### 2. Turn on Journey view

On the Journey view page, switch Journey view on for that SmartPath. You can also choose the default tab learners see.

![Editors open Journey view from the SmartPath list to configure the journey experience for a specific SmartPath](/img/helpscout/authored/smartpath-journey-view-open-from-list.png)

### 3. Choose a theme

Select a theme for the journey. You can pick an existing theme, create a theme, or manage themes to add starter themes.

Themes control the look of the journey, including the trail color, traveler, destination, and device-specific images.

### 4. Pick a map layout

Choose **Path** or **Picture** map layout. Then place the pins for the journey screens.

Use the layout that best fits the story you want learners to follow.

![Editors choose a theme and select either Path or Picture map layout before placing pins for the journey](/img/helpscout/authored/smartpath-journey-view-theme-and-layout.png)

### 5. Set journey details

Configure the visibility, readiness metrics, and **What's next** nudges for the SmartPath.

You can also add weather effects and animation to make the journey more engaging.

### 6. Save your changes

Select **Save** to apply the Journey view settings to the SmartPath.

Learners can then open **My Journey** in the app or web app to see the experience you configured.

## Things to know

:::note
If Journey view is not available for a SmartPath, contact SmartWinnr support.
:::

:::note
Older app builds may still show the module list instead of **My Journey**.
:::
