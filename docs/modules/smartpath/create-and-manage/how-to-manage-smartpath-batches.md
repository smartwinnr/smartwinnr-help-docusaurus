> **At a glance** - SmartPath batches let you run the same SmartPath for different learner groups. Each batch can have its own schedule, due date, learning session details, and assigned users.

Use batches when you need one SmartPath to serve separate groups. You can update batch details, assign or remove learners, and create more batches as needed.

## When to use this

Use SmartPath batches when you need separate schedules or assignments for the same learning path.

- Run one SmartPath for different learner groups.
- Set different dates or due dates for each group.
- Add learning session details for a specific batch.
- Remove learners from a batch before it starts.

## Steps

### 1. Open SmartPaths

Go to Editor → Learning and Knowledge → SmartPaths, then select View All SmartPaths to view the complete list of SmartPaths.

### 2. Select a SmartPath

Find and open the SmartPath you want to manage from the list.

### 3. Open the Batches Tab

In the SmartPath details page, select Batches to view all batches created for that SmartPath.
![kindly select batches](/img/helpscout/authored/how-to-manage-smartpath-batches-mttlwydl.png)

### 4. Edit Batch Details

Select the required batch and click Edit to manage the batch details. You can update the batch name, duration, due date, and learning session details (if applicable), then save the changes.
![Kindly click on edit to edit batches](/img/helpscout/authored/how-to-manage-smartpath-batches-mttm968w.png)

### 5. Remove Assigned Users

If the batch has not started, select Edit, remove the users you want to unassign, and click Save to apply the changes.
![you can remove or add users if the batch is not started](/img/helpscout/authored/how-to-manage-smartpath-batches-mttmad6z.png)
### 6. Create a New Batch

Select Create Batch to assign the same SmartPath to a new group of learners. Enter the batch details, select the users, and complete the assignment.
