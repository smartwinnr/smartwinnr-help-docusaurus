> **At a glance** - Bulk Upload Users allows you to assign multiple users to a SmartPath batch in a single upload using a CSV file. This helps administrators quickly add large groups of learners to a batch without selecting users individually.

Bulk uploading simplifies user management by using a standardized CSV template to add or update users in a SmartPath batch. Once the CSV is uploaded successfully, all users in the file are assigned to the selected batch, making the enrollment process faster and more efficient.

## When to use this
Use Bulk Upload Users when you need to:
* Assign a large number of users to a SmartPath batch at once.
* Enroll learners using a CSV file instead of selecting users individually.
* Save time when creating or updating batches for multiple users.
* Manage training assignments for teams, business units, or large learner groups efficiently.

## Steps

### 1. Log in to the Editor Portal
Log in to your SmartWinnr Editor account using your credentials.

### 2. Open SmartPaths
Navigate to **Editor → Learning and Knowledge → SmartPath → View All SmartPaths**. 

The **View All SmartPaths** page displays all the SmartPaths available in your account.
![smartpaths page](/img/helpscout/authored/how-to-bulk-upload-users-into-smartpath-batches-mtny6jn4.png)
### 3. Open the Batch and Select Bulk Assign Users

Click **Batches** for the SmartPath where you want to upload users.

Click the hamburger menu in the top-right corner.

Select **Bulk Assign Users**.
![kindly select the bulk upload batches option](/img/helpscout/authored/how-to-bulk-upload-users-into-smartpath-batches-mtnyccp5.png)
### 4. Choose the Batch Mode
Smartpath provides two options for bulk assigning users:

- **New Batch**: Create a new SmartPath batch, fill the details below and assign users by uploading a CSV file.
- **Existing Batch**: Select an existing SmartPath batch and add users in bulk using a CSV file.

![kindly select the batch mode](/img/helpscout/authored/how-to-bulk-upload-users-into-smartpath-batches-mtnyezyy.png)
![kindly select the batch](/img/helpscout/authored/how-to-bulk-upload-users-into-smartpath-batches-mtnygfqw.png)
### 5. Upload the CSV File
Click **Download Template** to download the CSV template.

Enter the required user details in the template.
![kindly fill the details in csv template](/img/helpscout/authored/how-to-bulk-upload-users-into-smartpath-batches-mto4cmcs.png)
Upload the completed CSV file.

Click **upload** to assign the users to the selected SmartPath batch.

Note: Ensure the CSV file follows the downloaded template format. Users in the uploaded file are assigned to the selected SmartPath batch after a successful upload.
