> **At a glance** - Journey themes define the appearance of the SmartPath Journey View. They include the background pictures, trail colors, traveler, and destination displayed on the learner's journey map. Editors can add ready-made themes provided by SmartWinnr or create their own themes and customize them to match their organization's requirements.

## When to use this
Use Journey Themes when you want to:
- Add a ready-made theme to your organization's theme library.
- Create a custom theme for your SmartPath Journey View.
- Customize the pictures, trail colors, traveler, and destination.
- Reuse a theme across multiple SmartPaths.
- Archive or delete themes that are no longer required.

## 1. Open the Journey Themes library

Before accessing the Journey Themes library, ensure that the **SmartPath journey view** setting is enabled for your organization.

Please check the following to enable the toggle button. [How to Enable SmartPath journey view for an organization](https://help.smartwinnr.com/admin/authoring/edit?path=docs%2Fmodules%2Fsmartpath%2Fsettings-and-permissions%2Fhow-to-turn-the-journey-view-on-for-an-organization.md\&utm_source=chatgpt.com)

1. Sign in to the Editor Portal.
2. Navigate to **Learning and Knowledge → SmartPath → View All SmartPaths**.
![navigate to view all smartpaths](/img/helpscout/authored/how-to-add-a-journey-theme-to-a-smartpath-mwn80x44.png)
3. Click **Journey themes** at the top of the SmartPath list.
![click the journey themes button to access the organization's Journey Themes library](/img/helpscout/authored/how-to-add-a-journey-theme-to-a-smartpath-mwn822kn.png)
4. The organization's Journey Themes library opens.
![The organization's Journey Themes library page](/img/helpscout/authored/how-to-add-a-journey-theme-to-a-smartpath-mwnbj3rx.png)
You can also access the library by clicking **Manage themes** under the **Theme** settings while configuring a SmartPath's Journey View.
![Editor>Smartpath>View all smartpaths>journey view>theme>Manage themes](/img/helpscout/authored/how-to-add-a-journey-theme-to-a-smartpath-mwokrr6s.png)
## 2. Add a starter theme

SmartWinnr provides ready-made starter themes that you can add to your organization's library.

1. Open the Journey Themes library.
2. Review the available starter themes:
   - **Space:** A rocket travels from planet to planet.
   - **Mountain:** A journey from the meadow to the summit.
   - **Road:** A night drive along a mountain road.
   - **Christmas:** Santa's sleigh travels up to the star on the tree.
   - **Plain:** A simple map in your organization's colors.
![Starter themes](/img/helpscout/authored/how-to-add-a-journey-theme-to-a-smartpath-mwn8bc5u.png)
3. Select the starter theme you want to add to your library.

   Click **Add to my themes** to add the theme to your organization's library.
![Click **Add to my themes** to add the theme to your organization's library.](/img/helpscout/authored/how-to-add-a-journey-theme-to-a-smartpath-mwnbf71j.png)

4. Once added, the theme appears in your library with the **In your library** label.
![Once added, the theme appears in your library with the In your library label](/img/helpscout/authored/how-to-add-a-journey-theme-to-a-smartpath-mwnbsmjj.png)
**Note:** Adding a starter theme creates a separate copy for your organization. You can customize this copy without affecting other organizations. Future updates made by SmartWinnr to the original starter theme will not overwrite your copy.

## 3. Create a custom theme

You can create a new theme and customize its appearance using the available theme settings.

1. Open the Journey Themes library.
2. Click **Create a theme**.
![click on create a theme](/img/helpscout/authored/how-to-add-a-journey-theme-to-a-smartpath-mwnbvibv.png)
3. A page titled **New Theme** opens, where you can customize the theme.
4. Customize the Journey Theme:

  **Preview the theme:**
- Use the **Preview** section on the right to see how your theme looks.
- Switch between **Laptop**, **Tablet**, and **Phone** to preview the theme on different screen sizes.
- Select **Path** or **Picture map** to preview the theme in different layouts.
- Click **Play animation** to see the journey animation.

# Configure the theme using the available sections
   - **Name**
     - Under the **Name** section, enter a name for your theme in the **Name** field. 
     - To add the theme name in other languages, click **Add Translation**, select the required language, manually translate the theme name, and enter the translated text in the corresponding language section.
![Select the language from the list](/img/helpscout/authored/how-to-add-a-journey-theme-to-a-smartpath-mwncwnvc.png)
![the name section](/img/helpscout/authored/how-to-add-a-journey-theme-to-a-smartpath-mwncc7bm.png)
   - **Pictures**


     - Under the **Pictures** section, upload background pictures for **Phone**, **Tablet**, and **Laptop** using the respective **Upload** buttons.
     - Supported formats are JPG, PNG, and WebP. If a picture is left blank, one of the other uploaded pictures is used.
     - Under **Background color**, choose a color to display while pictures load, around a Picture map, or when no pictures are available.
     - Under **Weather effect (optional)**, upload an animated SVG effect, such as falling snow. Leave it blank if no effect is required.
![the picture section](/img/helpscout/authored/how-to-add-a-journey-theme-to-a-smartpath-mwndrmrq.png)
 **Note:** The Picture map layout requires pictures for all three screen sizes.
   - **Trail colors**
     - **Route color:** Choose a color for the dashed line connecting the modules.
     - **Progress color:** Choose a color for completed modules and the trail behind the learner.
     - Select **Use our app color** to use your organization's app color instead of a fixed color.
     - Click **Clear** to clear the selected color.
![trail colors section](/img/helpscout/authored/how-to-add-a-journey-theme-to-a-smartpath-mwne5t7l.png)
   - **Traveler and destination**
     - **Traveler:** Select the **Built-in** tab to choose an icon (Rocket, Climber, Car, Gift, or Progress badge), or select **My own picture** to upload a custom picture. The traveler moves along the trail to show the learner's current module.
     - **Destination:** Select the **Built-in** tab to choose an icon (Planet, Summit flag, Finish flag, Star, or Flag), or select **My own picture** to upload a custom picture. The destination appears at the end of the trail.
![Traveler and destination section](/img/helpscout/authored/how-to-add-a-journey-theme-to-a-smartpath-mwnegs77.png)
5. Once you have completed the customization, click **Create theme** to create and save your theme.
- After clicking **Create theme**, the theme opens in editing mode. Click **Save** at the top-right corner to save your theme.
- **Back:** Return to the Journey Themes library.
- **Archive:** Remove the theme from the active theme list. You can restore it later, and SmartPaths already using it will continue to use it.
![click on archive button to archive it](/img/helpscout/authored/how-to-add-a-journey-theme-to-a-smartpath-mwnevgb8.png)
- **Delete:** Permanently delete the theme. This is allowed only when no SmartPath is using it.
- **Save:** Save any changes made to the theme. Changes are reflected in all SmartPaths using that theme.

## 4. Edit an existing theme

You can edit any theme in your organization's library.

1. Open the Journey Themes library.
2. Click the theme you want to edit.
3. The theme opens with its settings and live preview.
4. Update the required settings.
5. Click **Save** to save your changes.



**Important note:**

- The organization's theme library is shared across all its SmartPaths, and the same theme can be used in multiple SmartPaths.
- Any changes made to a theme are reflected in all SmartPaths that use it. The theme page also displays the SmartPaths currently using that theme.
- To give a particular SmartPath a different appearance, create a separate theme instead of changing a shared theme.
- Adding a theme to the library does not automatically apply it to a SmartPath. To use it, open the SmartPath's **Journey view** settings, select the theme under **Theme**, and save the changes.
- You can permanently delete a theme only when no SmartPath is using it. If it is currently in use, select another theme for those SmartPaths before deleting it, or archive the theme instead.
