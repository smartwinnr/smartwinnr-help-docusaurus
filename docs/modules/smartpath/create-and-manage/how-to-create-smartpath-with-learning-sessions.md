> **At a glance** - Adding a module with a Learning Session works like adding any other module. The one difference: the session's date, instructor, and link/location are entered on the Batch Creation page.

Just as you add modules with quizzes, surveys, SmartFeeds, or video coaching to a SmartPath, you can add modules with **Learning Sessions** (virtual or classroom).

## Before you start

Create the module with a Learning Session segment first - see [How to add Learning Sessions in a SmartPath Module](./how-to-add-learning-sessions-in-smartpath-module.md). For the general SmartPath creation flow, see [How to create a SmartPath](./how-to-create-a-smartpath.md).

## Steps

### 1. Open or create the SmartPath

Go to **EDITOR > LEARNING AND KNOWLEDGE > SmartPaths > View All SmartPaths**. Select an existing SmartPath or create a new one.

![Select the SmartPath or create a new SmartPath where you want to include the module with learning session.](/img/helpscout/editors/how-to-create-smartpath-with-learning-sessions-1.jpg)

### 2. Fill the SmartPath details

Complete the SmartPath details and move to the modules step.

![Fill the SmartPath details and move to step 2 where you add the modules to the SmartPath.](/img/helpscout/editors/how-to-create-smartpath-with-learning-sessions-2.jpg)

### 3. Add the module containing the Learning Session

Select the modules to attach - including the one with the Learning Session segment - and click **Add Selected** at the top right corner.

![Here, select the modules that you want to attach to the new SmartPath, including the module where you have added the segment for the Learning session.](/img/helpscout/editors/how-to-create-smartpath-with-learning-sessions-3.jpg)

The SmartPath is created with its module details:

![This opens the following page where your SmartPath, along with its module details, is created.](/img/helpscout/editors/how-to-create-smartpath-with-learning-sessions-4.png)

### 4. Open batches

Click **View Batches** at the top right corner to create a training batch.

![Once your SmartPath is created with required modules, you can assign the SmartPath to Batches. Click on the View Batches button at the top right corner.](/img/helpscout/editors/how-to-create-smartpath-with-learning-sessions-5.jpg)

### 5. Create the batch

Click **Create Batch** at the top right corner.

![In the next step, Click on the Create Batch icon at the top right corner.](/img/helpscout/editors/how-to-create-smartpath-with-learning-sessions-6.jpg)

### 6. Fill batch and session details

Enter the standard batch details:

* **Batch Name**
* **Duration of the batch** - start date/time and end date/time.
* **Due date of the batch** - shown on the learner's calendar as the completion deadline.

Because the SmartPath includes a Learning Session, an extra section asks for the session details for this batch:

![Whenever a learning session is added to the SmartPath, you will have an extra section where you will need to enter the details of the learning session.](/img/helpscout/editors/how-to-create-smartpath-with-learning-sessions-7.png)

* **Start Date & Time:** When the session begins.
* **End Date & Time:** When the session ends.
* **Instructor:** Who conducts the session. If the instructor has a SmartWinnr account, start typing and select them; otherwise enter the name manually.
* **Session Link:** Mandatory for **virtual sessions** - the meeting link (Zoom, Google Meet, Microsoft Teams, and similar).
* **Session Location:** Mandatory for **classroom sessions** - the room or venue address.
* **Session Details:** The topics covered, session objectives, and anything learners should know or prepare in advance.

Add **reminders** to nudge learners to complete their training and attend the session:

![The editor can also add reminders for the users notifying them to complete their training and attend the learning session.](/img/helpscout/editors/how-to-create-smartpath-with-learning-sessions-8.png)

### 7. Assign users

Select the users for the batch and click **Assign Users**.

![The next step is to select the list of users for the batch. And after selecting the users, click on Assign Users below.](/img/helpscout/editors/how-to-create-smartpath-with-learning-sessions-9.jpg)

The batch is created for the SmartPath:

![This will successfully create the batch for the SmartPath.](/img/helpscout/editors/how-to-create-smartpath-with-learning-sessions-10.png)

## After the session: attendance

Once the session takes place, the instructor marks attendance. The Learning Session segment turns **Completed** for each learner only after attendance is recorded.
