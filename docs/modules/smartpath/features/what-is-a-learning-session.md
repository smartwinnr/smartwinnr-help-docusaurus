> **At a glance** - A **Learning Session** is a scheduled, instructor-led segment within a **SmartPath module**. It allows learners to attend structured training either in person or online. SmartWinnr supports **Classroom Sessions** and **Virtual Sessions**, with session details configured as part of the SmartPath batch.


Learning Sessions can include an instructor, scheduled start and end times, and either a physical location or a virtual meeting link. If enabled, learners can also receive a calendar invitation for the scheduled session.

### Types of Learning Sessions

* **Classroom Session:** An in-person training session conducted at a physical location.
* **Virtual Session:** An online training session conducted through a meeting platform such as Zoom, Microsoft Teams, or Google Meet.

### How Learning Sessions Work

Learning Sessions are added as **segments within a SmartPath module**, similar to quizzes, surveys, and other learning activities.

When creating the SmartPath batch, the editor provides the session-specific details, such as the **date, time, instructor, and location or meeting link**.

Learners can view the session information from their assigned SmartPath:

* For **Classroom Sessions**, learners can view the location, instructor, start date and time, and end date and time.
* For **Virtual Sessions**, learners can view the session link, instructor, start date and time, and end date and time. They can use the session link to join the virtual session.

After the session, the **instructor records learner attendance**, either individually, in bulk, or through a QR code. The Learning Session is marked **Completed** for a learner once their attendance is recorded.

### QR Code Attendance

Each Learning Session has a **session-specific QR code** that can be shared with learners for attendance. Learners can scan the QR code using the **Scanner** option available within the SmartPath in **User View** to mark their attendance themselves. This provides a quick and convenient way to record attendance during a learning session.

The instructor or editor can also download the QR code for each Learning Session and share or display it for learners to scan during the session.

The Learning Session is marked **Completed** for a learner only after their attendance has been recorded.

### When to Use

Use Learning Sessions when you need to:

* Conduct **instructor-led training** as part of a SmartPath.
* Organize **in-person classroom training** at a specific location.
* Conduct **virtual training sessions** using an online meeting platform.
* Schedule training with a defined **date, time, and instructor**.
* Provide learners with **session links or location details**.
* Send **calendar invitations** for scheduled sessions.
* Track **learner attendance and session completion**.
* Allow learners to **mark their own attendance using a session-specific QR code**.
