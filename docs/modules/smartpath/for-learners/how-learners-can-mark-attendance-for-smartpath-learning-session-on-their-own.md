> **At a glance** - Learners can mark their attendance for SmartPath learning sessions using the built-in scanner option in the User View.

Learners can self-mark their attendance for learning sessions in SmartPath directly from the **User View** using the built-in scanner option.

## When to use this
Use this feature when you need to mark your attendance for a learning session in SmartPath. This is particularly useful for:

- Attending scheduled learning sessions.
- Ensuring your attendance is recorded accurately.
- Using the QR code provided for the session.

## Steps to Mark Attendance

### 1. Log in to SmartWinnr
Log in to your account in SmartWinnr.

### 2. Switch to User View
Switch to **User View** if you have both User and Manager roles in SmartWinnr.

### 3. Navigate to SmartPath
Navigate to **SmartPath**.

### 4. Select the SmartPath
Select the **SmartPath** that contains the learning session for which you need to mark attendance.

![Select the SmartPath that contains the learning session for which you need to mark attendance.](/img/helpscout/managers-and-team-members/how-learners-can-mark-attendance-for-smartpath-learning-session-on-their-own-1.png)

### 5. Tap the Scanner Icon
On the SmartPath screen, tap the **Scanner icon** available at the **top-right corner**.

![On the SmartPath screen, tap the Scanner icon available at the top-right corner](/img/helpscout/managers-and-team-members/how-learners-can-mark-attendance-for-smartpath-learning-session-on-their-own-2.png)

### 6. Scan the QR Code
Scan the QR code shared for the learning session.

### 7. Attendance Confirmation
Once the scan is successful, your attendance will be marked automatically.

![Once the scan is successful, your attendance will be marked automatically.](/img/helpscout/managers-and-team-members/how-learners-can-mark-attendance-for-smartpath-learning-session-on-their-own-3.png)

## Important Notes

- The scanner option is available only for SmartPaths that include **learning session modules**.
- Ensure you have the correct SmartPath selected before scanning the QR code.
