> **At a glance** - Yes,you can edit an existing AI role-play scenario to keep it aligned with your coaching goals. Update the scenario flow, wording, AI persona, scoring, schedule, visibility, and supporting resources as needed.

## When to use this
Use this when you want to refine an existing scenario instead of creating a new one.
- Improve the effectiveness of a scenario.
- Respond to user feedback.
- Update training content or objectives.
- Adjust the AI persona or supporting resources.
- Keep the experience relevant for learners.

# Changes That Can Be Made to an Existing AI Role-Play Scenario

## 1. The Basics
If users have attempted the AI Role-Play scenario:
- Business Unit: Cannot be changed once selected.
- Coaching Type: Cannot be changed.
- Coaching Template: Can be changed.
- Coaching Assessment Type: Can be changed.
- Enable AI Coaching Type: Cannot be changed.
- Enable Multiple Languages: Can be changed.

If no users have attempted the AI Role-Play scenario:
- Business Unit: Cannot be changed once saved.
- Coaching Type: Can be changed.
- Coaching Template: Can be changed.
- Coaching Assessment Type: Can be changed.
- Enable AI Coaching Type: Cannot be changed.
- Enable Multiple Languages: Can be changed.

## 2. The Intro
The following fields can be changed in both cases, whether users have attempted the AI Role-Play scenario or no users have attempted it:
- Coaching Title: Can be changed.
- Coaching Code: Can be changed.
- Coaching Cover Image: Can be changed.
- Coaching Description: Can be changed.
- Short Title: Can be changed.
- Short Description: Can be changed.
- Requested By: Can be changed.
- Parent Coaching: Can be changed.

## 3. The AI Customer
The following fields and settings can be changed in both cases:
- Scenario Description: Can be changed.
- Customer Name: Can be changed.
- Customer Profile: Can be changed.
- AI Voice: Can be changed.
- AI Avatar: Can be changed.
- Conversation Settings: Initiate AI First, Enable AI Suggestions, Enable Screen Share, and Enable Difficulty Levels can be changed.
- Objections to Be Raised: Can be changed.
- Questions List: Can be changed.
- Randomize Questions: Can be changed.
- Allow Feedbacks for Questions: Can be changed.
- Verbal Knowledge Assessment: Questions, expected answers, and related settings can be changed.
- Conversation Stages: Stage names, descriptions, and score scales can be changed.

## 4. Sharable Resources
The following fields and settings can be changed in both cases:
- Enable Sharable Resources: Can be enabled or disabled.
- Uploaded Resources: Can be added, replaced, or removed.

## 5. How It Is Evaluated

The following fields and settings can be changed in both cases, whether users have attempted the AI Role-Play scenario or no users have attempted it:
- **Evaluation Criteria:** Can be changed.
- **Product Name:** Can be changed.
- **Product Description:** Can be changed.
- **Additional Details:** Can be added or changed.
- **Objectives of the Response:** Can be changed, including objective descriptions and weightages.
- **Select Competencies:** Selected competencies and their weightages can be changed.
- **Extra Evaluation Modes:** Enable Soft Skills, Enable Smart Skills, Enable Compliance Feedback, and Enable Facts Feedback can be changed.
- **Speech Recognition:** Boost Words and Phonetics can be changed.
- **Advanced Settings:** Keywords to Cover, Keywords to Avoid, Banned Words, and Exclusion Sentences can be changed.

## 6. Scoring
**If users have attempted the AI Role-Play scenario:**
- **Who Scores:** AI and Coach weightages cannot be changed.
- **Score Distribution:** Weightages for Objective Coverage, Objection Handling, Total Time Taken, Speech Pace, Filler Words, Keyword Coverage, and Ignore Words can be changed.
- **Rating Scales and Bands:** Bucket Definition and Leaderboard Score Type can be changed.
- **Advanced Settings:** Evaluation Provider, Objective Rating Scale, Coach Rating Scale, Objective Coverage Threshold, Score Boost Multiplier, and AI Evaluation Level can be changed.
- **Response Types:** Video and Streaming Links settings can be changed.
- **Coach Review:** Enable Coach Named Scale Mapping can be changed.

**If no users have attempted the AI Role-Play scenario:**
All fields and settings can be changed, including:
- **Who Scores:** AI and Coach weightages.
- **Score Distribution:** Weightages for Objective Coverage, Objection Handling, Total Time Taken, Speech Pace, Filler Words, Keyword Coverage, and Ignore Words.
- **Rating Scales and Bands:** Bucket Definition and Leaderboard Score Type.
- **Advanced Settings:** Evaluation Provider, Objective Rating Scale, Coach Rating Scale, Objective Coverage Threshold, Score Boost Multiplier, and AI Evaluation Level.
- **Response Types:** Video and Streaming Links settings.
- **Coach Review:** Enable Coach Named Scale Mapping.

## 7. Schedule and Attempts
If users have attempted the AI Role-Play scenario:
- Start Date: Cannot be changed.
- End Date: Can be changed.
- Time Zone: Can be changed.
- Due Date: Can be changed.
- Maximum Attempt Count: Can only be increased, not decreased.
- Min Duration: Can be changed.
- Max Duration: Can be changed.
- Schedule Reminder: Can be configured or changed; start and end dates are required.

If no users have attempted the AI Role-Play scenario:
- Start Date: Can be changed.
- End Date: Can be changed.
- Time Zone: Can be changed.
- Due Date: Can be changed.
- Maximum Attempt Count: Can only be increased, not decreased.
- Min Duration: Can be changed.
- Max Duration: Can be changed.
- Schedule Reminder: Can be configured or changed; start and end dates are required.

## 8. Notifications
The following settings can be enabled, disabled, or changed in both cases:
- Send Notification on Coaching Assignment
- Send Notification to User
- Send Notification to Reviewer
- Enable Completion Notification

## 9. Visibility
The following settings can be changed in both cases:
- Visibility Settings: Show Video to Editor, Show Video to Manager, Show Video to User, Show AI Analytics to Editor, Show AI Analytics to Manager, and Show AI Analytics to User.
- Feedback Report: Show Objectives, Show Objections, Show Keywords, Show Competencies, Show Keyword Coverage, Show Objective Coverage Only, Disable Scoring, Allow Learners and Managers to Download AI Feedback as PDF, and Allow Timeline Feedback.
- Dashboards and Access: Show Manager Dashboard, Show Manager Dashboard to Reviewer, Show Direct Reportee in Analytics, Allow Showing Selected Attempt to Manager, and Allow to Delete Video.

## 10. Pre-read Material
The following fields and settings can be changed in both cases:
- Sample Recording: Can be added or changed.
- Sample Resource Type: Can be changed.
- Upload a Pre-read Audio/Video: Can be uploaded, replaced, or removed.
- Introductory Video: Title and video can be changed; the background can be uploaded or replaced.
- Instruction PDF: Can be uploaded, replaced, or removed.
- File Name: Can be changed.
- Allow Download Instructions: Can be enabled or disabled.
- Resources: Reading materials and links can be added, changed, or removed.

## 11. Extras and Integrations
The following fields and settings can be changed in both cases:
- Enable Disclaimer: Can be enabled or disabled.
- Reviewer Notes: Can be added or changed.
- Archive AI Feedback: Can be enabled or disabled.
- Categories: Can be changed.
- Integrate with LMS (xAPI): Can be enabled or disabled.
- Allow Self Registration: Can be enabled or disabled.

## 12. Tags and Competencies
If users have attempted the AI Role-Play scenario:
- Competencies: Can be changed.
- Resource Tags: Can be changed.

If no users have attempted the AI Role-Play scenario:
- Competencies: Can be changed.
- Resource Tags: Can be changed.
