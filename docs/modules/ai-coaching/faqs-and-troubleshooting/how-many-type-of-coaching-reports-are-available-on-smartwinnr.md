> **At a glance** - SmartWinnr offers four coaching report types that help you review performance, progress, and training effectiveness.

Coaching reports provide critical insights into learner performance, skill development, and training effectiveness. These reports help you track progress, identify knowledge gaps, and make data-driven decisions about coaching interventions.

The platform offers multiple report types, each designed for a specific purpose. Whether you need a high-level overview of all coaching activities or granular, objective-level performance data, there's a report to match your needs.

**Who can access these reports?**

Editors and Managers can download coaching reports from the system. These reports are not emailed automatically to managers on a daily or weekly basis. Editors need to download them from their SmartWinnr account and share them with managers. For example, if managers want a participation report or an objective-wise report on a weekly or monthly basis, editors can provide it by downloading it from their account.

## When to use this

Use coaching reports when you need to review learner performance across coaching activities or share performance data with managers.

- You want a complete picture of how each team member performs across assigned coaching activities.
- You want to review one coaching scenario in detail.
- You want to track improvement across multiple attempts.
- You want objective-level performance data for deeper analysis.

## Steps

### 1. Review the overall coaching summary

Use the **Overall Coaching Report** when you need a coachee-wise summary across all coaching sessions in the system.

**What it shows:**

- Latest submission for each coaching by each user
- A holistic view of each user's coaching journey
- High-level performance across multiple coaching scenarios

**When to use it:**

Use this report when you need a complete picture of how each team member is performing across all assigned coaching activities.

### 2. Review one coaching scenario

Use the **Coaching-wise Report** when you want to focus on one specific coaching scenario and see how users performed in that activity.

**What it shows:**

- Latest attempt by each user for the selected coaching
- AI scores, if applicable
- Coach scores
- Competency breakup

**When to use it:**

Use this report when you want a snapshot of team performance for a single coaching scenario. It helps you evaluate how well a specific training initiative is working.

### 3. Review all attempts

Use the **Attempt-wise Coaching Report** to capture all attempts made by users for a specific coaching scenario, not just their latest submission.

**What it shows:**

- Every attempt by every user for the selected coaching
- Performance trends over time
- Improvement progression across multiple tries

**When to use it:**

Use this report to track how users improve with practice. It is especially useful for identifying learners who may need additional support or those who are making steady progress.

### 4. Review objective-level performance

Use the **Attempt-wise User Objective Report** when you need the most granular report available in the system. It provides objective-level performance data for each attempt made by each user.

**What it shows:**

Unlike other reports that provide overall scores, this report breaks down performance by individual objectives, also called evaluation criteria or competencies.

**Example:**

If a coaching scenario has 5 objectives, and a user scores:

- Objective 1: 8
- Objective 2: 8
- Objective 3: 5
- Objective 4: 9
- Objective 5: 9

The report displays each of these scores in separate columns, allowing you to pinpoint exactly where the user excelled and where they struggled.

**How the data is structured:**

Each row in the report represents one attempt. This means:

- If 1 user makes 5 attempts, the report contains 5 rows for that user.
- If 50 users each make 2 attempts, the report contains 100 rows.

Each row includes:

- User name
- Attempt number
- Score for each objective

**When to use it:**

Use this report when you need to:

- Identify specific skill gaps across your team
- Understand which objectives users consistently struggle with
- Plan targeted coaching interventions based on objective-level performance
- Analyze improvement trends for individual competencies

This report is essential for deep performance analysis and precision coaching.

## Tips

- Use the **Overall Coaching Report** for a broad view of coaching activity across users.
- Use the **Coaching-wise Report** when you need to evaluate one coaching scenario.
- Use the **Attempt-wise Coaching Report** to compare progress across attempts.
- Use the **Attempt-wise User Objective Report** for detailed objective-level analysis.
