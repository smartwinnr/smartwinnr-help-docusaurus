AI Coaching can work as Assessment Coaching or as Certification Coaching. Both score the learner’s performance and provide feedback. Certification Coaching also checks objective-based pass criteria to decide whether the learner passes.

## When to use this

Use Assessment Coaching when you want to score performance and help learners improve through feedback.All your AI coaching can be considered as Assessment coaching.

Use Certification Coaching when you want to verify that learners meet a required standard.

- Review performance after a coaching scenario.
- Compare learner results against a certification requirement.
- Show learners which objectives they met and which they missed.

## Before you start

You need an AI Coaching scenario.

For Certification Coaching, set the coaching type as **Certification** and a pass criterion based on objectives.

## Steps

### 1. Choose the coaching type

When you create an AI Coaching scenario, choose the coaching type that matches your goal. All the AI coaching type that you can create in SmartWinnr are Assessment Coaching which gives the learers scoring and feedback. Use **Certification** when you want to set a pass criteria based on objectives.

### 2. Review the learner score

After the learner completes the scenario, SmartWinnr shows a score based on the configured evaluation criteria. Use this score to understand overall performance.

### 3. Check certification results

For Certification Coaching, compare the learner’s performance against the configured objective count needed to pass. For example, if the scenario has 4 objectives and the pass criterion is 3, the learner must meet at least 3 objectives to pass.

### 4. Read the Feedback page

On the **Feedback** page, each objective shows a **Pass** or **Fail** status for Certification Coaching. This allows learners to view and understand which objectives were met and which need improvement. On completing the pass criterion, leaners will receive a congratulation message as shown below.

## Things to know

Assessment Coaching always provides scoring and feedback. It does not require a pass criterion.
:::

Certification Coaching uses both the score and the objective-based pass criterion. The score shows performance, and the criterion determines pass or fail.
:::
