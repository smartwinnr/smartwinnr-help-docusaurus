> **At a glance** - Follow these steps to create a new coaching folder in the AI Coaching Library.

Creating a coaching folder helps you organize your coaching materials effectively. You can add a name and cover images to personalize the folder.

## When to use this
Use this feature when you want to:
- Organize coaching content for easy access.
- Create a dedicated space for specific coaching topics.
- Enhance the learning experience by categorizing materials.

## Steps

### 1. Log in to the Editor account
Navigate to **Editor** and select **Coaching Library** from the left menu. This will display the list of available folders.

![Select Coaching Library from the Left Menu](/img/helpscout/authored/authored-ms7haush.png)

### 2. Click on the Create button
Locate and click the **Create** button to initiate the folder creation process.

![Click on create button](/img/helpscout/authored/authored-ms7hf6sg.png)

### 3. Select the Folder option
Choose the **Folder** option to create a new folder.

![Click on folder button](/img/helpscout/authored/authored-ms7hfiyo.png)

### 4. Add folder details
Enter the name of the folder and any additional details, such as cover images. Then, click the **Create** button to finalize the creation.

![Add the name of the folder and other details](/img/helpscout/authored/authored-ms7hg35s.png)

### 5. View your new folder
Your new folder will now appear in the Coaching Library, ready for use.

![New Folder](/img/helpscout/authored/authored-ms7hjxb4.png)
