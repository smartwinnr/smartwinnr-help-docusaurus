> **At a glance** - Follow these steps to add a coaching scenario to a specific folder in the Coaching Library.

To enhance your coaching experience, you can easily add a coaching scenario to a folder within the Coaching Library. This allows you to organize and manage your coaching scenarios effectively.

## When to use this
You might want to add a coaching scenario when:
- You have new coaching content to include.
- You need to organize existing coaching scenarios into specific folders.
- You want to ensure that all relevant coaching materials are easily accessible.

## Steps

### 1. Log in to your Editor account
Access the **Editor** section and navigate to **Coaching Library**. This will display the list of folders available in the Coaching Library.

![List of folders in coaching library](/img/helpscout/authored/authored-ms7gbqix.png)

### 2. Select the folder for the coaching
Choose the folder where you want to add the coaching scenario.

![Select the folder to add the coaching to it](/img/helpscout/authored/authored-ms7gemqz.png)

### 3. Open the Hamburger Menu
Click on the **Hamburger Menu** and select the **Add Coaching To Folder** option.

![Select Add Coaching To Folder](/img/helpscout/authored/authored-ms7ggdnl.png)

### 4. Enter the coaching name
Type the coaching name in the **Coaching Textbox**. It will list the available coaching scenarios.

![Put the coaching name in the textbox](/img/helpscout/authored/authored-ms7gk81q.png)

### 5. Select the coaching scenario
Use the **Down Arrow** key to select the coaching scenario or click on it with your mouse. Then, click the **Add** button to include that coaching in the folder.

![Select the coaching using Down Arrow](/img/helpscout/authored/authored-ms7gm1aw.png)

### 6. Verify the coaching scenario
The added coaching scenario will now appear in the selected folder.

![Coaching in the folder](/img/helpscout/authored/authored-ms7gqeip.png)
