> **At a glance** - Create coaching scenarios using Zappy by defining the scenario details, objectives, and more.

Zappy is a self-serve tool that allows you to create AI coaching scenarios effortlessly. You can describe a scenario, let Zappy generate the coaching content, preview the result, and assign it to your team. This article walks you through the entire process of creating a coaching scenario using Zappy.

**Note: You can create only two-way conversational scenarios using Zappy.**

## When to use this
Use Zappy when you need to create conversational role-play scenarios for coaching purposes. Consider using it in the following situations:
- When you want to enhance team training with AI-generated scenarios.
- To provide personalized coaching experiences tailored to specific situations.
- When you need to create multiple scenarios quickly and efficiently.

## Before you start
Ensure you have access to the Zappy tool in your SmartWinnr account. You should also have a clear idea of the coaching scenario you want to create, including the objectives and any supporting documents you may need.

## Steps

### 1. Access Zappy
Go to the left menu and select **AUTHORING TOOLS**, then choose **Zappy**. This will take you to the coaching creation page where you can start building your scenario.

![Scenario creation using Zappy](/img/helpscout/authored/authored-mtmshhbm.png)

### 2. Choose the coaching type
Select the appropriate coaching type from the options available. This will determine the structure and focus of your scenario.

![Choose the coaching type here](/img/helpscout/authored/authored-mtmsiql3.png)

### 3. Choose the evaluation type
Select the evaluation type that best suits your coaching scenario. This will guide how responses are assessed.

![Choose the evaluation type here](/img/helpscout/authored/authored-mtmsizjg.png)

### 4. Fill in scenario details
Add the scenario title and provide a detailed description of the scenario. This helps users understand the context and objectives.

![Add the scenario title and detailed scenario description](/img/helpscout/authored/how-to-create-a-coaching-with-zappy-mtmu3duo.png)

### 5. Choose or create a Persona
Select an existing persona or create a new one for the scenario. A persona represents the character that users will interact with during the coaching.

![Choose or create the Persona for the scenario](/img/helpscout/authored/how-to-create-a-coaching-with-zappy-mtmu60j4.png)

### 6. Upload supporting documents
Upload any supporting documents, such as PDFs or images, that provide additional details for evaluating responses. These documents can enhance the coaching experience.

![Upload the supporting document which provides the additional details to evaluate the responses for the scenario](/img/helpscout/authored/authored-mtmsml4s.png)

### 7. Define objectives and objections
Specify the objectives and objections for the scenario. This will help guide the coaching process and provide clear targets for users.

![Define the objectives and objections of the scenario](/img/helpscout/authored/how-to-create-a-coaching-with-zappy-mtmufda1.png)

### 8. Select keywords
If applicable, select keywords that should be covered in the scenario. Keywords can help focus the coaching on specific topics or skills.

![Select the Key words for the scenario if any](/img/helpscout/authored/how-to-create-a-coaching-with-zappy-mtmugiyh.png)

### 9. Define scoring parameters
Set the scoring percentage for each parameter to evaluate the responses. This will help in assessing user performance during the coaching.

![Define the scoring % for each parameter](/img/helpscout/authored/authored-mtmsqnq0.png)

### 10. Select languages and duration
Choose the languages allowed for the scenario and specify the duration for the coaching. This ensures that the scenario is accessible to users in their preferred language and fits within time constraints.

![Select the languages allowed for the scenario, in which users can make the response submission and also choose the duration of the scenario](/img/helpscout/authored/authored-mtmsro9o.png)

Once you fill all the required details, click on **Create Coaching Scenario**. It will take a few seconds to generate the scenario.

![create scenario](/img/helpscout/authored/how-to-create-a-coaching-with-zappy-mtmukjbg.png)

Once the scenario is created, you will have the option to preview it. Click on **Try Now** at the bottom of the coaching preview to test the scenario yourself. This will assign the scenario to you in SmartWinnr for testing.

![scenario preview](/img/helpscout/authored/how-to-create-a-coaching-with-zappy-mtmupl4w.png)

You can test the scenario and make necessary changes. To edit or make further changes to the scenario, go to the left menu and select **Coaching**. Under the **My Coachings** tab, you will find the new scenario listed under **Draft** status. Make the necessary changes and publish the scenario to assign it to the required team.

## Tips
- Use clear and concise titles and descriptions to ensure users understand the scenario.
- Upload high-quality supporting documents to enhance the evaluation process.
- Regularly review and update your scenarios to keep them relevant and effective.
