> **At a glance** - Create reward point rules to define when learners earn points. You can set them up for leaderboard, quiz, survey, or coaching activity.

Create reward point rules to define when learners earn points. You can base points on ranking, completion, or coaching activity. You can also name the rule and add a reason or description for it.

## When to use this

Use reward point rules when you want to standardize how points are awarded across activities.

- Reward learners based on leaderboard rank or score.
- Award points when someone completes a quiz or survey.
- Award points for coaching submissions.

## Steps

### 1. Choose an assignment type

Select the assignment type that matches your use case.

![Assignment Types available](/img/helpscout/authored/authored-mu3ry93f.png)

### 2. Add rule details

Enter the **logic name** for the rule. You can also add a **point reason** and **logic description**.

![Add point name](/img/helpscout/authored/authored-mu3sbjtn.png)

### 3. Leave the rule empty for manual points

Leave **Assign Rule** empty if you want to assign points manually.

Follow the below steps to assign the points manually and use the bulk option.

### 4. Open assignment options

Click the hamburger menu to see the assignment options. Select **Assign** if you want to select and assign points to individual users.

![Select Assign option to assign points for individual users](/img/helpscout/authored/how-to-create-reward-point-rules-mu3uleu6.png)

### 5. Set manual assignment details

Select the expiry date for assigning points, then select the points and add the reason for the points. If you want to notify the user about the points assignment, select **Notify Users** and then select the users to whom you want to assign the points.

![Assign the points manually](/img/helpscout/authored/how-to-create-reward-point-rules-mu3uwugc.png)

Click **Confirm** to assign the points.

![Confirm the assignment](/img/helpscout/authored/how-to-create-reward-point-rules-mu3uxkaq.png)

### 6. Start a bulk assignment for multiple users

Select **Bulk Assign** from the hamburger menu.

![Bulk Assign](/img/helpscout/authored/how-to-create-reward-point-rules-mu3uyuq0.png)

### 7. Choose bulk upload settings

Select **Reward Type** and **User Identifier** on the page that opens.

![List od Reward Types](/img/helpscout/authored/how-to-create-reward-point-rules-mu3v35s0.png)

![Identifier of the user](/img/helpscout/authored/how-to-create-reward-point-rules-mu3v3lst.png)

### 8. Download and fill the template

Click **Download Template Option** to download the template.

Fill the template as shown below.

![fill the template](/img/helpscout/authored/how-to-create-reward-point-rules-mu3wk51h.png)

### 9. Upload the completed file

Select the **Notify Users** checkbox if you want to notify the users to whom you are assigning the points. Select the file from your system and click **Upload**.

![Upload the template](/img/helpscout/authored/how-to-create-reward-point-rules-mu3wolnq.png)

### 10. Review the upload result

After the upload completes successfully, the message below appears.

![uploaded successfully](/img/helpscout/authored/how-to-create-reward-point-rules-mu3wsp4n.png)
