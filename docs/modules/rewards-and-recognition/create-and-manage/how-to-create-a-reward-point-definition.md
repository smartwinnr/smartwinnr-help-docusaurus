> **At a glance** - Use point definitions to set up reward points, choose how users earn them, and add expiry reminders.

A point definition lets you create a reward point type in SmartWinnr. You define the point details, choose an assignment rule, and optionally add expiry reminders. Use this when you want points to be awarded automatically or managed manually.

## When to use this

Use a point definition when you want to:

- Create a new reward point type for your organization
- Award points after quiz, survey, coaching, or leaderboard activity
- Set up reminders for points that expire
- Manage point assignment from the admin area

## Steps

### 1. Open point definitions
Go to **Admin → Rewards → Points Definitions**.

![Take Points Definitions from Rewards section in Admin account](\/img\/helpscout\/authored\/authored-mu3rlb86.png)

### 2. Start a new point definition
On the list page, select **Create Point Definition**.

![Create new point definitions](\/img\/helpscout\/authored\/authored-mu3rqgsw.png)

### 3. Enter point details
Add the point **title** and **description**. You can also update the point image.

![Define the point](\/img\/helpscout\/authored\/authored-mu3rtaba.png)

### 4. Set the assignment rule
Select **Click Here** under **Assign Rule** to define how users earn points.

![Assign rule](\/img\/helpscout\/authored\/authored-mu3rx15l.png)

### 5. Choose an assignment type
Select the assignment type that matches your use case.

![Assignment Types available](\/img\/helpscout\/authored\/authored-mu3ry93f.png)

Use **Leaderboard ranking** for points based on score or rank. Use **Quiz Completion**, **Survey Completion**, or **Coaching Submission** for activity-based points.

Add the **logic name**. You can also add a **point reason** and **logic description**.

![Add point name](\/img\/helpscout\/authored\/authored-mu3sbjtn.png)

You can leave **Assign Rule** empty if you want to assign points manually.

### 6. Add expiry reminders
Use **Expiry Reminder Settings** to notify users before points expire.

![Adding Expiry Notifications](\/img\/helpscout\/authored\/authored-mu3sksd9.png)

Choose the reminder duration in **Days** or **Weeks**.

![Types](\/img\/helpscout\/authored\/authored-mu3svy3h.png)

Choose the notification type as **Email** or **Push**.

![Notification Type](\/img\/helpscout\/authored\/authored-mu3sw7cj.png)

Set the reminder duration.

![Notification duration](\/img\/helpscout\/authored\/authored-mu3swk3w.png)

You can add multiple reminders if you need more than one notice before expiry.

![Adding multiple reminders](\/img\/helpscout\/authored\/authored-mu3sz6uv.png)

### 7. Save the point definition
Select **Save** to create the point definition.

![Save Button to save the settings](\/img\/helpscout\/authored\/authored-mu3t4o2r.png)

## Things to know

:::note
**Assign Rule** is optional. Leave it blank if you want to assign points manually.
:::

:::note
**Expiry Reminder Settings** are optional. Add one reminder or several, based on your needs.
:::
