> **At a glance** - Manage reward redemption requests efficiently by updating their statuses and notifying users.

You can process reward redemption requests from users through the **Admin** section. This feature allows you to manage requests, update their statuses, and communicate with users effectively.

## When to use this
Use this feature when you need to:
- Review and manage reward redemption requests from users.
- Update the status of requests based on your decision.
- Notify users about the outcome of their requests.

## Steps

### 1. Access Redemption Requests
Go to **Admin → Rewards → Redemption Requests** to view the reward requests received from users. You will see requests with different statuses: **Request Received**, **Request In Process**, **Request Rejected**, and **Completed**.

![Request list page](/img/helpscout/authored/authored-mtq44anp.png)

### 2. Filter Requests by Status
You can filter requests by status using the dropdown menu. For instance, select **Request Received** to view all requests currently in this status.

![List of request in the request received status](/img/helpscout/authored/authored-mtq48qrb.png)

### 3. Change the Status of a Request
To update the status of a specific request, select the request and click the **Change Status** button next to it.

![Change status button](/img/helpscout/authored/authored-mtq6m8zk.png)

### 4. Update Status and Provide Feedback
Select the new status from the **Status** dropdown. If necessary, add feedback, then click the **Save** button to apply the changes.

![Change the status of the request](/img/helpscout/authored/authored-mtq6ozqk.png)

### 5. Notify the User
An email notification will be sent to the user informing them whether their request is accepted, rejected, or still in progress.

## Tips
- Regularly check the redemption requests to ensure timely processing.
- Use filters to manage large volumes of requests effectively.
- Provide clear feedback to users to enhance their experience.
