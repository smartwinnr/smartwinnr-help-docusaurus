> **At a glance** - SmartFeed Analytics allows you to track the number of views for each SmartFeed you create and those you have access to. This helps you evaluate content engagement and effectiveness.

SmartFeed Analytics provides insights into the **number of views** for each SmartFeed created by you, as well as for SmartFeeds to which you have access. This feature helps you understand the reach and engagement of your shared content.

## When to use this
Use SmartFeed Analytics to:
- Assess the performance of your SmartFeeds.
- Understand user engagement and content reach.
- Identify popular SmartFeeds and areas for improvement.

## Steps

### 1. Access SmartFeed Analytics
From the **left menu bar**, navigate to **SmartFeeds**. Click on **SmartFeed Analytics** to open the analytics dashboard.

![Once opened, you will see two tabs within the SmartFeed Analytics section, allowing you to view and analyze SmartFeed performance.](/img/helpscout/editors/how-to-view-smartfeed-analytics-1.png)

### 2. Explore the Analytics Dashboard
You will see **two tabs** within the SmartFeed Analytics section:
- **My SmartFeeds Tab**: Displays analytics for the SmartFeeds created by you.
- **Others Tab**: Displays analytics for SmartFeeds created by other editors.

You can search for a set of users or specific User and identify the SmartFeeds he/she has viewed using the **Search** box or filter SmartFeeds by selecting a date range from the **Date** filter.

### 3. Download SmartFeed Reports
You can download SmartFeed analytics reports in multiple formats to analyze user engagement in detail.

#### Available Report Types

![Available Report Types](/img/helpscout/editors/how-to-view-smartfeed-analytics-3.png)

### 4. Download Report by User
This report provides a consolidated view of SmartFeed engagement by user. Each user appears **once** in the report for each SmartFeed, along with the **total number of views** recorded for the SmartFeed.

In the **Download Report by User**, you can view user details, the associated SmartFeed information, and the **total number of views** recorded for each user.

![In the Download Report by User, you can view user details, the associated SmartFeed information, and the total number of views recorded for ](/img/helpscout/editors/how-to-view-smartfeed-analytics-4.png)

### 5. Download Report by View
This report provides a **view-level breakdown** of SmartFeed engagement. Each row represents a single view by a user for a SmartFeed, allowing you to track views **based on date**.

In the **Download Report by View**, each view is captured in a **separate row**, along with the corresponding **view date**.

![In the Download Report by View, each view is captured in a separate row, along with the corresponding view date.](/img/helpscout/editors/how-to-view-smartfeed-analytics-5.png)

### 6. Download Report by SmartFeed Comments
This report includes **user details along with their comments** on the SmartFeed, enabling you to review feedback and interactions associated with each SmartFeed.

In the **Download Report by SmartFeed Comments**, you can view the SmartFeed’s basic details, the comment details, and the information of the user who posted each comment.

![In the Download Report by SmartFeed Comments, you can view the SmartFeed’s basic details, the comment details, and the information of the us](/img/helpscout/editors/how-to-view-smartfeed-analytics-6.png)

## Tips
- Use the **Search** functionality to quickly find specific SmartFeeds.
- Regularly review analytics to stay informed about content performance.
- Leverage the insights gained from reports to improve future SmartFeeds.

## Things to know
- The analytics reflect only the views and interactions recorded within the SmartFeed platform.
- Ensure you have the necessary permissions to access SmartFeed Analytics and download reports.
