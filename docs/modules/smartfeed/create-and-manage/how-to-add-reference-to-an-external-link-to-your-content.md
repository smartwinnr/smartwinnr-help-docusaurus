> **At a glance** - SmartWinnr enables you to add references to external links in your content, enhancing the learning experience for quiz-takers.

SmartWinnr allows you to share external links via **SmarttFeed**. You can also add references to external links in the questions created in SmartWinnr, which helps quiz-takers refer to the links in the questions and answer accordingly.

## When to use this
Use this feature when you want to:
- Enhance quiz questions with relevant external resources.
- Provide additional context or information through external links.
- Improve the learning experience for users by directing them to useful content.

## Steps

### 1. Click on the link icon
Click on the **link** icon to attach an external link to your **SmartFeed** or to the question that you create in SmartWinnr. You can add links from **Dropbox**, **Box**, or any other external links as content.

![Click on the link icon to attach an external link to your SmartFeed or to the question that you create in SmartWinnr. You can add links from Dropbox and Box or any other external links as content.](/img/helpscout/editors/how-to-add-reference-to-an-external-link-to-your-content-1.png)

### 2. Fill in the link details
Once you click on the link icon, the following pop-up appears.

![Once you click on the link icon, the following pop-up comes up.](/img/helpscout/editors/how-to-add-reference-to-an-external-link-to-your-content-2.png)

Add the link title and the link URL, then click on the **submit** button.
