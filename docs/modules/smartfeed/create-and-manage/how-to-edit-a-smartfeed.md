> **At a glance** - Editing a SmartFeed allows you to update its title and content after it has been published.

Once a SmartFeed has been published, it can be edited if any changes are required.

## When to use this
Use this process when you need to update the content or title of an existing SmartFeed that has already been published. This is useful for:

- Correcting errors or outdated information.
- Adding new content or resources.
- Modifying the title for clarity or relevance.

## Steps to Edit a SmartFeed

### 1. Navigate to the SmartFeeds section
Open the **SmartFeeds** section and select the SmartFeed you want to modify.

### 2. Click the Edit option
Click the **Edit** option located in the **top-right corner** of the SmartFeed.

![Click on the edit button](/img/helpscout/authored/how-to-edit-a-smartfeed-mth5sjyf.png)

### 3. Update the SmartFeed
The **Edit SmartFeed** screen will open, allowing you to update the title and content as needed.

![Edit the different attributes](/img/helpscout/authored/how-to-edit-a-smartfeed-mth5tlj4.png)

### 4. Save your changes
After making the required changes, click the **Update** button at the bottom of the page.

Upon clicking **Update**, the SmartFeed will be successfully updated with the latest changes.
