> **At a glance** - You can create language-specific versions of supported content and assign them to the same audience. SmartWinnr shows each user the version that matches their language preference, or the default language if a translation is missing.

SmartWinnr lets you manage content in multiple languages for supported modules. You can create separate language versions of the same learning item, then assign them to users with different language preferences.

When a user opens assigned content, SmartWinnr checks their preferred language first. If a matching version exists, they see that version. If not, they see the default language version.

## When to use this

Use multilingual content when you want the same learning material to reach users in different languages.

- You need to deliver one campaign or learning item to a multilingual audience.
- You want users to see content in their preferred language when available.
- You want to keep one default version available for all users.
- You manage content in modules that support language-specific versions.

## Steps

### 1. Choose a supported module
Create your content in a module that supports multiple languages, such as **SmartFeed**, **Quiz**, **SmartPath**, **KHub**, or **Coaching**.

### 2. Select the language
In the creation or editing flow, choose the language for creating content. Then enter the title, content, questions, or other module-specific details in that language.

### 3. Assign the module once it is created
Assign the module to users as you normally would.
