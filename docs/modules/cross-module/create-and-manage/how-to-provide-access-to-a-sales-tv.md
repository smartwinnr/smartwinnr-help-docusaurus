> **At a glance** - You can share a Sales TV with a link or give another Editor access permission. Use the link when someone only needs to display it. Use access permission when they also need to manage it.

After you create a Sales TV, you can let other people open it from their own SmartWinnr account. They can then display the content on a screen without using your account. If they also need to edit the Sales TV, you can give them access permission instead.

## When to use this

Use this when you want to share a Sales TV with someone else in your organization.

- Share a link when someone only needs to open and display the Sales TV.
- Give access permission when another Editor needs to update the Sales TV content.
- Let someone use their own SmartWinnr account instead of yours.
- Allow another Editor to manage the Sales TV from the Admin portal.

## Steps

### 1. Open the Sales TV
Go to **Editor > Sales TV** and select the Sales TV you want to share.

### 2. Generate a link
Click **Generate Link** in the top-right corner.

The link is copied to your clipboard. Share it with the person who needs to display the Sales TV.

![Generate link](/img/helpscout/authored/how-to-provide-access-to-a-sales-tv-mtsd9ahk.png)

### 3. Use the shared link
The recipient should log in to SmartWinnr in the web version and paste the shared link into the browser address bar.

They can then open the Sales TV and display it on a screen.

**Manage Generated Sales TV Links:**

Once you generate a link for a Sales TV, you can view and manage the generated links from the Shared Links section at the bottom.

![shared link details](/img/helpscout/authored/how-to-provide-access-to-a-sales-tv-mtsdm4yq.png)

The section displays the details and status of each link that has been created.

What the Shared Links section shows
- **Created By**	Shows the user who generated the Sales TV link.
- **Created On**	Shows the date and time when the link was generated.
- **Expires At**	Shows the date and time when the link will expire.
- **Status**	Shows the current status of the link, such as Active or Revoked.

**Actions available for an active link:**

For an active shared link, you can perform the following actions:

- **Copy**: Copies the Sales TV link so you can share it with another user.
- **Extend**: Extends the validity of the existing shared link.
- **Revoke**: Revokes the shared link so that it can no longer be used to access the Sales TV.

**Link status** : The Status column helps you identify whether a shared link is currently available.
       
- Active: The shared link is currently valid and can be used to access the Sales TV until its expiry.
- Revoked: The shared link has been manually revoked and can no longer be used.

Note: If you need to continue using an expired or revoked link, you can generate a new link or use the available Extend option for an active link.

**Example**: If you have shared a Sales TV link with someone and want to stop access, you can locate the link under Shared Links and click Revoke. If you want the same link to remain available for a longer period, use Extend instead.

This gives you control over which Sales TV links are active, how long they remain valid, and whether access should be revoked.



### 4. Grant access permission
If another Editor needs to manage the Sales TV, open the **hamburger menu** in the top-right corner and select **Access Permission**.

### 5. Select the Editor
Choose the Editor who should have access.

That Editor can update the Sales TV from the Admin portal and view it from the SmartWinnr User view.

## Things to know

:::note
Use **Generate Link** when the person only needs to access and display the Sales TV.
:::

:::note
Use **Access Permission** when the person needs to edit or update the Sales TV content.
:::

:::warning
The shared link works only after the user logs in to their SmartWinnr account.
:::
