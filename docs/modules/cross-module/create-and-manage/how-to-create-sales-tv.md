> **At a glance** - This article explains how to create Sales TV, which displays information on screens in a slide format. Only users with EDITOR and USER roles can create and use the Sales TV feature.

Only SmartWinnr accounts with EDITOR and USER roles can create Sales TV. Sales TV is used to display information to everyone on a screen in the format of slides that change at intervals you set. You can create slides based on your requirements. Below are the steps to create Sales TV.

## When to use this
Use Sales TV when you want to display information, leaderboards, shoutouts, or widgets on a screen for your audience. This feature is particularly useful in environments where motivation and engagement are key, such as in sales teams or training sessions.

## Steps

### 1. Go to Sales TV settings
Navigate to **EDITOR > Settings > Sales TV**. Click on the create icon located in the top right corner.

![Go to EDITOR > Settings > Sales TV. Click on the create icon in the top right corner.](/img/helpscout/editors/how-to-create-sales-tv-1.jpg)

### 2. Enter title and description
Fill in the title and description fields, and select the required **Business Unit** and **Status**.

![Title and description of Sales TV](/img/helpscout/authored/how-to-create-sales-tv-mszvilb0.png)

![Enter the title and description and select the required Business Unit and Status.](/img/helpscout/editors/how-to-create-sales-tv-2.jpg)

You have three status options available:
- **Active**: Active Sales TVs can be used immediately.
- **Draft**: You can draft the Sales TV for future use and update the status to 'Active' whenever needed.
- **Inactive**: Update the status of the Sales TV to 'Inactive' when it is no longer in use.

![Sales TV status](/img/helpscout/authored/how-to-create-sales-tv-mszvk3c0.png)

### 3. Add slides for your Sales TV
You can add multiple slides to your Sales TV, which can display different types of leaderboards, widgets, etc., in each slide.

Fill in the title and description fields for the slide. Choose the **Slide Type** from the options: **Leaderboard**, **Shoutouts**, or **Widgets**.

- **Leaderboards** display data from quizzes or competitions to motivate users.
- **Shoutouts** can highlight achievements or key performance indicators (KPIs).
- **Widgets** allow you to show various dashboard elements that you have created.

![Create Slide](/img/helpscout/authored/how-to-create-sales-tv-mszvwrg7.png)

### 4. Configure leaderboard settings
If you select **Leaderboard**, you can choose the **Leaderboard Type**:
- **Group Leaderboard** to show scores of teams.
- **User Leaderboard** for individual scores.
- **Different Leaderboard available in competition** to show the score and ranking available in the selected leaderboard.
- **Quiz Leaderboard** to display results from a specific quiz.

For User Leaderboard and Group Leaderboard, select the **Competition** and the **Leaderboard** you want to display. Choose the **Ranking Type** as either **Total Points** or **Target Achieved**. Set the **Ranking Duration** to daily, weekly, or monthly based on your competition or quiz.

![Leaderboard type](/img/helpscout/authored/how-to-create-sales-tv-mszwy3jf.png)

For Quiz Leaderboard, select the quiz for which you would like to display the live leaderboard. 

![Quiz leaderboard](/img/helpscout/authored/how-to-create-sales-tv-mszwun6m.png)

### 5. Set slide duration
Define the **Slide Duration**, which determines how long each slide remains on the screen. You can set it to any duration that fits your needs.

![The Slide Duration is the timer for each slide to stay on the screen. You can set it to any duration you want.](/img/helpscout/editors/how-to-create-sales-tv-4.jpg)

### 6. Customize display options
Decide how many users to display and customize the background image according to your requirements.

![Customize display options.](/img/helpscout/editors/how-to-create-sales-tv-5.jpg)

### 7. Configure shoutouts
If you select **Shoutouts**, choose the **Shoutout Type** as either **KPI** or **Scorecard**. Set the **Ranking Type** to **Target Achievement**, along with the duration and any relevant meta tags.

Click on **'Add Shoutout objects'** to select the KPIs for which the top performer and data need to be displayed.

![Shoutout type](/img/helpscout/authored/how-to-create-sales-tv-mszx1tt2.png)

### 8. Add widgets
If you select **Widgets**, add the widgets you have created for the user view dashboard. You can choose any widget you want to display from this selection.

Click on **'Add Widget'** to select the widget that you would like to display in the slide.

![When the slide type is selected as Shoutouts, you should select the Shoutout type as KPI or Scorecard. Here the Ranking Type can be Target Achievement and duration and meta tags as per your requirements.](/img/helpscout/editors/how-to-create-sales-tv-6.jpg)

### 9. Set up ticker
Select the **Ticker Type** that you want to display in the footer of the screen. Tickers continuously show content in the footer area.

![Select the Ticker type that you want to put in the footer of the screen. (Tickers are the content that will continuously show in the footer)](/img/helpscout/editors/how-to-create-sales-tv-8.jpg)

You can choose either text or an image as a ticker. After completing all the configurations, click on the **Save** icon to finalize the creation of your Sales TV.

***

Once the Sales TV is created in the SmartWinnr admin portal, to view or display it, log in to your user view from the SmartWinnr Web version (https://web.smartwinnr.com/).

Go to the Left Menu > Sales TV, and this will list down the Sales TVs that you have created. 

![Go to left menu > Sales TV](/img/helpscout/authored/how-to-create-sales-tv-mszxre0q.png)

Click on **'Start TV'** to display the Sales TV you created.

![Sales TV view](/img/helpscout/authored/how-to-create-sales-tv-mszxs0ug.png)
