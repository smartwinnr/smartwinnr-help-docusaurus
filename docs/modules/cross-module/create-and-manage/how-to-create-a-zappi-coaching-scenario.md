> **At a glance** - Create AI-powered coaching scenarios with Zappi by selecting coaching types, defining objectives, and uploading resources.

Zappi allows you to create engaging coaching scenarios that leverage AI technology. You can configure different coaching types, set objectives, and provide supporting resources to enhance the learning experience.

## When to use this
Use Zappi when you need to create interactive coaching scenarios for learners. This feature is ideal for:
- Training sessions that require practice and feedback.
- Scenarios that need to simulate real-life conversations.
- Situations where you want to provide learners with a dynamic learning experience.

## Steps

### 1. Navigate to Zappi
Go to **Editor → Authoring Tools → Zappi**. The Zappi dashboard opens, allowing you to create a new coaching scenario.

![first page how to select zappy option from left menu](/img/helpscout/authored/authored-mrxhs3v3.png)

### 2. Select the Coaching Type
Choose the type of coaching you want to create. Available options include:
- **Self Practice**: One-way coaching where learners practice independently.
- **Conversation with AI**: Two-way coaching where learners interact with an AI-powered avatar.

![Select the coaching type](/img/helpscout/authored/how-to-create-a-zappi-coaching-scenario-mrxi2emc.png)

### 3. Select the Evaluation Type
Choose how the coaching will be evaluated. Options include:
- **Brief Evaluation**: High-level performance summary with essential metrics.
- **Detailed Evaluation**: Comprehensive feedback with performance insights and recommendations.

![Select the evaluation type](/img/helpscout/authored/how-to-create-a-zappi-coaching-scenario-mrxi3ue1.png)

### 4. Enter Basic Coaching Information
Provide the following details:
- **Coaching Title**
- **Scenario Description**

You can copy these details directly from your approved intake template.

![Enter basic coaching information](/img/helpscout/authored/how-to-create-a-zappi-coaching-scenario-mrxi570n.png)

### 5. Select the AI Persona
Choose the AI persona for the coaching. You can either:
- Select a default persona from the system.
- Create a customized AI persona by providing background, characteristics, behavior, personality, and role in the conversation.

![Select the AI persona](/img/helpscout/authored/how-to-create-a-zappi-coaching-scenario-mrxib2dc.png)

### 6. Upload Supporting Resources
Upload documents that provide additional context to the AI. Supported file types include:
- PDF
- Image files

Supporting resources can include product brochures, sales aids, clinical studies, and training material.

![Upload supporting resources](/img/helpscout/authored/how-to-create-a-zappi-coaching-scenario-mrxig4qk.png)

### 7. Configure Coaching Objectives
Define what the learner is expected to achieve during the coaching. You can either:
- Generate objectives automatically using AI.
- Add objectives manually based on the scenario.

**Objective Limits**:
- Minimum: **1 Objective**
- Maximum: **10 Objectives**

![Configure coaching objectives](/img/helpscout/authored/how-to-create-a-zappi-coaching-scenario-mrxil4y7.png)

### 8. Assign Objective Scores
Assign weightage to each objective. Ensure the total objective score equals **100%**.

![Assign objective scores](/img/helpscout/authored/how-to-create-a-zappi-coaching-scenario-mrxira65.png)

### 9. Configure Objections
Objections simulate customer resistance during the conversation. You can:
- Generate objections automatically.
- Add objections manually.

![Configure objections](/img/helpscout/authored/how-to-create-a-zappi-coaching-scenario-mrxj1gob.png)

### 10. Define Scoring
Score of Objectives score + Handling Objections + Keyword Coverage need to equal **100%**.

### 11. Select Coaching Languages
Choose the languages in which learners can take the coaching. English is selected by default, and you can add up to **3 languages** if needed.

![Select coaching languages](/img/helpscout/authored/how-to-create-a-zappi-coaching-scenario-mrxj664u.png)

### 12. Select Coaching Duration
Choose the coaching availability period. Options include:
- One Day
- One Week
- One Month
- Custom Date Range

![Select coaching duration](/img/helpscout/authored/how-to-create-a-zappi-coaching-scenario-mrxj7b1y.png)

### 13. Create the Coaching Scenario
After completing all mandatory fields, click **Create Coaching Scenario**. A progress bar appears indicating the coaching creation status.

![Create the coaching scenario](/img/helpscout/authored/how-to-create-a-zappi-coaching-scenario-mrxj8ww1.png)

### 14. Preview the Coaching
Once the scenario is created, preview it to ensure everything is configured correctly. The preview displays all relevant details.

![Preview the coaching](/img/helpscout/authored/how-to-create-a-zappi-coaching-scenario-mrxjezpb.png)

### 15. Start a Trial Run
Click **Try Now** to test the coaching. This allows you to experience the learner journey and verify AI responses.

![Start a trial run](/img/helpscout/authored/how-to-create-a-zappi-coaching-scenario-mrxjibfd.png)

## Tips
- Use a clear and descriptive coaching title.
- Upload accurate and updated supporting resources.
- Keep objectives measurable and scenario-specific.
- Assign score weightage carefully so that the total equals **100%**.
- Always preview the coaching before assigning it to users.

## Things to know
- English is the default coaching language.
- A maximum of **10 objectives** can be added.
- A maximum of **3 coaching languages** can be selected.
- Supporting resources are limited to **PDF** and **image** formats.
- Coaching creation may take several minutes depending on the uploaded resources and AI processing time.
