> **At a glance** - This article outlines how to create customer engagement content, including images and descriptions.

iShare content is designed for sharing customized templates for various purposes. Within the **iShare** content system, there are several content types: **iShare**, **customer engagement content**, **YouTube links**, **visiting cards**, and **iShare links**. 

iShare content types enable users to create a wide range of materials, such as greetings and birthday cards, using custom templates. In the **customer engagement content** category, users can generate images with accompanying descriptions. This is particularly useful for presenting policies and terms and conditions to stakeholders. For **YouTube** content, users can conveniently share YouTube video URLs through this content type, allowing users to view the video directly within the app. **Visiting card** content enables users to create and share digital visiting cards, making networking and contact sharing more convenient. With **iShare links**, users can insert external links, providing easy access for users to check external web content.

## When to use this
Use this feature when you need to:
- Present important policies or terms to stakeholders.
- Create visually appealing content for customer interactions.
- Organize information for better understanding and engagement.

## Before you start
Ensure you have access to the customer engagement content creation feature in your platform, specifically within the **iShare** module.

## Steps

### 1. Access the iShare Gallery
Go to **EDITOR > LEARNING AND KNOWLEDGE > iShare > Gallery**, then click on the **Create** button in the left corner and select an item from the Gallery as per the screenshot given.

![Access the iShare Gallery](/img/helpscout/authored/understanding-customer-engagement-content-creation-mrzxxjfp.png)

### 2. Choose Essentials
There are some essentials to choose from; select those according to your needs. The explanation is given below.

### Content-Type
In the **customer engagement content** category, users can generate images with accompanying descriptions. This is particularly useful for presenting policies and terms and conditions to stakeholders.

### Status
- **Draft**: This is the default status set by the system when the editor creates content inside the **iShare** module. If the content is in Draft status, it won’t be visible to any users; it is only visible to Admins and Editors.
  
- **Review Overdue**: This status applies when you add a review date to the content. When you enable the review date for the content, the system sends a notification to the editor group responsible for reviewing the content. This email notification is sent 7 days prior to the review date set. The content will remain in the Review Overdue status until the email notification is sent to the editor group.

- **Due For Review**: This status applies when you add a review date to the content. When you enable the review date for the content, the system sends a notification to the editor group responsible for reviewing the content. This email notification is sent 7 days prior to the review date set, and then the content will be in the Due for Review status. Once the review is done, the editor should manually update the status to **Published** to make the content visible to users.

- **Published**: When the content is in Published status, it will be visible to all users.

- **Archived**: When the content is in Archived status, it won’t be visible to anyone.

### Tags
If you want to assign tags to a specific group of people, you can utilize this tagging feature.

### Customer Profile
If you wish to choose a specific customer profile for any of your **iShare** content, you can do so by utilizing the **Customer Profile** feature.

### Title
Provide the title of the content.

### Description
Enter the description of that **iShare** content.

### Footer Details
You can customize the footer details to display any information you want.

![Footer details customization](/img/helpscout/authored/understanding-customer-engagement-content-creation-mrzx2ztk.png)

### 3. Add Section
After clicking on **Create**, you will see the following page. To add a section, click **Add Section**.

![Add Section to include a new section](/img/helpscout/authored/understanding-customer-engagement-content-creation-mrzxk35z.png)

In this section, you need to provide the **Tab Title**, **Section Heading**, select the **Image**, and add **Bullet Points**.

### 4. Fill in the Section Details
Select the image that you want to describe. In the **Bullet Point** section, you can describe what you need to.

![Fill in the section details](/img/helpscout/authored/understanding-customer-engagement-content-creation-mrzx9ozm.png)

You can add bullet points, edit them, and also delete points as needed.

### 5. Add Multiple Sections
You can add as many sections as you wish.

![Add multiple sections](/img/helpscout/authored/understanding-customer-engagement-content-creation-mrzx9ozm.png)
