> **At a glance** - You can post queries through the SmartWinnr Mobile App or Web App (PWA) using the QResolve feature.

You can post queries through both the SmartWinnr Mobile App and the SmartWinnr Web App (PWA). This feature allows you to reach out for assistance by submitting your questions or issues directly.

## When to use this
Use this feature when you need to ask a question or report an issue related to your work in SmartWinnr. This is particularly useful for:

- Seeking clarification on a task or process.
- Reporting a technical issue.
- Requesting additional information or support.

## Steps

### 1. Log in
Sign in to the SmartWinnr Mobile App or SmartWinnr Web App (PWA).

### 2. Open QResolve
Navigate to the **QResolve** section in the left menu.

### 3. Create a New Query
Click the **+ (Plus)** icon available at the bottom-right corner of the screen.

![Creating a new query in QResolve](/img/helpscout/authored/how-to-use-qresolve-in-the-smartwinnr-app-mrvwgfc9.png)

### 4. Select a Tag/Category
Choose the appropriate Query Type (Tag/Category) that best matches your query.

- Selecting the correct Tag/Category ensures that your query reaches the appropriate SPOC.

![Selecting a tag/category for the query](/img/helpscout/authored/how-to-use-qresolve-in-the-smartwinnr-app-mrvwjgwv.png)

### 5. Enter Your Query
Provide a clear description of your question or issue.

- If required, you can also attach supporting documents related to your query.

Examples of attachments include:

- Images
- PDF documents
- Screenshots
- Other supporting files

### 6. Submit
Click **Submit** to post your query

The query will now be available for the assigned SPOC to review and respond.
