QResolve is SmartWinnr's query management feature that enables users to raise questions, seek clarification, and report issues related to their organization, products, processes, or any work-related topic.

Queries are organized using **Tags/Categories**, ensuring they are automatically routed to the appropriate **Subject Matter Expert (SPOC)** for resolution.

QResolve provides a centralized platform where users can track their queries and receive responses from the designated SPOCs.

### How QResolve Works

QResolve follows a simple workflow:

1. A user raises a query by selecting the appropriate Tag/Category.
2. The query is automatically assigned to the SPOC mapped to that Tag/Category.
3. The SPOC reviews the query and submits a response.
4. The user can view the response within QResolve.
