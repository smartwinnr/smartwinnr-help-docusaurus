> **At a glance** - This article explains how to set reminders for tasks, including scheduling options and message customization.

This feature lets you set a reminder and schedule it to be delivered to users about the status of the task. To schedule a reminder, click on the **Add** button at the top right corner of the **Schedule Reminder** section. This action will open a popup.

## Steps

### 1. Choose Send Type

In the popup, select the **Send Type**. This field lets you decide if you want to send the reminder on a specific date or if you want to send it depending on the end date of the quiz.

![describe this screenshot](/img/helpscout/authored/how-to-set-reminder-for-your-tasks-msr2t1xu.png)

### 2. Set Date to Send

Select the **Date to send**. Here, choose the date and time when you want to send the reminder.

![Date to send selection](/img/helpscout/editors/how-to-set-reminder-for-your-tasks-2.png)

### 3. Specify Days Before End

If you selected "Depends on Quiz End Date," you will see the **Send before end (In Days)** field. Enter the number of days before the end date of the quiz when you want to send the reminder.

![Send before end field](/img/helpscout/editors/how-to-set-reminder-for-your-tasks-3.png)

### 4. Choose Recipients

In the **Send To** field, choose to send the reminder to "Everyone" or a specific "Group."

![Send To selection](/img/helpscout/editors/how-to-set-reminder-for-your-tasks-4.png)

### 5. Filter Recipients

Use the **Filter By** option to filter the quiz takers to whom you want to send the reminder. There are three options to choose from: "All," "Completed," or "Not Completed."

![Filter By options](/img/helpscout/editors/how-to-set-reminder-for-your-tasks-5.png)

### 6. Select Teams

If you selected "Group" in the **Send To** field, you must select the teams to whom you want to send the reminder in the **Teams** section.

![Teams selection](/img/helpscout/editors/how-to-set-reminder-for-your-tasks-6.png)

### 7. Customize Message

In the **Message** field, you will see the auto-generated message that will be sent in the reminder. You can modify this message according to your requirements.

![Message customization](/img/helpscout/editors/how-to-set-reminder-for-your-tasks-7.png)

### 8. Save the Reminder

Once you have filled in all these fields for the reminder, click on the **Save** button. This action will successfully add the reminder to the quiz.

![Reminder saved confirmation](/img/helpscout/editors/how-to-set-reminder-for-your-tasks-8.png)

After filling out all the details on this page, click on the **Save and Add Questions** button to save the quiz.
