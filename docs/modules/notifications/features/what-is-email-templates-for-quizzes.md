> **At a glance** - Use **Email Templates** to design quiz notification emails, personalize them with placeholders, and assign them to specific quizzes.

**Email Templates** lets you create reusable email designs for quiz notifications. You can customize the subject, content, language, and template status from one place. You can also attach a template to a quiz so learners receive the right email for that quiz event.

## When to use this

Use **Email Templates** when you want more control over quiz emails than the standard template provides.

- You want different email content for different quiz events.
- You want to personalize emails with learner and quiz details.
- You want one template to support multiple languages.
- You want to limit a template to specific divisions.
- You want to choose which template a quiz sends.

## Before you start

- You need admin access to create or change templates.
- **Email Templates** is available from the admin menu.
- Only templates marked **Active** appear on quiz pages.
- A template attached to a quiz cannot be deleted until you remove it from that quiz.

## Steps

### 1. Open **Email Templates**
Go to **Admin → Email Templates** to view the template library. From here, you can search templates and manage them in one place.

![admin>email templates](/img/helpscout/authored/authored-mwm1ycmz.png)

### 2. Create a new template
Select **New Template** in the top-right corner to start a quiz email template.

![click on the new template in top right corner](/img/helpscout/authored/authored-mwm204gx.png)

### 3. Choose a quiz email type
Pick the quiz email you want to customize. The available quiz templates include **Quiz Assigned**, **Auto Quiz Assigned**, **Auto Quiz Passed**, **Auto Quiz Failed**, **Auto Quiz Completed**, **Quiz Reassigned**, and **Learner Completed Quiz**.

![which all templates we can edit](/img/helpscout/authored/authored-mwm21qse.png)

### 4. Set the template details
Fill in the basic settings for the template, including **Name**, **Status**, and **Divisions**. Use **Active** when you want the template to be available for quizzes. Use **Draft** when you want to keep it in the library without selecting it for a quiz.

![basic setting](/img/helpscout/authored/authored-mwm324hn.png)

### 5. Build the email content
Use the block builder to shape the email body. You can add headings, text, buttons, info cards, dividers, spacers, and images. You can also edit the subject, greeting, and title.

Keep **English** as the default language, or select **Add** to include more languages for the same template.

![ss](/img/helpscout/authored/what-is-email-templates-for-quizzes-mwm3m5ka.png)

### 8. Preview the email
Use the preview to review the template with sample data before you send it to learners.

![email preview](/img/helpscout/authored/authored-mwm38eu6.png)

### 9. Attach the template to a quiz
Open the quiz settings and turn on **Use custom email templates**. Then choose the template for each quiz email and save your changes.

![go to quiz setting enable this option](/img/helpscout/authored/authored-mwm3cb6a.png)

![after clicking choose this tab will open you can select the templated created in systrem and save then users assigned to this quiz will recive new email tempalte](/img/helpscout/authored/authored-mwm3djsl.png)

Users who are assigned to that particular quiz will receive the email notification using the newly configured Quiz Assigned Email Template
