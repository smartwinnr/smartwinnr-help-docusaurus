> **At a glance** - Learn how to create an iShare, including folders and items within it.

Creating an iShare allows you to organize and share knowledge effectively. You can create folders to categorize content and add items within those folders for easy access.

## When to use this
Use this feature when you want to:
- Organize learning materials for your team.
- Create a structured knowledge base.
- Share specific content with different user groups.

## Steps

### 1. Navigate to the iShare Gallery
Go to **Editor > LEARNING AND KNOWLEDGE > iShare > Gallery**. This will open the iShare management page.

![Navigate to the iShare Gallery](/img/helpscout/authored/what-is-an-ishare-and-how-to-manage-its-contents-mryl9ijq.png)

### 2. Create a Folder
Click on the **Create** button at the top left corner, then select the **Folder** option. A pop-up will appear for folder creation.

![Create a Folder](/img/helpscout/authored/what-is-an-ishare-and-how-to-manage-its-contents-mrylabzm.png)

### 3. Fill in Folder Details
Provide a title for the folder and a short description. If you want to change the folder icon, click **Change Icon** and upload your desired icon.

![Fill in Folder Details](/img/helpscout/authored/what-is-an-ishare-and-how-to-manage-its-contents-mrylbgqm.png)

### 4. Create the Folder
Once you have filled in all the details, click on the **Create** button. Your folder will be created successfully.

### 5. Open an Existing Folder
To add items, open the folder you just created or any existing folder. Click on the **dropdown** button at the folder name, then select **Item**. This will open a page where you can create shareable content.
![Open an Existing Folder](/img/helpscout/authored/what-is-an-ishare-and-how-to-manage-its-contents-mrym5d6f.png)

### 6. Fill in Item Details
Enter the necessary details about the item and upload the document you wish to share.

![Fill in Item Details](/img/helpscout/authored/what-is-an-ishare-and-how-to-manage-its-contents-mrylea17.png)

### 7. Item Status
The status of an item can be set as follows:

- **Draft**: This is the default status set by the system. When the editor creates content inside the iShare module, it will not be visible to any users; it is only visible to Admins and Editors.

- **Review Overdue**: This status applies when you add a review date to the content. When you enable the review date, the system sends a notification to the editor group responsible for reviewing the content. This email notification is sent 7 days prior to the review date set.

- **Due For Review**: This status is applicable when a review date is added. The system sends a notification to the editor group 7 days before the review date. Once the review is done, the editor should manually update the status to **Published** to make the content visible to users.

- **Published**: When the content is in the Published status, it will be visible to all users.

- **Archived**: When the content is in the Archived status, it will not be visible to anyone.

![Item Status](/img/helpscout/authored/what-is-an-ishare-and-how-to-manage-its-contents-mryljmxc.png)

### 8. Item Language
You can set the language for the item. The default language is English.
![Item Language](/img/helpscout/authored/what-is-an-ishare-and-how-to-manage-its-contents-mryll5j0.png)

### 9. Item Tags
If you want to assign tags to a specific group of people, you can utilize this tagging feature.
![Item Tags](/img/helpscout/authored/what-is-an-ishare-and-how-to-manage-its-contents-mryllvnb.png)

### 10. Customer Profile
Choose a specific customer profile for any of your iShare content using the Customer Profile feature.
![Customer Profile](/img/helpscout/authored/what-is-an-ishare-and-how-to-manage-its-contents-mrylp8b0.png)

### 11. Expires On
You can modify the expiry date to suit your specific needs.
![Expires On](/img/helpscout/authored/what-is-an-ishare-and-how-to-manage-its-contents-mrylq5kc.png)

### 12. Title and Description
Provide a title and description for the iShare content.
![Title and Description](/img/helpscout/authored/what-is-an-ishare-and-how-to-manage-its-contents-mrylrs3m.png)

### 13. Upload Image
Within the Custom Template, you have the option to easily drag and drop available templates.
![Upload Image](/img/helpscout/authored/what-is-an-ishare-and-how-to-manage-its-contents-mrylsr3a.png)

![Custom Template](/img/helpscout/authored/what-is-an-ishare-and-how-to-manage-its-contents-mrylv6dz.png)

### Select Action
There are several actions you can perform in iShare:

- **Move**: Relocate the item or folder to a different location. Once you select this option and click on **Apply**, you can choose the folders or items as needed.

![Select Action - Move](/img/helpscout/authored/what-is-an-ishare-and-how-to-manage-its-contents-mrym9f86.png)

After selecting the necessary folder/item by checking the box next to it, click on **Apply**. A popup will appear showing a list of folders in iShare. Select the folder you want to move the item or folder to, then click on **Move**.
![Move Item](/img/helpscout/authored/what-is-an-ishare-and-how-to-manage-its-contents-mrymazf7.png)

- **Delete**: This option enables you to delete the folder or item. Select **Delete** from the dropdown. Once the small delete icon appears next to each item/folder, you can click it to delete as needed.

![Select Action - Delete](/img/helpscout/authored/what-is-an-ishare-and-how-to-manage-its-contents-mrylhc82.png)
![ishare-detail](/img/helpscout/authored/what-is-an-ishare-and-how-to-manage-its-contents-mrynrdwt.png)
## Tips
- Use clear and descriptive titles for folders and items to enhance navigation.
- Regularly update the content in your iShare to keep it relevant.

## Things to know
:::caution
Ensure that you have the necessary permissions to create and manage iShares within your organization.
:::
