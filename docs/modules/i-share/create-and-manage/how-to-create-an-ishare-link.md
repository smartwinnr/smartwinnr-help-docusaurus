> **At a glance** - Learn to create an iShare Link that allows users to access external web content easily.

iShare Links enable users to insert external links, making it simple for others to check web content outside your platform. You can also assign tags and select specific customer profiles for your iShare content.

## When to use this
Use iShare Links when you want to:
- Provide access to external resources or content.
- Assign tags to specific groups for better organization.
- Choose a customer profile for targeted content delivery.

## Before you start
No prerequisites are required to create an iShare Link.

## Steps

### 1. Navigate to the iShare Gallery
Go to **LEARNING AND KNOWLEDGE > iShare > Gallery**. Click on **Create > Item** as shown in the screenshot below.

![This screenshot shows the navigation path to create an iShare Link](/img/helpscout/authored/how-to-create-an-ishare-link-ms7gv5e8.png)

### 2. Insert the External Link
In the iShare link content type, locate the **iShare Link** field. Enter the link that you want to redirect users to.

![This screenshot shows the External Link field in the iShare Link content type](/img/helpscout/authored/how-to-create-an-ishare-link-ms7dul69.png)

### 3. Assign Tags
If you want to assign tags to a specific group of people, utilize the tagging feature available in the iShare setup.

### 4. Choose a Customer Profile
Select a specific customer profile for any of your iShare content using the **Customer Profile** feature.

### 5. Provide a Title and Description
Enter a title and description for your iShare content to ensure users understand the purpose of the link.

After providing all the necessary details, click on the **Create** button.
