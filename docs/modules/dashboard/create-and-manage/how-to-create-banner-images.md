Create banner images in **Editor → Gamification and Engagement → Banners**. You can add a banner, choose its division, and pick the banner type that fits your content.

Use this when you want to promote content or surface an announcement in the banner area. Banner types include **Image slide**, **Video**, and **Popup**.

## When to use this

Use banner images when you want to:
- Show a visual announcement in the banner area.
- Add an image-based banner for a specific division.
- Upload a banner that fits the **Image slide** format.
- Create a banner alongside other banner types, such as **Video** or **Popup**.

## Steps

### 1. Open the Banners page
Go to **Editor → Gamification and Engagement → Banners**.

### 2. Start a new banner
Select **Add banner** in the top-right corner as shown below.
![Click on add banner](/img/helpscout/authored/how-to-create-banner-images-mwt4c900.png)

### 3. Choose the banner details
Select the **division** and **Banner type**.

### 4. Upload an image slide
If you choose **Image slide**, select an image with a 16:9 ratio. Make sure the file size is within 2 MB.

### 5. Save the banner
After you select the image you want, click **Save banner**.
