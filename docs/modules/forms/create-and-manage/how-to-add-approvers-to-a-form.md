> **At a glance** - Editors can add approvers to forms to manage approval workflows effectively.

An Editor who has access to the form can add approvers to the form. This feature allows you to designate specific individuals who will review and approve submissions made through the form.

## When to use this
Use this feature when you need to:

- Ensure that certain individuals review form submissions.
- Manage approval workflows for forms effectively.
- Assign approvers at different levels within your organization.

## Steps

### 1. Navigate to Forms
Go to **Left Menu** >> **Editor** >> **Forms** >> **View All Forms**.

![Go to Left Menu >> Editor >> Forms >> View All Forms.](/img/helpscout/editors/how-to-edit-a-form-on-submitted-by-a-user-1.jpg)

### 2. Select the Form
Select the form you want to add an approver to and click on the form.

![Select the form you want to add an approver and click on the form.](/img/helpscout/editors/how-to-add-approvers-to-a-form-1.jpg)

### 3. Access Approver Settings
After selecting the form, click on the hamburger icon at the top right side, then select **Approvers**.

![After selecting the form, click on the hamburger icon at the top right side, where you should select Approvers](/img/helpscout/editors/how-to-add-approvers-to-a-form-2.jpg)

### 4. Manage Approvers
Click on **Manage Approvers** where you can add the approvers.

![After this, you need to click on Manage Approvers where you can add the approvers.](/img/helpscout/editors/how-to-add-approvers-to-a-form-3.jpg)

### 5. Select Approvers
Select the approvers you want to add and click on the **Finish** icon to complete adding the approvers.

![Select the approvers you want to add and click on Finish icon to complete adding the approvers.](/img/helpscout/editors/how-to-add-approvers-to-a-form-4.jpg)

### 6. Assign Approvers to Users
Once you have successfully added the approvers to the form, you can assign the approvers to various users at different levels. Initially, the approver is not assigned to any users. Click on the **Edit** option to assign the approvers to different users in the system.

![Click on Edit option](/img/helpscout/authored/how-to-add-approvers-to-a-form-msznf7ip.png)

### 7. Select Users
You will be taken to a page where you can select various users at different levels.

![Select users at different levels](/img/helpscout/authored/how-to-add-approvers-to-a-form-mszng56a.png)

If you want to assign the approver for all users, select "User" from the dropdown **Selection Type** and "All Users" from the next dropdown **Selected Users**. You can also choose users by selecting Groups or meta tags from the **Selection Type** dropdown and selecting the appropriate group names and meta tag values from the provided dropdowns.

After selecting the desired users or reportees, click on the **OK** button to assign the approver to the selected users for the form.

### 8. Upload Form Approvers in Bulk
You can also add approvers in bulk by using the **Bulk Approvers** option. Click on the hamburger icon beside **Manage Approver** and select **Bulk Approvers**.

![Upload users in bulk](/img/helpscout/authored/how-to-add-approvers-to-a-form-msznhi9j.png)

Download the sample CSV file and fill in the details based on the User Mapping, which can be Email Address or Org User Identifier.

![Download CSV template](/img/helpscout/authored/how-to-add-approvers-to-a-form-msznhzyp.png)

The file needs to be in CSV format. For the best result, save the spreadsheet as CSV UTF-8 (Comma delimited). Without UTF-8 encoding, non-English characters in the file might not display correctly.

![CSV Template](/img/helpscout/authored/how-to-add-approvers-to-a-form-msznsi7w.png)

You will be able to upload the approvers and corresponding reportees by providing their email ID or org user identifier in the CSV file.

The selection type will help you choose to upload for a user individually, for a group, or even for a specific meta tag.

Click on **Choose File**, select the CSV format file, and upload the approver data. This will successfully upload the approvers and their corresponding users or reportees for whom the approver is assigned.
