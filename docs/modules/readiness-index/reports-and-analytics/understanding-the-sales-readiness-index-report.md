> **At a glance** - The **Sales Readiness Index Report** gives you a user-wise view of readiness for a selected reporting period. You can download it, then review scores, user details, organisational details, and module activity.

Use this report when you need a detailed view of sales readiness for individual users. It helps you review scores for a specific period and compare readiness across organisational groups.

## When to use this

Use the **Sales Readiness Index Report** when you want to:

- Review a user's **Knowledge**, **Skill**, **Engagement**, and overall **Readiness Index** scores.
- Check each user's **Proficiency Level**.
- Review **Modules Completed** and **Active Modules**.
- Analyse readiness by **Business Unit**, **Country**, **Region**, **Zone**, or **Territory**.
- Check user details such as status, type, and employee information.
- Review readiness data for a specific reporting period.

## Steps

### 1. Open Sales Readiness Index
Go to **Editor Portal > Readiness Index > Sales readiness index**.

![select sales readiness index](/img/helpscout/authored/authored-mwx8czbv.png)

### 2. Start the download
On the **Sales Readiness Index Analytics** page, click the hamburger menu in the top-right corner. Then select **Download Readiness Index Report**.

![click on download readiness index report](/img/helpscout/authored/authored-mwx8jcgf.png)

### 3. Choose the report options
In the download window, select the report format and date range. You can choose **Excel (.xlsx)** or **CSV (.csv)**, and select **Last 7 days**, **Last 30 days**, or **Last 90 days**. Then click **Download**.

![Select the report format and date range to generate the report for download](/img/helpscout/authored/authored-mwxbl0zo.png)

The report runs in the background. When it is ready, it appears in **Generated Reports** with a download link.

### 4. Open Generated Reports
In the **Editor Portal**, go to **Reports > Generated Reports** from the left menu.

![under reports click generated reports](/img/helpscout/authored/understanding-the-sales-readiness-index-report-mwxehh6a.png)
### 5. Find and download the report
Select **My Generated Reports** to see reports you created. Select **Other Generated Reports** to see reports created by others.

Use the date options at the top to filter reports by **30D**, **90D**, or a custom date range. To use a custom range, click the calendar icon, enter the **Start Date** and **End Date**, then click **Apply**.

![select the custom date range and click apply](/img/helpscout/authored/authored-mwxbz34f.png)

You can also filter by **Status**, **Type**, **Search by Name**, and **Search by Tag**. Click **Apply Filters** to show matching reports, or **Clear All** to reset the filters.

Find **Readiness Index Overall Report** and click the download icon.

![View your generated reports, filter them by date and other criteria, and download the Readiness Index Overall Report](/img/helpscout/authored/authored-mwxbz31j.png)

## What the report contains

The downloaded report provides detailed information about individual users across these categories.

### 1. User Information

- **User Name**
- **Email**
- **Employee Code**
- **User Identifier**
- **User Status**
- **User Type**
- **Deactivated On**

### 2. Organisational Information

- **Business Unit**
- **Country**
- **Zone**
- **Designation**
- **Product Line**
- **Territory**
- **Therapeutic Area**
- **District**
- **Region**

### 3. Readiness Scores

- **Knowledge Score**: The user's Knowledge score.
- **Skill Score**: The user's Skill score.
- **Engagement Score**: The user's Engagement score.
- **Readiness Index**: The user's overall readiness score.
- **Readiness (0–10)**: The readiness score on a 0–10 scale.
- **Proficiency Level**: The proficiency level corresponding to the readiness score.

### 4. Module Activity

- **Modules Completed**: Number of modules completed by the user.
- **Active Modules**: Number of active modules for the user.

### 5. Report Period

- **Period Start**: Start date of the reporting period.
- **Period End**: End date of the reporting period.

## Things to know

:::note
The downloaded report includes user information, organisational information, readiness scores, module activity, and the reporting period.
:::

:::note
The report list shows the report name, tags, type, status, and creation date.
:::
