> **At a glance** - Question Studio is an AI-powered authoring tool that generates draft quiz questions from uploaded learning content, allowing editors to review and publish questions to the Question Bank.

Question Studio helps you create quiz questions from training documents and learning content in just a few steps. Upload your content, configure the question generation settings, and let AI generate draft questions. Before any question is published, editors can review, edit, tag, or delete the generated questions to ensure they are accurate and ready for use in quizzes and assessments.

## When to use this
Use Question Studio when you want to:
- Generate quiz questions automatically from training documents or learning content.
- Create multiple questions in different formats using AI.
- Review, edit, tag, or delete draft questions before publishing.
- Publish questions to the Question Bank for use in SmartWinnr quizzes and assessments.

## Supported File Types
Question Studio supports the following file formats for question generation:
- PDF documents
- Microsoft Word documents (.doc/.docx)
- Images (.JPG, .PNG, .WebP)

Maximum total upload size: 25 MB.

## How Question Studio Works
Question Studio generates draft questions from the uploaded content based on your selected language, difficulty level, question types, and the number of questions. All generated questions are placed in a review queue before they can be published.Can also add Categories & Tags for questions.

## Review and Publishing
After generation, editors can:
- View and review all AI-generated draft questions.
- Edit question text, answer options, feedback, or other details.
- Add Categories & Tags for better organization.
- Delete unwanted or incorrect questions.
- Use the drop-down menu to change the business unit for the generated questions, if required.
- Click Export to download all generated questions as an Excel (.xlsx) file. The exported file includes Question Text, Categories, Question Type, Answer Options (1–7), Correct Options, Feedback, Language, and Created On.
- Click Resources to view and download the source files that were uploaded for question generation.
- Publish questions to the Question Bank.


## Tips
- Review each AI-generated question for accuracy and relevance before publishing.
- Use tags and categories to organize questions for future quizzes.

## Things to know
Questions remain as drafts until they are published. Only approved questions are added to the Question Bank and become available for creating quizzes in SmartWinnr.
