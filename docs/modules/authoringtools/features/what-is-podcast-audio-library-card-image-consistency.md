A podcast now uses one image consistently across its Audio Library card, episode thumbnails, and editor player preview. That makes it easier to recognize a podcast at a glance and avoid visual mismatches.

This applies automatically when you generate a new podcast from **Authoring Tools > Create New Audio**. Non-podcast content, such as Narration, is not affected.

## When to use this

Use this when you want to understand how podcast artwork appears after generation.

- You want the Audio Library card to match the podcast’s episode thumbnails.
- You want the editor preview to show the same image as the library card.
- You are checking a newly generated podcast and want consistent visuals across views.

## Things to know

:::note
If you do not see this behavior, contact SmartWinnr support.
:::
