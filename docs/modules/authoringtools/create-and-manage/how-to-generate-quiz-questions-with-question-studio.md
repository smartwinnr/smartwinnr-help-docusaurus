> **At a glance** - Create AI-powered quiz questions from uploaded content by selecting your preferred question settings. Question Studio automatically creates draft questions that are ready for review and publishing to the Question Bank.

Question Studio helps you quickly create quiz questions from documents using AI. Upload your content, configure the question generation settings, and generate the required number of questions. You can then review, edit, tag and publish the approved questions to the Question Bank for use in quizzes and assessments.

## When to use this
Use Question Studio when you need to generate quiz questions efficiently from training documents or learning content. This feature is ideal for:

- Creating multiple questions in different formats, such as Multiple Choice, True or False, Fill in the Blanks, and Short Answer.
- Customizing question generation by selecting the language, difficulty level, and the number of questions.
- Reviewing, editing, and organizing AI-generated questions before publishing them to the Question Bank for future quizzes and assessments.

## Steps

### 1. Navigate to Question Studio
Log in to the editor portal and select **AUTHORING TOOLS** → **Question Studio** → **New Questions**. 
![kindky select new questions option](/img/helpscout/authored/how-to-generate-quiz-questions-with-question-studio-mtibe44r.png)

### 2. Configure Question information
Provide the basic details for your question set before generating questions.
- **Business Unit**: Select the business unit from the top-right corner under which you want to save the questions.
- **Title**: Enter a suitable title for the question set (Required).
- **Description**: Optionally, add a brief description to provide context for the question set.

### 3. Configure Question Settings
Configure how AI should generate your quiz questions.

- **Question Types**: Select one or more question types. Question Studio supports:
  - Multiple Choice (Single Answer)
  - Multiple Choice (Multiple Answers)
  - Fill in the Blanks
  - True or False
  - Short Answer
![provide the details](/img/helpscout/authored/how-to-generate-quiz-questions-with-question-studio-mtibesba.png)
- **Difficulty Level**: Choose the difficulty level for the generated questions (Easy, Medium, or Hard).
- **Number of Questions**: Specify the total number of questions you want AI to generate from the uploaded content.

### 4. Configure Language
Select the language in which you want the AI to generate quiz questions. Question Studio supports multiple languages, including English, Spanish, French, German, and many more.

- **Fixed Number of Options**: Select the checkbox to keep the number of answer options consistent across all multiple-choice questions.

### 5. Upload Content
Upload the source content from which Question Studio will generate quiz questions.

- Click the upload area or drag and drop your files.
- Supported file formats include PDF, Word documents, and images (JPG, PNG, and WebP).
- The maximum total upload size is 25 MB.

### 6. Generate Questions
Review the selected question generation settings and click **Generate Questions**. Question Studio processes the uploaded content and generates AI-powered draft questions. The processing time may vary depending on the size and complexity of the uploaded content.
![kindly click generate questions option](/img/helpscout/authored/how-to-generate-quiz-questions-with-question-studio-mtibobft.png)
### 7. Generation Status
After clicking **Generate Questions**, you will be redirected to the Question Generation Status page, where you can track the progress of the AI question generation process.
![generation status](/img/helpscout/authored/how-to-generate-quiz-questions-with-question-studio-mtibpazt.png)
- Wait until the generation status reaches 100%.
![kindly click on review questions option](/img/helpscout/authored/how-to-generate-quiz-questions-with-question-studio-mtibsnv4.png)
- Once the generation is complete, click **Review Questions**.
### 8.  Generated Questions
The Review Questions page displays all the AI-generated draft questions created from the uploaded content, ready for review, editing, tagging, and publishing to the Question Bank.

### 9. Publish and Export Questions
After the questions are generated, the Generated Questions page displays all AI-created draft questions from the uploaded content.

View, tag, edit, or delete generated questions before publishing them to the Question Bank.

- **Business Unit**: Use the drop-down menu to change the business unit for the generated questions, if required.

- **Publish Questions**: Click **Publish Questions** to publish all approved questions to the Question Bank. Once published, the questions become available for creating quizzes in SmartWinnr (click on confirm publish option to publish).
![click on confirm publish option to publish](/img/helpscout/authored/how-to-generate-quiz-questions-with-question-studio-mtibuzyj.png)
- **Export**: Click **Export** to download all generated questions as an Excel (.xlsx) file. The exported file includes details such as Question Text, Categories, Question Type, Answer Options (1–7), Correct Options, Feedback, Language, and Created On.
- **Resources**: Click **Resources** to view and download the source files that were uploaded for question generation.
![kindly click on publish questions option to publish questions to the question bank](/img/helpscout/authored/how-to-generate-quiz-questions-with-question-studio-mtibul5j.png)

**Tip:** Review each generated question for accuracy, relevance, and correct answer options before publishing it to the Question Bank.


**Caution:** Make sure the uploaded files are in a supported format and within the allowed size limit for successful processing.
