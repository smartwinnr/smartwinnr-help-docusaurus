> **At a glance** - Open Zappy to browse your coaching library, create a new coaching, refine each section, and save or publish the result.

Zappy gives you a guided way to build coaching content from a chat-style studio. You can start from a library view, create a new coaching, review each section, and make changes before you save or publish.

Use it when you want to build a coaching from a structured workflow instead of starting from scratch. It helps you shape the role play, the learner’s conversation partner, supporting product details, and the final coaching settings in one place.

## When to use this

Use Zappy when you need to:

- Create a new coaching from the library view.
- Search existing coachings or filter them by status.
- Review and edit a coaching before publishing.
- Save a coaching as a draft for later work.
- Publish a coaching when it is ready for learners.

## Before you start

Make sure Zappy is available in your organization. If you do not see it, contact SmartWinnr support.

## Steps

### 1. Open Zappy
Open **Authoring Tools** and select **Zappy**. The library grid shows the coachings created with Zappy.

![The Zappy library grid with search, status filter, delete, and Create a coaching](/img/helpscout/authored/zappy-library-grid.png)

### 2. Start a new coaching
Select **Create a coaching** to begin the guided setup.

### 3. Choose the coaching details
Pick the kind of role play, describe the person the learner meets, and add any product files you want to use. You can upload up to 10 files, including PDF, Word, text, and image files.

### 4. Add instructions and confirm details
Write your instructions or choose a suggestion. Then confirm the coaching name and gender before you generate it.

### 5. Generate the coaching
Select **Generate**. Zappy creates the coaching in the background and shows a progress screen with a resumable link.

### 6. Review each section
When the coaching is ready, review the grouped sections for what the learner sees, who they meet, objections, product details, scoring, and settings. Use the pencil icon to edit any section.

![The review page with grouped sections, pencil edit controls, and Ask for a change boxes](/img/helpscout/authored/zappy-review-page.png)

### 7. Request changes
Use **Ask for a change** in any section to request a rewrite. You can use this up to 100 times for a coaching.

### 8. Adjust the settings
Open **Settings** to set the division, language, availability, and call length. For availability, choose a custom start and end date and time in the timezone you want.

### 9. Save or publish
Select **Save as draft** to keep working later, or **Publish** when the coaching is ready.

## Tips

- Use the search box to find a coaching quickly in the library.
- Use the status filter to narrow the list to the coachings you need.
- Review the settings before you publish so the coaching is available when you expect it.
- Use **Save as draft** if you want to return to the coaching later.

## Things to know

:::note
A draft opens in the coaching edit page. A published coaching opens in its preview.
:::

:::note
The library includes coachings created with Zappy. Existing coachings from the earlier version stay unchanged.
:::

:::note
New coachings can take a short time to appear in search after you create them.
:::
