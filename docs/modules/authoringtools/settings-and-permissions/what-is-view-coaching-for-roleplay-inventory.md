> **At a glance** - If you have the Global Editor sub-role, you can open a coaching from the Roleplay Inventory preview and go to its coaching page. From there, you can review details and make edits when you have access.

The Roleplay Inventory page shows all coachings. If you have the Global Editor sub-role, you also see a **View** button on the coaching preview page. Use it to open the coaching’s page directly and update the coaching if needed.

## When to use this

Use this when you need to work with coachings across divisions and you have the Global Editor sub-role.

- You want to open a coaching from the Roleplay Inventory preview.
- You need to review coaching details before editing.
- You manage coachings that span multiple divisions.
- You need direct access to the coaching page from the preview.

## Before you start

- You need the Global Editor sub-role.
- Your access must include all divisions for the coachings you plan to edit.

## Steps

### 1. Open Roleplay Inventory
Go to **COACHING > Video Coaching > View Coaching**, then you can see the coaching list page. From the hamburger menu in the top-right corner, select **Roleplay Inventory**. The page shows the available coachings, including coachings you may not directly access.

![go to view coaching](/img/helpscout/authored/authored-mwq4d7au.png)

### 2. Open a coaching preview
Select the coaching you want to review. The preview page opens for that coaching.

![role play inventory page all ciachings visible here](/img/helpscout/authored/authored-mwq4f4ql.png)

### 3. Select **View**
On the preview page, select **View**. This opens the coaching’s page directly.

![here u can see this view click on view button](/img/helpscout/authored/authored-mwq4i00i.png)

### 4. Edit and save changes
Make the updates you need on the coaching page, then save your changes.

![u will get into the settings page here u can edit what u needed](/img/helpscout/authored/authored-mwq4jorn.png)
