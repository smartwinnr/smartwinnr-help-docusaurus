> **At a glance** - Users with an editor role can access KHub analytics to evaluate content performance and user engagement.

Only users who have an editor role can view KHub analytics. This feature allows you to analyze the performance of KHub items and gain insights into user engagement.

## When to use this
Use KHub analytics when you want to:
- Evaluate the effectiveness of your KHub content.
- Monitor user engagement and interaction with specific KHub items.
- Identify trends and areas for improvement in your KHub resources.

## Steps

### 1. Access KHub Analytics
Go to the **Left Menu** > **LEARNING AND KNOWLEDGE** > **KHub** > **Analytics**. This will open the analytics page.

![KHub Analytics Page](/img/helpscout/authored/how-can-i-view-khub-analytics-mswt2cqt.png)

### 2. Filter Analytics
You can filter the analytics by country, group, frequency, name, email, and meta tags. This makes it easy for you to quickly find the analytics you need.

![Filter Options](/img/helpscout/authored/how-can-i-view-khub-analytics-mswt3ev6.png)

### 3. Search for KHub Items
Use the search feature to select a particular KHub item from the list and view its analytics.

![Search KHub Item](/img/helpscout/authored/how-can-i-view-khub-analytics-mswt4sr6.png)

### 4. Analyze Bar Graph Data
The analytics of the KHub item is displayed in the form of a bar graph. This graph provides an intuitive way to analyze KHub item data, such as the total number of views and views per day. You can also filter this graph based on the date range.

![Bar Graph of KHub Analytics](/img/helpscout/authored/how-can-i-view-khub-analytics-mswt603a.png)

### 5. Review Search Terms
There is a section showing search terms and the count of how many times each term was searched. This information can help you understand what users are looking for.

![Search Terms Count](/img/helpscout/authored/how-can-i-view-khub-analytics-mswt6scf.png)
