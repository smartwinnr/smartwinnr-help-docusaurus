> **At a glance** - This article shows you how to set visibility and write permissions for KHub items, ensuring the right users have access.

To provide KHub access, you need to set two types of permissions: Visibility Permission and Write Permission. This allows you to control who can see and edit KHub items.

## When to use this
Use this process when you want to:
- Grant specific users access to KHub items.
- Control visibility based on user attributes like divisions or countries.
- Allow certain users to edit or update KHub content.

## Steps

### 1. Log in to the editor account
Log in to your editor account and navigate to the **KHub**. Select the folder containing the KHub items.

![KHub items in the folder](/img/helpscout/authored/authored-mrutzmoa.png)

### 2. Access the Access Control settings
Click on the **Hamburger Menu** of the folder and select **Access Control**.

![Providing Access Permission](/img/helpscout/authored/authored-mruu6sk4.png)

### 3. Set Visibility Permissions
In the **Visibility Permission** section, select the appropriate **Metatags**, **Divisions**, **Country**, and **Groups**. This determines which users can see the KHub item.

![Visibility Permission](/img/helpscout/authored/authored-mruuadww.png)

### 4. Set Write Permissions
In the **Write Permission** section, select the **Division** and **Country** of the editors who need to edit or update the KHub. You can also select the **Meta Tags** for these editors.

![Write Permission](/img/helpscout/authored/authored-mruugmp3.png)
