> **At a glance** - To award points on badge assignments, create the required badges first, then follow the steps to assign badges and allocate points.

Before you go ahead with the assignment, you'll have to create the required badges.

[Learn How To Create Badges](../create-and-manage/how-to-create-badges.md)

Here are the steps to award points on assigning badges as part of the competition:

### 1. Navigate to Competitions
Go to **Left Menu >> GAMIFICATION AND ENGAGEMENT >> Competitions**.

### 2. Open the Competition
Open the competition from which you would like to assign badges and award points.

### 3. Select Assign Badges
From the landing page or first step of the competition, choose the hamburger menu in the top right-hand corner and select the option '**Assign Badges**' to proceed with assigning the badges.

![From the landing page or first step of Competition, choose the hamburger menu in the top right-hand corner and select the option 'Assign Badges'](/img/helpscout/editors/how-to-award-points-on-badge-assignment-1.jpg)

### 4. Access the Assignment Page
Once you select the above-mentioned option, you will be redirected to the page from which you'll be taken to the assignment page for badges.

### 5. Use Advanced Search
Click on the **Advanced Search** option to find and select users more effectively using the '**Search**' functionality. Type the name or email ID of the user to whom you would like to assign badges, and then hit the **Search** button.

![Click on the Advanced search option to have a better option to find out/select the users by using the 'Search' functionality. Type the name or email ID of the user to whom you would like to assign badges, and then hit the 'Search' button.](/img/helpscout/editors/how-to-award-points-on-badge-assignment-2.png)

### 6. Assign the Badge
It will pop up the user details as follows. Click on the **Assign** button to start assigning the badge.

![It will pop up the user details as follows and click on the 'Assign' button to start assigning the badge.](/img/helpscout/editors/how-to-award-points-on-badge-assignment-3.jpg)

### 7. Choose Badge Type
You will be taken to the assignment page from which you can choose the type of badge you would like to award.

### 8. Allocate Points and Add Comments
Mention the points that you would like to allocate along with the badge and add a comment to notify the user.

![Mention the points that you would like to allocate along with the badge and add a comment you would like to notify the user.](/img/helpscout/editors/how-to-award-points-on-badge-assignment-4.png)

### 9. Save the Assignment
Once you fill in the data with points and comments on the above-mentioned page, click on the **Save** button. The badge will be assigned to the user, and the user will be notified. Upon assigning the badges, you'll be able to see the user-wise assigned badges along with points as follows.

![Once you fill up the data with points and comments on the above-mentioned page, click on the Save button. It will get the badge assigned to the user and the user be notified on the same.](/img/helpscout/editors/how-to-award-points-on-badge-assignment-5.png)

### 10. User Notification
The user can log into the app and see the assigned badge as well as the allocated points updated on the competition leaderboard.

## Things to know
- Keep the competition active to allocate the points on badge assignments and get them updated on the competition leaderboard.
- Once you create the badges, there is no need to assign them individually, as we provide an option to assign badges outside of the competition. Since the points are allocated on the assignments, you need to do the assignment within the competition as mentioned.
