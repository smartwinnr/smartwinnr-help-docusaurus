> **At a glance** - This article explains how to view the data and leaderboard for Scorecard in the KPI Gamification module.

You can view the data and leaderboard for Scorecard by navigating to **EDITOR → PERFORMANCE → Scorecards**. Here, you will see all the scorecards created, along with options to view data and view leaders.

## When to use this
Use this feature when you want to:
- Analyze uploaded data values for each KPI.
- Check the leaderboard for scorecards to see user performance.
- Select specific KPIs to view detailed data for individual users.

## Steps

### 1. Navigate to Scorecards
Go to **EDITOR → PERFORMANCE → Scorecards**. Here, you can see all the scorecards created.

![Scorecards overview showing view data and view leaders options](/img/helpscout/authored/how-to-view-the-data-and-leaderboard-for-scorecard-msyfe3y6.png)

### 2. View Data
Click on **View Data** to see all the uploaded data values for each KPI. You can select the KPI you need from the dropdown menu. This allows you to view the uploaded data for that particular KPI for each user within the specified date or month.

![View Data options for selecting KPIs and viewing uploaded data](/img/helpscout/authored/how-to-view-the-data-and-leaderboard-for-scorecard-msyfvqg6.png)

### 3. View Leaders
Click on **View Leaders** to access the Scorecard leaderboard. This leaderboard displays the performance of users based on the scorecards

![Scorecard leaderboard showing user performance](/img/helpscout/authored/how-to-view-the-data-and-leaderboard-for-scorecard-msyicc4z.png)
