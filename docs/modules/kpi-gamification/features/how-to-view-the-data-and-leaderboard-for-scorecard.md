> **At a glance** - At a glance — The Scorecard Data View helps you review KPI achievement and scores for individual users across measurement periods. The Scorecard Leaderboard provides a ranked view of users based on their scorecard performance.

Scorecards measure sales reps' performance against defined KPIs by setting **measurement periods, targets, and scoring mechanisms**. Once a scorecard is created, you can use the **View Data** and **View Leaders** options to review KPI performance and leaderboard results.

## When to use this

Use the Scorecard Data View and Leaderboard when you want to:
- Review KPI achievement for individual users.
- Check the scores calculated for each KPI.
- Compare performance across different measurement periods.
- Review the performance of a specific KPI within a scorecard.
- View users ranked based on their scorecard performance.

## Before you start

Make sure that:

- The required KPIs have been defined.
- Field mappings have been configured.
- A scorecard has been created with the **required measurement frequency, targets, and scoring mechanism**.

For more information, see [What are Scorecards?](https://help.smartwinnr.com/modules/kpi-gamification/features/what-are-scorecards/)

## Steps

### 1. Navigate to Scorecards

Go to **EDITOR → PERFORMANCE → Scorecards**.

The Scorecards page displays the available scorecards. For each scorecard, you can see the number of KPIs included and access:
- **View Data** – View KPI performance data and scores.
- **View Leaders** – View the scorecard leaderboard.

![Scorecards overview showing view data and view leaders options](/img/helpscout/authored/how-to-view-the-data-and-leaderboard-for-scorecard-msyfe3y6.png)

### 2. View Scorecard Data

Click **View Data** for the required scorecard.

The KPI Score page allows you to review KPI performance for individual users across different measurement periods chosen for the scorecard. The measurement period can be day, week, fortnight, month, quarter, year or custom range based on the Measurement Frequency set for the scorecard.

You can use the available filters to narrow down the data:

- Business Unit – Filter data by business unit.
- Country – Select the required country.
- Group – Select a specific group.
- Advanced Search – Use additional search options.
- Select scorecard – Select the scorecard you want to review.
- Select KPI – Select a specific KPI within the scorecard.

The data is displayed by user, with the available measurement periods shown across the page.

![View Data options for selecting KPIs and viewing uploaded data](/img/helpscout/authored/how-to-view-the-data-and-leaderboard-for-scorecard-msyfvqg6.png)

**Understanding the KPI values**

The data view shows the user's achievement and calculated score for the selected KPI.

For example, a value such as **28/40 - 20.00** represents:

- 28/40 – The achieved value compared with the target.
- 20.00 – The score calculated for the KPI.

The measurement periods shown depend on the **measurement frequency configured** for the scorecard, such as monthly or other configured periods.

    - Note: The exact values and measurement periods displayed depend on the KPI and scorecard configuration.

### 3. View the Scorecard Leaderboard

Click **View Leaders** for the required scorecard.

The **Scorecard Leaderboard** displays users in rank order based on their scorecard score.

The leaderboard includes:

- Rank – The user's position on the leaderboard.
- Name – The participant's name and country.
- Total Score – The participant's overall score from all KPIs included in the selected scorecard.
- KPI columns – The score associated with the individual KPIs included in the scorecard.

This provides a consolidated view of participant score and how the score is distributed across the KPIs.

![Scorecard leaderboard showing user performance](/img/helpscout/authored/how-to-view-the-data-and-leaderboard-for-scorecard-msyicc4z.png)

Thus, the **Data View** helps you understand the underlying KPI performance and scores for users, while the **Leaderboard** presents the resulting performance in a ranked format. 

The Scorecard **Data View** helps you analyze KPI achievement and scores across users and measurement periods. The Scorecard **Leaderboard** provides a consolidated, ranked view of participant performance.

Use **View Data** when you need to investigate KPI-level performance and **View Leaders** when you want to review the resulting rankings and scores.
