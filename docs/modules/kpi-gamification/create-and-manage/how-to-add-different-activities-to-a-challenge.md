> **At a glance** - This article outlines the steps to add various activities to a challenge in the SmartWinnr platform.

Follow the steps below to add activities inside a challenge:

## When to use this
Use this guide when you need to create or modify a challenge by adding different types of activities, such as quizzes, KPIs, or scorecard points.

## Steps

### 1. Navigate to Challenges
Go to **EDITOR > PERFORMANCE > Challenges**. Click on the particular challenge for which you want to add the activities.

![Go to EDITOR > PERFORMANCE > Challenges. Click on the particular challenge for which you want to add the activities.](/img/helpscout/editors/how-to-add-different-activities-to-a-challenge-1.jpg)

### 2. Set Up Notifications
By checking the **Send Custom Notification** option, you can inform users by sending them a custom email about the challenge.

### 3. Configure Challenge Settings
Under **Settings**:

- **Challenge Type:** Set the challenge for users, managers, or groups.
- **Meta Tag Type:** Select the meta tag based on your requirement (e.g., Role, Region, Territory).
- **Assignment Type:** Choose to send the challenge now or schedule it for a specific time.

Select the **Start Date** and **End Date** based on your time zone.

### 4. Add Challenge Activities
To add challenge activities, click the plus icon.

You can select activities from the drop-down menu (Quiz, KPI, and Scorecard Points).

![You can select the activities from the drop-down (Quiz, KPI, and Scorecard Points.)](/img/helpscout/editors/how-to-add-different-activities-to-a-challenge-2.jpg)

### 5. How to Add a Quiz to Challenge
**Quiz:** The editor can use the challenge type as a quiz to motivate two different users or teams to improve their knowledge and score high marks in the quiz.

Here, you need to select the quiz that you want the user to complete as part of the challenge.

![Here you need to select the quiz that you want the user to go through the challenge.](/img/helpscout/editors/how-to-add-different-activities-to-a-challenge-3.jpg)

### 6. How to Add KPIs to Challenge
**KPI:** By selecting a particular KPI, the editor can challenge two users or teams in a specific segment (e.g., Sales, Revenue).

![KPI: By selecting a particular KPI, EDITOR can challenge two users or teams in a particular segment (Example: Sales, Revenue)](/img/helpscout/editors/how-to-add-different-activities-to-a-challenge-4.jpg)

### 7. How to Add Scorecards to Challenge
**Scorecard Points:** The editor can also challenge users by comparing scorecard points to motivate them to perform better.

![Scorecard Points: EDITOR can also challenge by comparing the Scorecard points to motivate the users to perform better.](/img/helpscout/editors/how-to-add-different-activities-to-a-challenge-5.jpg)

After selecting the scorecards, click **Select** to add different activities to the challenge.
