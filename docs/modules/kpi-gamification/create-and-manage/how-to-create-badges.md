> **At a glance** - SmartWinnr enables you to create Badges and Certificates as achievements. This article outlines the steps to create and assign Badges.

SmartWinnr allows you to create two types of achievements - Badges and Certificates. Follow the steps below to create a Badge.

## When to use this
Use this feature when you want to recognize users for specific achievements within your organization. Badges can motivate and engage users by acknowledging their accomplishments.

## Steps

### 1. Navigate to Badges and Certificates
Go to **Left Menu >> Editor >> GAMIFICATION AND ENGAGEMENT >> Badges And Certificates**.

![This page shows various Badges and Certificates that are already existing](/img/helpscout/authored/how-to-create-badges-msww13mg.png)

This page shows various Badges and Certificates that already exist. The editor can view Badges and Certificates individually by selecting the type and then clicking the search button.

### 2. Add Achievement
Click on **Add Achievement** in the top right-hand corner of the page. The following page will open.

![Click on the "Add Achievement" in the top right-hand corner of the above image, following page will open.](/img/helpscout/editors/how-to-create-badges-2.png)

This page provides options for adding various types of achievements. The editor can select the type of achievement by clicking on **Achievement Type**. After selecting the achievement type (whether it be a Badge or Certificate), choose the Badge from the drop-down menu to create a Badge. The editor needs to input the appropriate achievement title corresponding to the achievement.

![Choose the Badge from the drop-down menu to create a Badge. The editor needs to input the appropriate achievement title corresponding to the](/img/helpscout/editors/how-to-create-badges-3.png)

The editor can also write a brief description of the achievement in the **Description** area. Then, upload an appropriate image corresponding to the achievement type. After all the fields are successfully filled, click on **Create Achievement**. The new achievement will be added.

### 3. Assign the Badge
Once the Badge is created, you need to assign it to the users you would like to reward. Click on the **Assign** option to assign the badge to the users.

![Click on the 'Assign' option to assign the badge to the users.](/img/helpscout/editors/how-to-create-badges-4.png)

This will redirect you to the user list page, where you can select the users for whom you would like to share it. Here, you can filter by group and easily assign it to the list of users belonging to the specific group.

![It will redirect to the user list page, where you can select the users for whom you would like to share it. Here, you can filter with a grou](/img/helpscout/editors/how-to-create-badges-5.png)

Click on the **Assign** button at the bottom to assign it to the users.

### 4. Bulk Assign Badges
You can also bulk assign the badge if you have a list of many users that you cannot assign manually. Click on **Hamburger Menu >> Bulk Assign**.

![Click on the Hamburger Menu>>Bulk Assign.](/img/helpscout/editors/how-to-create-badges-6.jpg)

Once the page opens, you need to download the template by selecting the Badge name from the **Achievements** drop-down and the Email ID in the **User Identifier** drop-down.

![Once the page is opened you need to download the template by selecting the Badge name from the "Achievements" drop down and the Email Id in ](/img/helpscout/editors/how-to-create-badges-7.jpg)

Once the template is downloaded, input the email IDs of the users you want to assign the badge, save the CSV file, and upload it under the **Choose File** option.

### 5. View Assignment History
After the badge is assigned, you can see the list of users for whom the badge has been awarded. Click on **Hamburger Menu >> Assignment History**.

![Once it is assigned, you can also see the list of users for whom the badge has been awarded. You can click on the Hamburger Menu>>Assignment](/img/helpscout/editors/how-to-create-badges-8.png)

Click on the **View Logs** option to see the list of users for whom the badge has been awarded.

![Once it is assigned, you can also see the list of users for whom the badge has been awarded. You can click on the Hamburger Menu>>Assignment](/img/helpscout/editors/how-to-create-badges-9.png)
