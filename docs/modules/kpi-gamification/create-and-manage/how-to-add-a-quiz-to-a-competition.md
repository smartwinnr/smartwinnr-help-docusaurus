> **At a glance** - This article explains how to add a quiz to a competition in SmartWinnr, detailing each step from selecting the quiz task to creating the quiz.

To add a quiz to a competition, you will need to follow specific steps during the competition creation process. This allows you to incorporate quizzes as tasks within your competitions, enhancing engagement and gamification.

## When to use this
Use this process when you want to:
- Create a competition that includes a quiz as a task.
- Engage participants with interactive quiz content.
- Track performance and scores through quizzes.

## Steps

### 1. Select the Quiz Task
In the **fourth step** of creating a competition, select **Quiz** from the **“Select Task”** dropdown.

### 2. Enter the Quiz Name
Enter a **name** for the quiz task.

### 3. Assign Points
Assign the **points** to be awarded for completing the quiz.

### 4. Set Dates
Set the **start and end dates** for the quiz task.

![Below is a screenshot of adding a quiz to a competition](/img/helpscout/editors/how-to-add-a-quiz-to-a-competition-1.png)

### 5. Choose Participants Manually
Check the **“Choose Participants Manually”** checkbox to manually select the participants for the quiz. This allows you to **exclude specific users** from the participant list if necessary.

### 6. Assign Points for Correct Answers
Specify the **points for correct answers** to be awarded to quiz takers. Enter the desired value in the provided field.

### 7. Create the Quiz
Click the **“Create”** button. You will be redirected to a page where you can **create a new quiz** and add it to the competition.

For detailed instructions on creating a quiz, refer to the following articles:

- [How to create an automatic quiz?](/modules/quiz/create-and-manage/create-automatic-quiz)
- [How to create a manual quiz?](/modules/quiz/create-and-manage/how-to-create-a-manual-quiz)

### 8. Duplicate an Existing Quiz
Clicking on the **"Duplicate Quiz"** button opens a pop-up from where you can select an existing quiz and duplicate it.

![Clicking on the "Duplicate Quiz" button opens the following pop-up from where you can select an existing quiz and duplicate it.](/img/helpscout/editors/how-to-add-a-quiz-to-a-competition-2.png)
