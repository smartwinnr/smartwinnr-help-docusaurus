> **At a glance** - This article outlines the steps to add a scorecard to a competition within the KPI Gamification module.

Adding a scorecard to a competition allows you to track performance and progress effectively. Follow these steps to set up a scorecard for your competition.

## When to use this
Use this feature when you want to:
- Create a competition that includes performance tracking.
- Monitor participant progress through scorecards.
- Enhance engagement and motivation among competitors.

## Steps

### 1. Select Scorecard in Competition Setup
In the **fourth step** of creating a competition, select **Scorecard** from the **“Select Task”** dropdown.

### 2. Name the Scorecard Task
Enter a **name** for the scorecard task.

### 3. Choose the Desired Scorecard
Select the **desired scorecard** that you want to add to the competition.

### 4. Set Dates for the Scorecard Task
Set the **start and end dates** for the scorecard task.

![Below is a screenshot of adding a scorecard to a competition:](/img/helpscout/editors/how-to-add-a-scorecard-to-a-competition-1.png)

### 5. Create the Competition
Then, click on the **Create** button. The scorecard will be added to the competition successfully.
