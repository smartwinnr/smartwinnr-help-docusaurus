> **At a glance** - This article explains how to add a Video Coaching task to a competition in SmartWinnr.

You can enhance your competition by adding a Video Coaching task. This allows participants to engage in coaching sessions through video, enriching their learning experience. Follow the steps below to add a Video Coaching task to your competition.

## Steps to Add Video Coaching to a Competition

### 1. Select Video Coaching
In the **fourth step** of creating a competition, select **Video Coaching** from the **“Select Task”** dropdown.

### 2. Enter Task Name
Enter a **name** for the video coaching task.

### 3. Assign Points
Assign **points** for completing the task.

### 4. Set Dates
Set the **start and end dates** for the task.

Below is a screenshot illustrating how to add a **Video Coaching** task to a competition:

![Below is a screenshot illustrating how to add a Video Coaching task to a competition:](/img/helpscout/editors/how-to-add-a-video-coaching-to-the-competition-1.png)

### 5. Choose Participants Manually
Check the **“Choose Participants Manually”** checkbox to manually select participants for the Video Coaching task. This allows you to **exclude specific users** from the participant list if needed and assign the task to only a specific user set.

### 6. Create the Task
Click the **“Create”** button. You will be redirected to a page where you can **create the Video Coaching task** and add it to the competition.

### 7. Duplicate an Existing Coaching Scenario
You can duplicate an existing coaching scenario by clicking on **Duplicate Coaching** as shown below. 

![Duplicate coaching image](/img/helpscout/authored/how-to-add-a-video-coaching-to-the-competition-mt1e7yey.png)

Select the coaching scenario you want to duplicate. It will show **"Duplicate this coaching for current competition"**; click on it.

![Select coaching to duplicate](/img/helpscout/authored/how-to-add-a-video-coaching-to-the-competition-mt1ebs1l.png)
