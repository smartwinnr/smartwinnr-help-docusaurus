> **At a glance** - This article explains how to create certificates and badges in the SmartWinnr platform. Follow the steps to add achievements and customize them for your users.

Go to **Left Menu** >> **Editor** >> **GAMIFICATION AND ENGAGEMENT** >> **Badges And Certificates**.

![This page shows various Badges and Certificates that are already existing](/img/helpscout/authored/how-to-create-certifcates-msww50ie.png)

This page displays various badges and certificates that already exist. The editor can view badges and certificates individually by selecting the type and then clicking on the search button.

## When to use this
Use this feature when you want to create and manage achievements for your users, such as certificates and badges. This is useful in scenarios like:
- Recognizing user accomplishments.
- Encouraging engagement through gamification.
- Customizing achievements for specific events or milestones.

## Steps

### 1. Add Achievement
Click on the **Add Achievement** button. The following page will open.

![Click on the "Add Achievement" following page will open](/img/helpscout/editors/how-to-create-certifcates-2.png)

This page provides options for adding various types of achievements. The editor can select the type of achievement by clicking on the **Achievement Type** dropdown.

### 2. Fill in Achievement Details
After selecting the achievement type (either a badge or certificate), input the appropriate achievement title in the **Title** field. Write a brief description of the achievement in the **Description** area.

### 3. Upload Achievement Image
Upload an appropriate image corresponding to the achievement type using the **Upload Image** button.

![The editor also needs to upload an appropriate image corresponding to the achievement type.](/img/helpscout/editors/how-to-create-certifcates-3.png)

### 4. Create Achievement
After all fields are successfully filled, click on **Create Achievement**. The new achievement will be added.

### 5. Update Certificate Image
You can update the image for a certificate by clicking on the picture. This will allow you to enter the Sales Rep's name.

![You can update the image for a certificate by clicking on the picture and add a box where you can enter the Sales Rep's name.](/img/helpscout/editors/how-to-create-certifcates-4.jpg)

Here, you can change the font size and color of the name according to the certificates. Click on **Update** after completing the process.

### 6. Assign Certificate
Next, assign the certificate to the user you want to recognize.

![Then you have to assign the user to whom you want to give the certificate](/img/helpscout/editors/how-to-create-certifcates-5.jpg)

Click on **Assign** after completing the process.

## Tips
- Ensure that the images you upload are high quality for the best presentation of certificates.
- Use clear and concise titles and descriptions to enhance user understanding of the achievements.
- Regularly review and update achievements to keep them relevant and engaging for users

## Things to know

Ensure you have the necessary permissions to create and manage achievements. If you encounter any issues, contact your system administrator.
