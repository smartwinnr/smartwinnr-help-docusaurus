> **At a glance** - This article explains how to add a survey task to a competition in the KPI Gamification module. Follow the steps to create and configure your survey.

Adding a survey to a competition allows you to gather valuable feedback and insights from participants. You can set up the survey as part of the competition creation process, ensuring that it aligns with your objectives.

## When to use this
Use this feature when you want to:
- Gather participant feedback during a competition.
- Enhance engagement by including surveys in your competitions.
- Evaluate participant experiences and insights.

## Steps to Add a Survey to a Competition

### 1. Select Survey from the Dropdown
In the **fourth step** of creating a competition, select **Survey** from the **“Select Task”** dropdown.

### 2. Enter a Name for the Survey Task
Provide a **name** for the survey task.

### 3. Assign Points for the Task
Specify the **points** that participants will earn upon completing the survey.

### 4. Set Start and End Dates
Define the **start and end dates** for the survey.

![Below is a screenshot illustrating how to add a survey to a competition.](/img/helpscout/editors/how-to-add-a-survey-to-a-competition-1.png)

### 5. Choose Participants Manually
Check the **“Choose Participants Manually”** checkbox to manually select the participants for the survey. This allows you to **exclude specific users** from the participant list if needed.

### 6. Create the Survey
Click the **“Create”** button. You will be redirected to a page where you can **create a new survey** and add it to the competition.

[How can I create a survey?](/modules/survey/create-and-manage/how-to-create-a-survey)

[What are the different question types in a survey?](/modules/survey/features/what-are-the-different-question-types-in-a-survey-survey-template)

### 7. Duplicate an Existing Survey (Optional)
Clicking on the **"Duplicate Survey"** button opens a pop-up from which you can select an existing survey to duplicate.

![Clicking on the "Duplicate Survey" button opens the following pop-up from where you can select an existing survey and duplicate it.](/img/helpscout/editors/how-to-add-a-survey-to-a-competition-2.png)
