> **At a glance** - Use **Global Points** to review points earned across SmartWinnr activities. Use **Aggregated Rank** to see how those points affect leaderboard position.

**Global Points** show the points users earn across activities in SmartWinnr. You can review those points in **Admin > Global Points** and see how they roll up into overall rankings. This helps you check user performance and compare ranks across leaderboards.


Users can earn **Global Points through** activities such as **quizzes, coaching, SmartPath, competitions, first login, and profile image uploads**. These points contribute to the users' overall performance and are reflected in the relevant Global and Division-wise leaderboards.

From the Global Points menu, Admin can:

- View the Global Points list.
- Upload points in bulk.
- View aggregated ranks across leaderboards.
- Understand how Global Points contribute to global leaderboard and division wise leaderboard rankings.

## When to use this

Use **Global Points** when you need a single view of user points across the platform.

- Review points earned through quizzes, coaching, SmartPath, competitions, first login, and profile image uploads.
- Check the points recorded for a user before making updates.
- View aggregated ranks across relevant leaderboards.
- Compare performance across the organization or within a division.

## Steps

### 1. Open Global Points
Go to **Admin > Global Points** to view the points area.

You can use this section to review the available Global Points data and check the points accumulated by users.
This view is useful when you need to review user points or verify the data before making updates.

![to find global points, goto Admin > global points > view aggregate rank](/img/helpscout/authored/authored-mvaybd8r.png)

### 2. Review the points list
Use the **Global Points** list to see points recorded for users.This section will have points only immediately after the points are awarded to the user. Ever one hour the points get migrated to the aggregate ranking and is them removed from this page.

### 3. View aggregated rank
Open **View Aggregated Rank** to see each user's total score and their rank based on accumulated points.

![here, you can view the aggregate rank and the total score from different paramter based on the perod selected](/img/helpscout/authored/authored-mvayc30o.png)

### 4. How to Upload Global Points in Bulk

SmartWinnr allows Admin to upload Global Points in bulk when points need to be added for multiple users. Please note that the points can be uploaded only for the first login and profile image upload.

**Steps:**

1. Navigate to the **Global Points** section in the Admin portal.
2. Select the **upload** option.

![upload global points](/img/helpscout/authored/how-to-manage-global-points-and-aggregated-ranks-mvf84p4y.png)

3. Download the sample template and fill the user details, Object type as first login/profile image upload and points to be awarded.

![Fill the template](/img/helpscout/authored/how-to-manage-global-points-and-aggregated-ranks-mvf83cy5.png)
4. Once the template is filled, upload the same into SmartWinnr.
5. Review the upload results to ensure the data has been processed correctly.

## Things to know

## How Global Points Relate to Leaderboards

**Global Points** contribute to the overall ranking displayed on the global leaderboards.

### Global Leaderboard
The Global leaderboard provides an overall view of users' accumulated points and rankings across the organization from quizzes, coaching, SmartPath, competitions, first login, and profile image uploads.

**Division-wise Global Points Leaderboard**
The Division-wise Global Points leaderboard allows users' points and rankings to be viewed within their respective divisions. This helps admins compare users performance with others in the same division.

![divison wise leaderboard](/img/helpscout/authored/how-to-manage-global-points-and-aggregated-ranks-mvf8ku2f.png)

:::note
Global Points can come from quizzes, coaching, SmartPath, competitions, first login, and profile image uploads.
:::

:::note
Global Points contribute to the **Global Points** leaderboard and the **Division-wise Global Points** leaderboard.
:::
