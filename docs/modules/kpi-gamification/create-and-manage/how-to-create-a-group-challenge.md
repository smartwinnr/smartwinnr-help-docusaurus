> **At a glance** - This article outlines the steps to create a group challenge in the SmartWinnr platform.

Creating a group challenge allows you to engage teams in a competitive environment, fostering motivation and performance. Follow the steps below to set up a group challenge effectively.

## When to use this
Use this feature when you want to:
- Encourage teamwork and collaboration through challenges.
- Motivate employees to achieve specific KPIs.
- Create a competitive atmosphere within your organization.

## Steps

### 1. Navigate to the Challenges page
Go to **EDITOR > PERFORMANCE > Challenges**. Click on the **Create Challenge** button. This will open the page where you can fill in the details of the challenge.

![describe this screenshot](/img/helpscout/authored/how-to-create-a-group-challenge-mswtt56p.png)

### 2. Fill in the Challenge details
- **Challenge Name**: Give the name of the challenge.
- **Challenge Description**: Provide a description of the challenge.
- **Division**: Select a business unit for which the challenge is being created. This field will not be visible if you have access to only your division.
- **KPI**: Select a KPI for the challenge.
- **Challenge Type**: Specify the type of challenge you are creating. You have three options: User, Manager, and Group. Select **Group** to create a group challenge.
- **Start Date and End Date**: Specify the start and end dates for the challenge.
- **Win**: Specify the points to be allotted to the winning side.
- **Lose**: Specify the points to be allotted to the losing side.
- **Draw**: Specify the points to be allotted in case of a draw.
- **No Points**: Specify the points to be given if either of the teams does not score any points in the KPI.

### 3. Select Challenge Pairs
This section lets you select the pairs between whom the challenge will be conducted. Click on the **Add Pair** button to add pairs of competitors. It opens the following pop-up.

![Select Challenge Pairs: This section lets you select the pairs between whom the challenge will be conducted. Click on the 'Add Pair' button](/img/helpscout/editors/how-to-create-a-group-challenge-2.png)

Since you have selected the **Challenge Type** as **Group**, you will be able to select groups as pairs of competitors for the challenge. Click on the **Add** button once you have added the pairs of participants.

### 4. Create the Challenge
Finally, click on the **Create** button at the bottom to successfully create the challenge.
