> **At a glance** - This article explains how to create a KPI within SmartWinnr, detailing each field and its purpose.

In the previous article, we learned about how KPIs are selected. In this article, we will see how to create a KPI within SmartWinnr.

## When to use this
Use this guide when you need to establish a new KPI for tracking performance metrics in your organization. This can be useful for:

- Monitoring sales performance.
- Assessing training effectiveness.
- Evaluating team productivity.
- Aligning KPIs with organizational goals.

## Steps

### 1. Navigate to KPI Settings
Go to **ADMIN > KPI Settings > Definitions** and click on the **Add New KPI** button in the top corner.

### 2. Enter KPI Name
Enter the name of the KPI. Keep the list of KPIs handy. Example: Revenue, Number of Leads.

### 3. Select Metric Type
Select the type of measurement, such as whether it's the sum of revenue or the number of calls.

* * *

_If you are counting the number of calls, the metric type should be 'Sum'._

* * *

### 4. Choose Format and Dimension
Select the format of the KPI. For example, select 'Number' if it's 'Number of Calls'. Select 'Percentage' if it's 'Completion', select 'Duration' if it's 'Call Duration', and mention 'min' in Dimension. Select 'Currency' if it's 'Revenue' and mention the currency as $.

### 5. Select Categories
Select a category to map the KPI to specific skill areas of representatives. This is an optional field, but filling it out is crucial if you want to see a correlation between how training and other skill improvements are affecting performance.

### 6. Edit KPI Definitions
You can edit KPI definitions that you have already created. Changes can be made in each of the fields.

_Bear in mind that changes to the 'Metric Type' field cannot be made once you have already uploaded data against that KPI._
