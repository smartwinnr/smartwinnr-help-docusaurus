> **At a glance** - This article explains how to add a form to a competition in the KPI Gamification module.

Adding a form to a competition allows you to collect specific information from participants. This is useful for gathering insights or feedback during the competition. Follow the steps below to successfully add a form.

## When to use this
Use this feature when you want to:
- Gather information from competition participants.
- Enhance engagement by including forms in your competitions.
- Track responses and feedback effectively.

## Steps

### 1. Select Form from the Dropdown
In the **fourth step** of creating a competition, select **Form** from the **“Select Task”** dropdown.

### 2. Enter a Name for the Form Task
Enter a **name** for the form task.

### 3. Set Start and End Dates
Set the **start and end dates** for the task.

![Below is a screenshot illustrating how to add a Form to a competition:](/img/helpscout/editors/how-to-add-a-form-to-competition-1.png)

### 4. Choose the Desired Form
Select the **desired Form** you want to add to the competition.

### 5. Create the Form Task
Click the **“Create”** button. The Form will be **successfully added** to the competition.
