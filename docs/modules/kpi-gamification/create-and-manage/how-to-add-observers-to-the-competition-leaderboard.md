> **At a glance** - This article explains how Org Admins can add observers to competition leaderboards, allowing selected users to monitor leaderboard activity.

Only Org Admins can add observers to the competition leaderboards. This feature enables you to select specific users who can view the leaderboard without participating in the competition.

## When to use this
Use this feature when you want to:
- Allow specific users to monitor competition leaderboards.
- Manage who can view leaderboard details without altering competition participation.
- Ensure transparency and oversight in competition activities.

## Before you start
Ensure you have Org Admin access to perform these actions.

## Steps

### 1. Navigate to Competitions
Go to **EDITOR > GAMIFICATION AND ENGAGEMENT > Competitions**.

![Navigate to Competitions](/img/helpscout/editors/how-to-add-observers-to-the-competition-leaderboard-1.jpg)

### 2. Select the Competition
Choose the competition for which you want to add observers.

![Select the Competition](/img/helpscout/editors/leaderboards-of-a-competition-7.png)

### 3. View Leaderboards
After selecting the competition, click on the **View Leaderboards** tab.

![View Leaderboards](/img/helpscout/editors/leaderboards-of-a-competition-12.png)

### 4. Manage Leaderboard Observers
Click on **Manage Leaderboard Observers** and select the users you want to add as observers. This option allows you to select observers for all the leaderboards in the contest. It will open a page where you can choose the leaderboards and the observers to add.

![Manage Leaderboard Observers](/img/helpscout/editors/how-to-add-observers-to-the-competition-leaderboard-2.png)

### 5. Save Changes
Click on the **Save** icon at the bottom to complete the activity. A confirmation popup will appear.

![Save Changes](/img/helpscout/editors/how-to-add-observers-to-the-competition-leaderboard-2.png)

Click on the **Yes** button to add them as observers.

### 6. Confirm Observer Addition
Once saved, the selected observers will be displayed on the **Observers** button corresponding to that leaderboard.

![Confirm Observer Addition](/img/helpscout/editors/leaderboards-of-a-competition-13.png)

If you want to assign different observers to the leaderboards, click the same button for the respective leaderboard and follow the same steps to add the observers.
