> **At a glance** - Follow these steps to add a scorecard leaderboard to your competition.

Here are the steps to add a scorecard leaderboard to a competition

## When to use this
Use this process when you want to create a scorecard leaderboard for a specific competition. This is useful for tracking performance metrics and engaging participants.

## Steps

### 1. Navigate to Competitions
Go to the left side menu and select **Competitions** under **GAMIFICATION AND ENGAGEMENT**.

### 2. Select Your Competition
Choose the competition in which you want to add the scorecard leaderboard.

### 3. Access Leaderboards
After selecting the competition, click on the third step, **View Leaderboards**.

### 4. Add a New Leaderboard
Click on the **Add** icon at the top right corner.

### 5. Configure Leaderboard Settings
Enter the leaderboard name, select the **Scorecard** option in the type, and choose the required options

![Enter the leaderboard name and select the scorecard option in type and select the required options](/img/helpscout/editors/how-to-add-the-scorecard-to-leaderboard-1.png)

### 6. Add KPI Columns
Add the KPIs in the KPI columns configurations.

![Add the KPIs in the KPI columns configurations](/img/helpscout/editors/how-to-add-the-scorecard-to-leaderboard-2.jpg)

After selecting the KPI, choose the columns you want to add to the leaderboard.

![After selecting the KPI, you should select the columns that you want to add to the leaderboard.](/img/helpscout/editors/how-to-add-the-scorecard-to-leaderboard-3.jpg)

- **Total Achieved**: This column shows the data of your current progress.
- **Target**: This column displays the target for the selected time duration (Monthly, Weekly, etc.).
- **Score**: This column indicates the score the user has achieved based on the score set for the KPI.
- **Target Achieved**: This column shows your progress in comparison with the target, displaying the percentage of your target achieved.

Once you add the column, you can also change the label by clicking on it.

![Once you add the column, you can also change the Label by clicking on it.](/img/helpscout/editors/how-to-add-the-scorecard-to-leaderboard-4.jpg)

### 7. Save Your Changes
Click on the **Save** icon to complete the activity. Your scorecard leaderboard is now ready to use.
