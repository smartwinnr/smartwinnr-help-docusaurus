> **At a glance** - Follow these steps to create categories and tags to better organize your content.

Creating categories and tags helps you structure your content effectively. Use categories to group related items and tags to add specific attributes to those items.

## When to use this
Use categories and tags when you want to:
- Organize content for better navigation.
- Group similar items for easy access.
- Enhance searchability by adding tags.

## Steps

### 1. Navigate to Categories
Go to **Editor → SETTINGS → Categories**.

![Click on the Categories from Left Menu](/img/helpscout/authored/authored-ms8umny0.png)

### 2. View Existing Categories
You will see a list of the categories available in your organization.

![List of categories](/img/helpscout/authored/authored-ms8unfoc.png)

### 3. Add a New Category
Click on the **Add New** button. A pop-up will appear where you can select the division and module for the new category. Enter the **Category Display Name** and add any relevant tags.

![Category Details](/img/helpscout/authored/authored-ms8uqjdk.png)
![Tags under category](/img/helpscout/authored/authored-ms8uqy7x.png)

### 4. Save the Category
Click on the **Save Category** button to create your new category.

![Save Category](/img/helpscout/authored/authored-ms8us6vc.png)

## Tips
- Use clear and descriptive names for categories to make navigation easier.
- Regularly review and update your categories and tags to keep them relevant.
